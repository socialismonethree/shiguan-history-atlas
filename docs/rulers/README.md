# 历代统治者 · v0.20.0

独立的知识库板块，通史首页左栏与世界文明页面均有入口。公开静态网站，无账户或本地资料依赖。

## 本版范围

中国沿十九个时期展开主要王统、十六国、南北朝、五代十国、宋辽夏金、南明与部分其他并立政权。春秋战国按各政权注明实际起点，不声称上溯至所有始封祖。摄政者和实际掌权者另列角色，不把追尊自动算作在位。

世界按八个区域编排已核实的政权序列，包括罗马、英法俄、波斯、阿拉伯哈里发、奥斯曼、莫卧儿、朝鲜王朝、德川幕府、古埃及、墨西加、美国及夏威夷等。这个版本不等于全球所有国家和城邦的完整统治者名单；各政权自己的覆盖说明是判断边界的依据。年度对照截止1912年，1912年前已即位者可保留完整任期与其后的生平。

## 数据与维护

- `source/*.json` 是可编辑资料，格式为 `regimes` 与 `rulers`。每条人物用稳定 `id` 指向政权 `regimeId`，姓名变化不应随意改变 ID。
- `reigns` 是分段数组，分别记录皇帝、国王、摄政、共治和退位后掌权；复位不跨过失位年份连成一段。
- `born`、`died` 是有说明的文字，可用约数或未核定。旧库人物的活动起讫不能填入生卒或在位年。公元前用负整数，无公元0年。
- `life` 为原创叙述段落，`highlights` 为可证的个人史事，`assessment` 为带依据的历史定位；不得用虚构对白、心理活动或相同套话凑篇幅。
- `sources` 保存标题、公开 HTTPS 网址与定位说明。纸本书目允许空网址，并在页面显示为文字。用户提供的原著仅作整理依据，不发布全文、原始下载、私人路径或原始扫描页。
- `existingPersonIds`、`highlights[].eventId` 用于连接原知识库。关联背景不等于该人物亲自参与整个时期的每件事。相关事件正文沿用已有原创整理及来源。
- 有限史料与尚未核录是两种情况，文字分别注明；未知不等于历史上没有生卒记载。

修改后在仓库根目录执行：

```sh
node tools/sync-rulers.mjs
node tools/check-rulers.mjs
```

构建按政权生成 `content/*.json`，页面按需载入；`catalog.js` 仅用于目录、跨库搜索和年度在位对照。`manifest.json` 的实际统计和校验值是发布依据。资料深度依实际叙述长度分别标明，不把名录条数宣称为完整传记数。

## 持续考订

优先完善短条目中的出生地、亲属、关键转折与有直接史料支持的事迹，再扩展尚缺的世界王统和春秋诸侯。每次新增需要复核同名异人、改元与即位、共治起年、旧历跨年以及所据王表自身的错漏。对百科、宫廷资料和官方王表同样进行交叉核对，保留分歧，不简单复制。

# 中外战役专题维护说明

本专题以公开史料和研究资料整理重要战役选编，不代表穷尽。每条记录战役时间、地区、起因、过程、结果、影响、参战人物与资料链接，对史实争议分别说明；古代兵力和伤亡常有显著分歧，不能虚构精确数字。涉及现代地名仅为帮助定位，不作为历史疆界图。

`source/china.json` 和 `source/world.json` 可编辑，`year` 为排序用整数，公元前使用负数，同年可使用 `order` 表示先后。战役 ID 稳定且唯一，`sources` 对应来源 ID；来源须链接支持该事件的具体资料。修改后在仓库根目录运行 `node tools/sync-battles.mjs`、`node tools/check-battles.mjs`，并检查相关原有页面。

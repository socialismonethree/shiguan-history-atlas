关于史料与叙述

本专题依据公开资料整理，为重要战役选编，并非全部战役。战役日期、兵力、伤亡和战果的记载可能因史料和研究方法不同而存在差异；无法确定的数字不强行填入。战争对平民和社会的影响，与军事进程同样值得关注。

各战役的资料链接和具体争议见详情；本次未通过访问核验的链接会保留资料名称并暂停跳转。年代采用公元纪年，公元前年份按实际先后排列。

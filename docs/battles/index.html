本专题为重要战役选编，尚未穷尽所有战争。参战方使用当时国家、政权或军事集团名称；区域标签仅帮助浏览，具体地点见条目。“战争脉络”串联同一战争，“时代线索”与“跨地区线索”用于比较更长时段或不同战场，不表示各战役间均有直接因果。

时间线按战役开始时间或主要阶段排序，跨年战役会标出持续时间；古代约年、传统历法及争议年代按条目标明。分组背景由对应战役的既有资料整理，具体史料、争议与此前未通过访问核验的资料链接，均可在正文后展开查阅。

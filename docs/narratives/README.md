# 事件与人物叙事详解 · 0.8

本批共249篇：93篇中国事件、50篇世界事件，71篇中国人物、35篇世界人物。覆盖十九个中国时期与八个世界区域，共约11.1万正文字符（含标点和少量外文），不是全库2967条史事、1606个人物全部都已经详写。

事件分别讲时间、地点、背景、经过、直接结果和后续影响；人物分别讲生卒精度、籍贯与出身、生平、代表事迹、贡献与历史评价。作品栏目只在有本轮资料依据时显示，人生阶段保留非著述人物的代表事迹；不以通用占位文字凑作品。生卒不详、传统作者归属及历法换算分歧分别标注。

每篇保留现有稳定ID，`citations`标出来源和支持的正文段落。中国内容以用户提供的《中国断代史系列·全集》相关正文为重要基础，并补机构资料核对；世界内容采用博物馆、大学、官方档案、遗产机构等具体专题。150项来源包括具体网页及书稿来源条目，不等于150部完整研读的著作。部分机构资料只读取到检索摘录或书目，范围见相应note；未标称全库专家审定或每句均独立多源验证。

书稿行号是合并Markdown整理本行号，不是原书页码。原著中的时代观点、旧说及编辑归纳应分别理解，不能因有书名便忽略新材料。核对中特别注意了二里头年代、传统战史、纸的发明、生卒年公历换算和名篇的署名与成书层次。作品核对删去了本轮未定位的旁枝书名，并为赤壁赋、寒食帖、岳阳楼记、四书集注、康熙字典等补具体馆藏或书目依据。解释性影响与评价不作为学界一致结论。

`source/catalog.json`为来源和内容文件清单，源条目按批次、类型分成小JSON，便于逐条校订。运行`node tools/sync-narratives.mjs`生成浏览器数据脚本，再运行`node tools/check-narratives.mjs`和`node tools/check-annals.mjs`。校验只证明结构、引用、渲染与交互所需数据完整，不证明每条历史判断正确；事实和解释仍需阅读资料、持续修订。

未公开原书全文、原书图片或用户本地路径。收藏札记继续沿用旧条目ID。

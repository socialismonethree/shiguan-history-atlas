# 0.9 博物馆选藏

本次新增78件/组具体藏品：中国54、世界24；覆盖十九个中国时期、八个世界区域。原有19个时代意象与文化线索保留为单独折叠入口，不替换既有稳定ID。

## 编辑入口

`source/catalog.json`维护来源与文件清单；`early.json`、`late.json`、`world.json`、`open.json`、`regional.json`保存作品档案。修改后运行`node tools/sync-collections.mjs`生成浏览器脚本；再运行`node tools/check-collections.mjs`。不直接改生成脚本。

每件必填稳定ID、时期或区域、馆方年代、数值检索区间、材质、门类、收藏机构、中文概述、重要性、三项观看点、断代说明、来源与定位。编号和出土/流传没有可靠依据时留空，不以网页内部代码冒充馆藏编号。世界条目保留自己的区域，不硬套中国朝代。

## 断代与解释

展示优先采用馆方现行著录；约数和时代范围不是精确制作年。书画摹本与原作、后配与后加款、出土纪年与制作时间、发行始年与馆藏单件铸造年分开写。《韩熙载夜宴图》现存卷为宋摹本，归五代题材入口；《富春山居图》指无用师卷。二里头文化不直接等同夏王朝。马绍尔枝条图馆方断代延至20世纪初，作为跨展示边界实例保留，而不伪造1912截止年。

中国并立时期另补辽鸡冠壶、西夏铜牛、金代戏俑。世界选藏兼顾非洲、美洲、大洋洲的本地知识和生活；藏品流传、殖民掠夺与修复等有据内容在相关条目内说明。不把各地所有人的生活缩为宫廷器物，不随意使用“镇馆之宝”“一级文物”等称号。

馆方事实与本站赏鉴引导需区分。观看提示为观察线索，不是独立真伪鉴定或新考古结论。无法直接读取的官网页，在来源说明检索索引的读取方式；媒体报道、官方机构转载、馆方记录分别标记，不能统称全部为原始馆藏登记。

## 图片与许可

52件/组带明确许可实物图：原有23件，本次新增29件。来源包括克利夫兰艺术博物馆、大都会艺术博物馆、台北故宫开放资料及逐件核验的Wikimedia Commons照片。文件随站保存于`docs/assets/collections/`，不依赖外站热链加载。每张保留原始图链、摄影者credit、license、licenseUrl、sourceUrl、localUrl与范围说明；局部、半卷和单幅册页明确标注。本站不生成实物图，不用同型器、复制品或意绘冒充对应藏品。

许可与出处见各展签和`assets/collections/README.md`；本批身份核对见`image-completion-audit.json`。公开可浏览不等于允许转载，馆方所有照片也并非自动采用同一许可。仍有26件尚未核验到可公开使用的对应照片，见`image-status.md`，不把待补图说成网络加载故障。有图但加载失败时显示重试提示，保留展签和机构资料入口。

收藏与札记仍仅在读者自己的浏览器。新增资料按完整批次提交；若某个数据脚本加载失败，整批新增资料暂不启用，旧资料可用，新增ID对应收藏及札记保留，不因临时故障清除。

1933

苏区扩大与第五次反“围剿”危机

临时中央迁瑞金，川陕等根据地成长，中央红军取得第四次反“围剿”胜利。但反“罗明路线”、查田过左错误压制地方经验，第五次“围剿”开始后，错误军事指挥使中央苏区局面逐步恶化。

1月组织建设

临时中央迁入瑞金

地点 / 范围：上海、江西瑞金

由于上海秘密工作环境恶化，临时中央迁到中央苏区瑞金。中央机构同根据地领导机关更直接地集中，中央错误路线也进一步影响当地政治、土地和军事工作。迁移有安全原因，但其后决策成效仍需依据实际结果评价。

结果与历史联系中央领导机构与苏区更集中，错误路线对根据地的直接影响同时加深。

1月—2月军事活动

川陕根据地形成

地点 / 范围：四川通江、南江、巴中

红四方面军进入川北后，同地方组织和群众结合，发展通南巴等地区的革命根据地，建立苏维埃政权。新的区域为部队提供活动空间，也带来土地、征粮、政权管理等任务。根据地形成不能只理解为一次军事占领。

结果与历史联系在川北建立新的军政基地，红四方面军获得持续发展的地域条件。

1月17日统一战线

提出有条件联合抗日

地点 / 范围：莫斯科、中央苏区

中共驻共产国际代表团以苏维埃政府和红军军事机关名义提出，在停止进攻苏区、保障民主权利和武装民众等条件下，同其他武装订立抗日协定。与拒绝一切上层合作相比，政策出现调整，但离广泛抗日民族统一战线仍有距离。

结果与历史联系开始提出有条件的联合抗日办法，为后来更广泛统一战线积累政策探索。

2月—3月军事活动

第四次反“围剿”获胜

地点 / 范围：江西黄陂、草台岗等

红军集中主力进行大兵团伏击，在黄陂、草台岗等地打击国民党军，取得第四次反“围剿”胜利。战斗运用此前运动作战的经验，巩固中央苏区。胜利之后，党内关于军事路线和红军行动方向的分歧并未因此消失。

结果与历史联系中央苏区再次得到巩固，但胜利未能阻止其后错误军事路线的扩大。

2月起历史教训

反“罗明路线”扩大到苏区干部

地点 / 范围：福建、江西苏区

苏区中央局以所谓路线问题批判罗明，并把斗争扩大到江西的邓小平等干部，撤换职务或调离工作岗位。地方干部根据实际条件提出的意见受到压制。此类斗争削弱基层经验在决策中的作用，加重错误路线带来的组织损失。

结果与历史联系地方干部与实际意见受到压制，加剧中央错误路线造成的组织损失。

5月8日军事活动

红军总司令部成立

地点 / 范围：中央苏区

中国工农红军总司令部成立，朱德任总司令、周恩来任总政治委员。统一军事领导适应红军扩大和不同战区协调的需要。由于各根据地之间交通与通讯困难，组织名义上的统一同实际指挥条件仍存在差距。

结果与历史联系建立全国性红军总司令部，推动军事指挥与政治工作统一。

5月26日统一战线

察哈尔抗日同盟军成立

地点 / 范围：河北张家口、察哈尔

冯玉祥、吉鸿昌、方振武等组织察哈尔民众抗日同盟军，主张联合抗日、收复失地，中共派干部参与相关工作。运动后来遭内外压力而受挫。它反映共产党同其他爱国军事力量合作的探索，并非一支完全由中共统一指挥的部队。

6月起政策建设

查田运动及政策纠偏

地点 / 范围：中央苏区

中央苏区开展查田运动，试图进一步处理土地分配问题，但执行中出现严重扩大化和过左做法。政府随后提出土地斗争的具体规定，毛泽东起草农村阶级分析文件。土地革命的社会效果与政策误差，应当在同一历史过程中考察。

结果与历史联系查田中出现过左问题，中央政府通过政策文件尝试纠正阶级与土地处理错误。

6月30日、7月11日组织建设

确定八一建军纪念日

地点 / 范围：中央苏区

中央革命军事委员会决定将南昌起义的8月1日作为红军成立纪念日，随后经临时中央政府批准。纪念日的制度化发生在起义六年之后。了解这一时间差，有助于区分历史事件发生、军队组织沿革和后来纪念制度三个层次。

结果与历史联系南昌起义周年被正式制度化为建军纪念日，形成持续的军队纪念传统。

9月起历史教训

第五次“围剿”与错误军事指挥

地点 / 范围：江西中央苏区

国民党以堡垒推进等办法大规模进攻中央苏区。博古与李德等在军事指挥中采用不适合实际的单纯防御等办法，使红军失去机动优势、不断消耗。根据地缩小、兵员物资困难加剧，最终走向1934年的战略转移。

结果与历史联系单纯防御使红军与根据地不断消耗，直接推动次年的战略转移。

11月思想文献

长冈乡、才溪乡调查

地点 / 范围：江西兴国、福建上杭

毛泽东实地调查苏区基层政权、生产、群众生活与动员工作，形成长冈乡、才溪乡调查报告。调查把制度是否有效同当地群众实际处境相联系，既涉及支援战争，也涉及基层治理与经济建设，为此后总结政权工作提供材料。

结果与历史联系基层政权、民生和生产经验被带入中央讨论，为苏维埃工作总结提供事实材料。

1月8日历史人物

周恩来逝世

地点 / 范围：北京

周恩来因病逝世，社会各界广泛悼念。他长期担任政府总理，在外交、经济及国家日常运行中发挥重要作用，文革中努力维持部分正常工作和保护干部群众，逝世使国家领导工作遭受重大损失。

结果与历史联系对周恩来的悼念汇聚了人们对稳定、秩序和纠正文革错误的强烈愿望。

3月下旬—4月5日历史曲折

天安门悼念活动与四五运动

地点 / 范围：北京、南京等地

北京和其他城市群众以送花圈、写诗文等方式悼念周恩来，同时表达对四人帮的不满。天安门广场活动被错误定性为反革命事件并遭压制，许多参与者受追查，1978年中央和北京市委予以平反。

结果与历史联系群众活动显示社会反对文革错误的广泛情绪，成为转折前的重要政治信号。

4月7日党的建设

华国锋任总理、邓小平再遭撤职

地点 / 范围：北京

华国锋被任命为中共中央第一副主席、国务院总理；邓小平则因错误政治判断被撤销党内外一切职务。这一人事变化发生在天安门事件后，国家正常整顿进一步受到挫折。

结果与历史联系领导权重新调整，但文革错误并未因更换主持人而自行停止。

7月6日历史人物

朱德逝世

地点 / 范围：北京

朱德因病逝世，结束其长期参与人民军队和国家建设的生涯。他曾任红军总司令、八路军总指挥及全国人大常委会委员长等职，晚年在文革困难条件下仍关心军队和国家工作。

结果与历史联系国家和军队失去重要缔造者与领导人，军政机构面临连续的代际交替。

7月14日外交

坦赞铁路竣工交接

地点 / 范围：赞比亚、坦桑尼亚

中方援建的坦赞铁路举行交接仪式，铁路连接赞比亚铜矿地区与坦桑尼亚港口。勘测、施工、设备供应和技术培训经历多年协作，中非建设者在复杂自然环境中完成重要工程。

结果与历史联系铁路改善内陆交通并增强两国经济联系，成为中非合作的代表项目。

7月28日社会民生

唐山大地震

地点 / 范围：河北唐山、丰南等地

唐山和丰南地区发生强烈地震，造成二十四万余人死亡和大规模城市破坏。军队、医疗和各地救援力量投入抢救，幸存居民开展自救，之后经历漫长的住房、生产与城市重建。

结果与历史联系灾难促使人们更加重视抗震设防、公共救援和城市安全，也给众多家庭留下长期创伤。

9月9日历史人物

毛泽东逝世

地点 / 范围：北京

毛泽东因病逝世，全国举行悼念活动。作为中共、人民军队和新中国的重要缔造者，他在革命与建设中具有重大贡献，同时晚年发动文革造成严重错误，党对其评价后来区分历史贡献与晚年失误。

结果与历史联系逝世引发国家最高领导层重大变化，也使解决文革遗留问题进入新的政治条件。

10月6日党的建设

四人帮被粉碎

地点 / 范围：北京

中央政治局采取措施，对江青、张春桥、姚文元、王洪文实行审查，结束其继续争权和破坏正常工作的活动。全国随后广泛庆祝，持续十年的文化大革命由此结束，但纠正错误仍需进一步思想与制度努力。

结果与历史联系这一事件终止十年内乱，为恢复经济、平反冤案和后来改革开放创造必要前提。

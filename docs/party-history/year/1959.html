3月28日民族与统一

西藏地方政府被解散

地点 / 范围：西藏

拉萨发生武装冲突后，国务院下令解散西藏地方政府，由自治区筹备委员会行使其职权。中央随后推进民主改革，废除政教合一的封建农奴制度，土地和社会关系发生深刻变化，改革持续至1960年底基本完成。

结果与历史联系西藏治理体制与社会结构由此发生重大转变，中央与地方关系进入新的阶段。

4月18日—28日法治制度

刘少奇当选国家主席

地点 / 范围：北京

二届全国人大一次会议选举刘少奇为国家主席、朱德为全国人大常委会委员长，并决定周恩来继续任国务院总理。国家机关领导层调整是在1954年宪法框架下进行的，毛泽东不再担任国家主席。

结果与历史联系党的领导职务与国家职务进一步体现不同分工，刘少奇成为这一时期重要国家领导人。

7月2日—8月16日历史曲折

庐山会议转向错误批判

地点 / 范围：江西庐山

中央政治局扩大会议原拟总结大跃进经验，继续纠正左倾问题。彭德怀对浮夸和经济失误提出意见，却遭到错误批判；随后八届八中全会作出错误处理，会后全国开展反右倾斗争。

结果与历史联系对不同意见的压制阻碍纠错，进一步助长高指标和浮夸等问题，使经济困难加重。

9月17日法治制度

新中国首次特赦部分战犯

地点 / 范围：全国

刘少奇发布主席特赦令，对一部分经过改造的在押战犯等实行特赦。此后特赦分批进行，直到1975年处理完毕。这一安排体现惩办与改造政策，也使部分原国民党高级人员重新获得公民身份。

结果与历史联系特赦有利于落实统一战线政策，推动一部分原对立阵营人员转向和平社会生活。

9月26日经济建设

大庆油田被发现

地点 / 范围：黑龙江

地质勘探在松辽盆地取得重大突破，大庆油田发现。次年中央决定集中力量开展石油会战，钻井、运输、生产保障和地质研究协作推进，王进喜等石油工人成为建设的代表人物。

结果与历史联系大庆逐步成为中国重要石油生产基地，增强国内能源供给和工业建设的基础能力。

11月1日经济建设

第一拖拉机制造厂投产

地点 / 范围：河南洛阳

洛阳第一拖拉机制造厂建成投产，开始成批制造农业机械。拖拉机生产需要发动机、钢铁、机床和零部件协作，是工业化与农业技术改造相联系的项目，也为此后农业机械化积累设备和人才。

结果与历史联系农业生产开始获得更多国产动力机械支撑，但推广效果仍受经营制度和地方条件制约。

本年历史曲折

严重经济困难逐步显露

地点 / 范围：全国农村及城市

大跃进和公社化中的错误损害农业生产，加上自然灾害等因素，粮食减产、供应紧张和农村生活困难逐渐加剧。庐山会议后的反右倾又使许多批评难以提出，危机未能得到及时充分处理。

结果与历史联系1959—1961年出现严重经济困难和饥荒，人民生活及健康遭受重大损失，成为后来调整的重要背景。

2月22日—3月5日对外关系

组织利比亚撤侨

地点 / 范围：利比亚及周边海空通道

利比亚局势剧变后，中国政府组织船舶与飞机分批撤离在利中国人员，共撤出三万五千八百六十人。行动需要外交协调、运输保障和人员组织共同配合。撤离行动使用海上和航空等不同运输渠道，外交部门协调相关国家与企业，军地资源共同服务于海外公民安全保障。

结果与历史联系大规模撤侨显示经济全球化背景下海外利益保护需求上升。

2月25日法治制度

非物质文化遗产法通过

地点 / 范围：北京

全国人大常委会通过非物质文化遗产法，为传统技艺、表演、民俗等保护工作提供法律规范。文化保护从项目认定逐渐走向制度化管理。

结果与历史联系文化遗产不仅是器物建筑，也包含人群持续传承的知识与实践。

3月14日法治制度

宣布中国特色社会主义法律体系形成

地点 / 范围：北京

全国人大常委会工作报告宣布，以宪法为统帅、多个法律部门和不同层次规范构成的法律体系已经形成。该判断指制度框架的形成，不意味着所有法律实践问题均已解决。报告所说的体系由不同法律部门与法律行政法规地方性法规等层次构成，体系形成之后仍需继续修改和推进法律实施。

结果与历史联系国家法治工作从补齐主要制度转向完善体系与提高实施水平。

3月23日改革开放

分类推进事业单位改革

地点 / 范围：全国

中央和国务院发布分类推进事业单位改革意见，根据不同职能调整组织和管理方式。公共服务、行政职能和经营活动之间的边界成为改革重点。分类改革区分承担行政职能、从事生产经营和提供公益服务的单位，使不同性质组织采用不同管理安排，而非一律市场化。

结果与历史联系公共服务机构与行政、经营活动之间的职责边界进一步调整。

5月27日经济社会

新十年农村扶贫纲要发布

地点 / 范围：全国农村

中央和国务院发布二〇一一至二〇二〇年农村扶贫开发纲要，安排新阶段减贫任务。贫困问题由温饱改善进一步涉及能力、公共服务和地区发展。新纲要面向二〇二〇年设定周期和任务，扶贫重点由最基本温饱继续拓展到收入、基础设施、教育卫生与区域发展条件。

结果与历史联系为后来精准扶贫和脱贫攻坚的目标安排提供政策衔接。

地点 / 范围：北京

10月15日—18日科技文化

十七届六中全会讨论文化改革

地点 / 范围：北京

全会通过深化文化体制改革的决定，提出建设社会主义文化强国的任务。公共文化服务、文化产业和思想文化建设被纳入综合部署。决议将文化事业、产业、公共服务与体制改革共同讨论，既关注作品和市场，也关注群众获得文化服务的条件。

结果与历史联系文化建设被置于国家综合发展战略中，体制改革继续推进。

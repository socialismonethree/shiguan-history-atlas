1月历史曲折

上海夺权风潮扩散

地点 / 范围：上海及全国

上海造反组织在张春桥、姚文元等支持下夺取地方党政领导权，夺权风潮随后扩展到各地。大量领导干部受到冲击，正常党委和政府工作被破坏，革命委员会逐渐成为地方权力重组的形式。

结果与历史联系夺权加剧社会失序，党政机关的正常职责与程序难以维持，生产和公共服务受到影响。

2月前后历史曲折

老一辈领导人批评文革错误

地点 / 范围：北京

一些老一辈领导人在会议中反对任意打倒干部、冲击军队等错误做法，试图维护党政军正常工作。他们的批评被诬为二月逆流，受到压制和打击，纠正运动错误的努力遭到阻断。

结果与历史联系这说明文革期间并非没有反对错误的力量，但党内正常讨论已受到严重损害。

3月19日军事国防

军队承担三支两军任务

地点 / 范围：全国

中央军委部署军队参加支左、支农、支工、军管、军训，部队大量进入地方单位。军队试图维持生产和秩序，同时也被卷入派性纷争，地方党政职能与军队职责的边界受到冲击。

结果与历史联系军队临时代行和协助地方工作的范围扩大，反映正常国家治理体系遭破坏后的特殊状态。

6月17日科技教育

第一颗氢弹试验成功

地点 / 范围：中国核试验基地

中国完成第一颗氢弹空爆试验，核武器研制由原子弹进一步向热核武器突破。理论设计、工程研制和试验人员持续协作，许多工作在保密和艰苦条件下完成，成果建立在长期科学积累上。

结果与历史联系核技术能力进一步提高，体现科技队伍在动荡环境下坚持工作的努力。

7月历史曲折

武汉七二〇事件

地点 / 范围：湖北武汉

武汉地区群众组织派性冲突以及支左中的分歧发展为严重政治事件，中央来人和当地军队关系紧张，随后对军队与地方干部的批判扩大。事件反映文革中派性、夺权和军地关系相互激化。

结果与历史联系武斗和政治指控破坏城市治理与军事系统稳定，使全国混乱进一步升级。

8月历史曲折

武斗和冲击外交机关

地点 / 范围：北京及部分地区

全国多地发生武斗，部分激进组织冲击外交机关和外国驻华机构，严重违反外交规范。周恩来等努力维持对外事务和国家机关运转，但政治运动仍造成秩序混乱及人员安全风险。

结果与历史联系文革的破坏越出国内领域，损害中国外交信誉和国家正常对外关系。

9月5日外交

坦赞铁路建设协定签署

地点 / 范围：北京

中国、坦桑尼亚和赞比亚签订修建坦赞铁路的协定。中国承担勘测、施工、设备和人员培训等任务，工程跨越复杂地形，把非洲内陆地区同印度洋港口联系起来，后于1976年移交。

结果与历史联系这是中国援助非洲的重要大型项目，体现政治支持与基础设施合作相结合。

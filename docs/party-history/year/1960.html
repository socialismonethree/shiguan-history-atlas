1月7日—17日历史曲折

上海政治局扩大会议继续高指标

地点 / 范围：上海

会议讨论当年经济计划，仍以过高估计规定钢和粮食等指标，并设想加快人民公社所有制过渡。部分地区随后继续大办工业和水利，投入过量劳力和资源，农业生产及群众生活压力进一步增加。

结果与历史联系错误的形势判断延续了大跃进，推迟了全国经济转入全面调整的时间。

1月28日外交

中缅签订边界问题协定

地点 / 范围：北京

中缅签订边界问题协定及友好互不侵犯条约，随后于10月签订边界条约，通过谈判解决历史遗留边界问题。两国在主权、安全与邻里关系之间寻求可执行安排，形成相对稳定的边界框架。

结果与历史联系这是新中国与邻国通过谈判解决边界问题的重要先例，促进周边关系稳定。

3月22日经济建设

推广鞍钢企业管理经验

地点 / 范围：辽宁鞍山及全国

中央批转鞍山市委关于技术革新的报告，推广干部参加劳动、工人参加管理以及干部工人技术人员结合等做法。这种企业管理探索试图调动职工积极性，但实施效果仍受到当时政治动员环境影响。

结果与历史联系相关经验进入此后国营企业管理讨论，反映生产管理与职工参与之间的制度探索。

5月28日社会民生

紧急调运粮食应对供应危机

地点 / 范围：全国

北京、天津、上海和辽宁等地粮食库存紧张，中央发出紧急调运粮食指示，要求支援困难地区。调粮措施是在农业减产和城乡供应危机背景下采取的救急安排，同时还需调整口粮、生产和劳动力配置。

结果与历史联系文件显示经济困难已直接危及基本生活供应，粮食保障成为国家工作的紧急重点。

7月5日—8月10日经济建设

北戴河会议讨论经济调整

地点 / 范围：河北北戴河

中央工作会议研究工业、交通与农业困难，提出压缩基本建设、清理劳动力并加强农业等措施。对高指标和资源分散的修正开始进入计划安排，但当时仍存在保钢等压力，政策转向并不彻底。

结果与历史联系会议为后来八字方针的形成提供了政策准备，反映中央逐步认识经济失衡。

8月19日经济建设

压缩基本建设战线

地点 / 范围：全国

中央批准有关建设项目调整报告，对重点项目以外的工程采取停建、缓建和限制新开工等办法。国家试图把分散资金、材料和劳力集中到急需领域，以减轻基建规模过大对生产和供应的挤压。

结果与历史联系缩短建设战线是降低积累强度、恢复部门平衡的具体措施，后来成为全面调整的重要内容。

11月3日经济建设

人民公社紧急指示信发布

地点 / 范围：全国农村

中央发布有关农村人民公社政策的紧急指示，要求纠正无偿平调财物等做法，稳定所有制关系，允许保留自留地和家庭副业，节省劳力加强农业生产，试图恢复基层生产和生活秩序。

结果与历史联系指示为纠正共产风提供政策依据，也为随后农业六十条制定打开空间。

11月15日历史曲折

要求纠正农村五风

地点 / 范围：全国农村

中央要求纠正共产风、浮夸风、命令风、干部特殊化和瞎指挥生产等问题，并以反对无偿平调为重点。措施针对生产资料及劳动成果被随意调拨、基层事实被掩盖等现象，触及此前运动中的具体失误。

结果与历史联系对五风的纠正有助于恢复集体和农户的合理利益关系，但执行仍经历曲折。

12月24日—翌年1月13日经济建设

中央工作会议准备全面调整

地点 / 范围：北京

会议讨论1961年经济计划和农村政策，重新强调调查实际情况、承认错误以及放慢过急的建设速度。会议针对一平二调和共产风展开检讨，为八届九中全会确定经济调整方针作准备。

结果与历史联系政策开始由持续跃进转向恢复秩序与经济比例，为走出困难建立条件。

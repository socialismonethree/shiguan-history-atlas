1921

建党与工农组织的起步

这一年可从建党前的思想选择、一大建立全国组织和最初工农运动三条线索阅读。早期力量很小，公开宣传、秘密组织与群众工作相互结合；7月23日开幕与后来设立的7月1日纪念日须明确区分。

1月思想文献

新民学会讨论改造道路

地点 / 范围：长沙

新民学会在新年聚会中集中讨论中国与世界的改造方法。毛泽东把共产主义同改良主义、无政府主义等方案加以比较，表明其政治选择正在明确。讨论发生在各地共产党早期组织相互联络、筹备全国性政党的背景下。

结果与历史联系新民学会部分成员进一步明确共产主义选择，为湖南早期党组织和建党活动积累思想基础。

6月组织建设

马林抵沪与建党联络

地点 / 范围：上海

共产国际代表马林到达上海，与尼克尔斯基以及主持当地早期组织工作的李达、李汉俊接触，了解筹党进展，并推动召开全国代表大会。中国早期共产党组织间的联络因此同共产国际的活动发生更直接的联系。

结果与历史联系使各地建党筹备同共产国际建立更直接联系，推动全国代表大会的召开。

7月23日党的会议

中共一大开幕

地点 / 范围：上海、嘉兴

来自各地及旅日早期组织的代表在上海开会，末次会议移至嘉兴南湖。大会通过纲领和工作决议，产生以陈独秀为书记的中央局，建立全国性政党组织。陈独秀、李大钊本人没有出席。7月1日是后来确定的成立纪念日，不是此次开幕日。

结果与历史联系建立全国性政党和中央领导机构，把分散早期组织联结为中国共产党。

8月11日工农运动

劳动组合书记部成立

地点 / 范围：上海

中共设立中国劳动组合书记部，以公开机构形式联络和组织工人。此后在多地设分部，结合工人补习教育、报刊宣传和工会组织开展活动。成立不久的党由讨论纲领进入更持续的工人运动实践，逐渐建立公开与秘密工作相配合的方式。

结果与历史联系形成公开组织工人运动的机构，推动教育、宣传与工会建设结合。

9月27日工农运动

衙前农民组织建立

地点 / 范围：浙江萧山衙前

浙江萧山衙前召开农民大会，形成新型农民组织并公布章程、宣言。运动随后向邻近村庄扩展，涉及租税与乡村权力关系，也遭到地方势力和军警压制。这条线索表明，早期中共相关群众工作并不限于城市工厂和铁路。

结果与历史联系扩大农村群众自我组织的实践，成为后来农民运动的重要早期线索。

10月13日工农运动

粤汉铁路工人罢工

地点 / 范围：武汉、长沙

粤汉铁路武昌、长沙区段工人在武汉党组织推动下罢工，要求改善工资和生活待遇。铁路把多个城市的劳动者联系在同一交通系统中，工会组织、联络与集体行动由此成为党开展工人工作的重要实践领域。

结果与历史联系铁路工人的联合行动扩大，为跨地区工会组织积累经验。

10月25日工农运动

上海英美烟厂工人罢工

地点 / 范围：上海

上海英美烟厂工人为反对厂方开除和欺压工人而罢工，中国劳动组合书记部参与领导。参与者以工厂为依托提出集体诉求，运动展现外资企业劳动关系的矛盾，也使新成立的工人工作机构接受实际组织能力的检验。

结果与历史联系使新成立的劳动组合书记部介入大型工厂劳动冲突，扩大工人组织网络。

11月组织建设

陇海铁路罢工与中央组织部署

地点 / 范围：陇海铁路沿线、上海

陇海铁路机务工人反对裁员减薪，引发沿线工人的响应。同月，中央局向各地部署发展党员、成立区执行委员会、联系工会和出版宣传读物等任务，为次年代表大会作准备。早期组织扩展与群众运动是在同一时期并行推进的。

结果与历史联系罢工发展与中央组织部署并行，推动各区组织、工会和宣传工作制度化。

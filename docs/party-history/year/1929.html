1929

中央苏区前身与军队建设原则

红四军转战赣南、闽西，土地法与地方组织随实践调整。中央九月来信和古田会议讨论党与军队的关系，百色起义扩展广西斗争。陈独秀被开除党籍，也提示创建者的历史贡献与后续政治经历需要分开考察。

1月14日军事活动

红四军主力进军赣南

地点 / 范围：井冈山至赣南、闽西

为应对敌军进攻和给养困难，红四军主力离开井冈山，进入赣南、闽西，依托地方党组织与武装开辟新的根据地。两地后来连成中央革命根据地。井冈山经验因此向更广大区域发展，也面对新的社会和军事条件。

结果与历史联系赣南、闽西根据地逐步连接，成为后来中央革命根据地的主要基础。

4月政策建设

兴国《土地法》调整分配规定

地点 / 范围：江西兴国

毛泽东主持制定兴国土地法，把井冈山土地法中没收一切土地的规定，调整为没收地主土地及公共土地。修改来自当地斗争经验及党内政策讨论，反映土地革命在动员、生产与不同农民阶层利益之间不断摸索。

结果与历史联系调整没收范围，使土地政策更符合当时的实际阶层关系和动员需要。

5月军事活动

商南起义与豫东南根据地

地点 / 范围：河南商城南部

河南商城南部农民在地方党组织领导下起义，组成红军部队，并在艰苦环境中发展豫东南根据地。此后当地力量同鄂东、皖西革命武装逐步发生更紧密联系，为鄂豫皖根据地的形成提供地方基础。

结果与历史联系起义建立红军部队并发展豫东南根据地，为鄂豫皖地区整合提供力量。

6月下旬—7月初党的会议

六届二中全会

地点 / 范围：上海

中共中央在上海召开全会，讨论六大以来的工作，部署土地革命、游击战争、红军与苏区建设，也要求恢复白区的公开和秘密工作。会议反映中共同时处理农村军事发展和城市地下工作两类不同环境的问题。

结果与历史联系中央同时部署农村苏区和城市地下工作，维持两类环境中的组织活动。

9月28日组织建设

中央九月来信指导红四军

地点 / 范围：上海、闽西

中共中央向红四军前委发出指示信，陈毅参与起草、周恩来审定，讨论红军任务、党的领导和军队建设问题。来信肯定农村武装发展的意义，为解决红四军内部思想与组织分歧提供指导，随后成为古田会议的重要依据。

结果与历史联系为红四军解决思想组织分歧提供中央指导，直接推动古田会议形成。

11月15日组织建设

陈独秀被开除党籍

地点 / 范围：上海

陈独秀在大革命失败后与中央的政治分歧继续扩大，并转向托洛茨基主义、参与相应组织活动。中央政治局通过开除其党籍的决议。对这位主要创建者的认识，需要把早期贡献、革命后期的领导错误和之后政治选择分开考察。

结果与历史联系陈独秀与中共组织关系终止，创建贡献和此后不同政治活动形成历史区分。

12月11日军事活动

百色起义

地点 / 范围：广西百色、右江地区

中共代表与广西地方革命力量领导武装起义，建立红七军和右江苏维埃政权。当地农民运动与部分军队转变相结合，推动左右江革命根据地发展。1930年龙州起义又形成红八军，构成广西土地革命的重要脉络。

结果与历史联系红七军和右江政权形成，使广西成为土地革命与红军发展的重要区域。

12月28日—29日党的会议

古田会议

地点 / 范围：福建上杭古田

红四军第九次党代表大会总结部队建设经验，通过纠正党内错误思想等决议，强调思想建党和政治建军。毛泽东重新担任前委书记。会议处理的不仅是作战方法，更包括军队为何而战、党组织怎样领导以及如何克服旧军队习气。

结果与历史联系确立思想建党、政治建军原则，对党领导人民军队的组织建设产生长期影响。

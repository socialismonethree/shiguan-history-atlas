4月10日思想文化

邓小平来信反对机械照搬指示

地点 / 范围：北京

邓小平致信中央，针对两个凡是提出应完整、准确理解毛泽东思想，而不能拘泥于个别指示。信件后来转发全党，反映纠正文革错误必须首先突破思想僵化和个人崇拜的限制。

结果与历史联系这一主张为真理标准讨论及重新确立实事求是思想路线提供重要准备。

7月16日—21日党的建设

邓小平恢复领导职务

地点 / 范围：北京

十届三中全会决定恢复邓小平中共中央副主席、中央军委副主席、国务院副总理等职务，并追认华国锋担任中央主席和军委主席。邓小平随后重点推动科学教育、干部政策和经济工作。

结果与历史联系其恢复工作增强拨乱反正力量，为教育科研恢复及1978年重大转折创造条件。

8月4日—8日科技教育

科学和教育工作座谈会

地点 / 范围：北京

邓小平主持座谈，批评把文革前教育和科技工作全盘否定的错误估计，要求尊重知识、人才与教学科研规律。讨论推动恢复考试招生和科研秩序，专业人员的意见重新获得表达空间。

结果与历史联系会议是恢复高考和科教政策调整的重要先导，改变长期政治化评价造成的束缚。

8月10日社会民生

部分低工资职工调整工资

地点 / 范围：全国

国务院决定对部分低工资职工调整工资，建立在生产恢复和财政开始好转的条件上。长期工资冻结和物价、家庭负担问题受到关注，收入政策开始成为恢复正常经济生活的一部分。

结果与历史联系工资调整回应群众生活需求，也表明国家建设正重新重视劳动报酬与生产积极性。

8月12日—18日党的建设

中共十一大召开

地点 / 范围：北京

大会宣布文化大革命已经结束，重申四个现代化目标，并产生新的中央委员会。但大会未能根本纠正文革理论和政治路线中的错误，继续革命等旧提法仍然保留。

结果与历史联系十一大处于由结束动乱走向全面转折的过渡期，其进展和局限需要同时说明。

9月18日科技教育

部署恢复科研机构与职称

地点 / 范围：全国

中央通知召开全国科学大会，要求落实知识分子政策、恢复被撤科研机构及技术职称，建立考核和岗位责任制度。一些长期受压抑的研究人员重新获得工作机会，科研组织秩序逐步重建。

结果与历史联系制度恢复改善科研环境，为1978年科学大会和现代化议程提供基础。

10月5日—12日科技教育

决定恢复高考制度

地点 / 范围：全国

中央政治局原则批准高校招生意见，国务院随后批转，恢复自愿报名、统一考试和择优录取。各地于11月至12月组织考试，约五百七十万人报考，二十七万余人录取，大量青年重新获得上大学机会。

结果与历史联系高考重建改变一代人命运，也为改革开放培养亟需的专业人才。

10月5日党的建设

党校系统恢复办学

地点 / 范围：全国党校

中央作出办好各级党校的决定，文革中停办或受冲击的党校逐渐恢复。干部理论学习、政策研讨与培训重新成为常设工作，中央党校后来也成为真理标准讨论和思想解放的重要阵地。

结果与历史联系干部教育重回制度轨道，推动重新学习历史经验并培养现代化建设需要的干部。

12月10日党的建设

胡耀邦任中央组织部部长

地点 / 范围：北京

胡耀邦出任中央组织部部长，开始推动落实干部政策和复查历史案件，强调依据事实处理问题。组织系统对被错整干部的甄别逐步扩大，为大规模平反冤假错案和恢复人才工作创造条件。

结果与历史联系干部政策转变直接关系国家治理与社会信任，是拨乱反正不可缺少的组成部分。

2月7日改革开放

注册资本登记制度改革

地点 / 范围：全国

国务院发布改革方案，将企业注册资本登记从实缴制改为认缴制，企业年检转向年报公示。改革降低部分市场准入门槛，同时要求通过信息公示和后续监管维护交易秩序，避免把登记便利误解为免除经营责任。

结果与历史联系企业设立方式与政府监管机制发生调整，推动商事制度改革继续深化。

2月21日经济社会

统一城乡居民养老保险

地点 / 范围：全国

国务院发布建立统一城乡居民基本养老保险制度的意见，把此前分别开展的城乡居民养老保险探索衔接起来。社会保障开始减少城乡制度分割，覆盖范围扩大也对资金筹集、待遇和持续运行提出要求。

结果与历史联系养老保障从扩大覆盖进一步转向制度整合，为居民流动与长期保障提供条件。

2月26日经济社会

提出京津冀协同发展战略

地点 / 范围：北京、天津、河北

习近平主持听取京津冀协同发展汇报，提出把三地协同发展作为国家战略。区域发展不再只看单个城市扩张，而是涉及功能疏解、产业布局、交通联系和生态环境等相互关联的问题。

结果与历史联系跨行政区协调成为城市群发展和区域治理的重要路径。

2月27日法治制度

确定抗战纪念日与南京大屠杀公祭日

地点 / 范围：北京

全国人大常委会决定将九月三日确定为抗战胜利纪念日，将十二月十三日设为南京大屠杀死难者国家公祭日。国家通过固定日期组织纪念，将战争胜利、受难者记忆与公共历史教育纳入制度安排。

结果与历史联系战争记忆获得持续的国家纪念形式，也推动相关史料与历史现场的公共传播。

3月19日法治制度

深化司法体制改革

地点 / 范围：全国

两办发布司法和社会体制改革意见，涉及司法人员分类管理、司法责任、职业保障及省以下地方法院检察院人财物管理。改革试图调整司法组织运行与责任承担之间的关系，并减少不适当的地方干预条件。

结果与历史联系法治建设从制定法律进一步深入到司法机构如何运行和承担责任。

4月24日法治制度

环境保护法修订

地点 / 范围：北京

全国人大常委会通过修订后的环境保护法，在原有法律基础上强化环境治理制度。经济规模扩大、污染问题与公众健康需求，使环境监管、违法责任和社会参与成为更加迫切的法律议题。

结果与历史联系环境保护逐步由发展中的附属事项转向更有约束力的治理要求。

6月30日改革开放

深化财税体制改革方案

地点 / 范围：北京

中央政治局审议通过财税体制改革总体方案，重点涉及预算管理、税收制度以及事权和支出责任关系。改革试图使国家治理任务与财政资源配置相匹配，而不仅是改变某个税种的征收比例。

结果与历史联系现代财政制度成为国家治理的重要支撑，中央地方关系也进一步纳入改革。

7月24日经济社会

推进户籍制度改革

地点 / 范围：全国

国务院发布进一步推进户籍制度改革意见，回应农业转移人口进入城镇后的落户与服务问题。城镇化不再只是人口空间转移，也涉及教育、社保、住房和公共服务资格的制度衔接。政策推进后，农业转移人口落户成为十三五时期明确的城镇化任务之一。

结果与历史联系户籍改革把城市发展与人的市民化联系起来，对城乡公共服务布局产生长期影响。

地点 / 范围：北京

全会专题研究全面推进依法治国，通过相关决定，提出建设中国特色社会主义法治体系和法治国家的总目标。部署覆盖立法、执法、司法和守法等环节，并把法治与国家治理能力联系起来。

结果与历史联系法治被纳入全面改革的整体布局，重点由法律数量进一步延伸至制度实施。

11月1日法治制度

设立国家宪法日

地点 / 范围：北京

全国人大常委会决定将十二月四日设为国家宪法日，与一九八二年现行宪法通过日期相联系。国家通过纪念、宣传和教育强调宪法地位，但宪法实施仍有持续的制度与实践任务。纪念日安排也与宪法宣传、法律教育和国家机构工作中的宪法意识建设相联系。

结果与历史联系宪法教育获得固定公共时间节点，法治意识传播有了新的制度载体。

11月6日改革开放

推动农村土地经营权有序流转

地点 / 范围：全国农村

两办发布土地经营权流转与适度规模经营的意见，在稳定承包关系的同时探索经营方式变化。农村劳动力转移、农业技术和经营规模需求，使土地所有、承包和经营关系需要更细致的制度安排。

结果与历史联系为后来农村土地“三权分置”政策进一步展开提供了实践和政策基础。

11月11日、17日改革开放

APEC北京会议与沪港通

地点 / 范围：北京、上海、香港

亚太经合组织领导人会议在北京举行，决定启动亚太自由贸易区进程；同月沪港通正式启动，推动两地股票市场互联互通。区域贸易合作与资本市场开放通过不同机制同时推进。两项开放分别面向贸易规则与证券投资，运行机制和参与对象并不相同。

结果与历史联系开放由贸易和直接投资继续扩展到金融市场与区域规则协调。

12月5日党的建设

周永康被开除党籍

地点 / 范围：全国

中央决定给予周永康开除党籍处分，这是十八大后查处高级干部严重违纪违法案件的重要节点。同一时期多个省军级以上干部案件受到审查，巡视、纪律与司法处理之间形成更紧密衔接。

结果与历史联系反腐败触及高级领导干部，对权力监督和干部队伍产生重要影响。

局部反攻与战后政治准备

豫湘桂正面战场严重失利，中共向河南等敌后地区扩展并开展局部反攻。美军观察组来延安，对外联络增多；六届七中全会总结历史并筹备七大，民主联合政府主张则把战后政治安排提上公开议程。

3月12日统一战线

周恩来讨论宪政与团结

地点 / 范围：延安

周恩来在纪念孙中山逝世的会议上讨论宪政、民主与抗日团结，主张把政治制度改进落实为实际权利，而非停留于承诺。国统区社会对政治改革的要求日益增长，中共的主张同这一民主运动发生联系。

结果与历史联系为后来民主联合政府主张铺垫，连接抗日合作和战后政治安排。

4月—11月历史转折

豫湘桂战役与中共敌后部署

地点 / 范围：河南、湖南、广西

日军发动大规模进攻，国民党正面军队在豫湘桂战场遭严重失败，大片地区陷落。中共中央要求在河南等地组织抗日游击队、进入敌后建立根据地。正面溃退加剧民族危机，也促使中共调整中原地区的军事和政治布局。

结果与历史联系1944年的抗战形势并非全面顺利，局部反攻与正面严重失利同时存在。

5月21日起党的会议

六届七中全会开幕

地点 / 范围：延安

扩大的中央全会开始举行，由主席团处理日常工作，讨论党史经验和七大筹备，会议延续至1945年4月。其长时段程序包含多次会议和文件讨论。不能把翌年通过的历史决议全部提前到1944年开幕时。

结果与历史联系为七大准备组织与思想条件，并形成总结历史问题的共同认识。

6月5日组织建设

城市工作与根据地并重

地点 / 范围：各党组织

中央要求把城市工作和根据地工作视为相互配合的任务，发展交通、情报、群众和地下组织，准备在条件成熟时内外呼应。敌后农村的扩大并未消除夺取大城市、恢复城市社会联系的需要，相关干部与机构因此得到加强。

结果与历史联系为抗战后期和解放战争中的接管城市准备组织网络。

7月—8月国际联系

美军观察组进驻延安

地点 / 范围：延安

美军观察组分批抵达延安，考察敌后抗战、军事情报和中共情况，双方展开接触。此前中外记者也来访，延安对外信息渠道扩大。来访不等于美国已同中共建立正式外交关系，其军事观察和政策争论有明确边界。

结果与历史联系增加中共同外部世界的直接联系，为战时外交实践提供经验。

7月—10月军事活动

向河南敌后发展

地点 / 范围：豫东、豫中、豫西

八路军、新四军先后进入河南敌后，恢复和建立根据地，争取连接华北、华中与陕北。部队要在日军进攻造成的破坏中重新组织群众、发展地方武装。彭雪枫在这一过程中牺牲，战略展开伴随着人员和组织代价。

结果与历史联系加强中原地区战略联系，为后来全国军事布局奠定基础。

9月15日统一战线

提出民主联合政府主张

地点 / 范围：重庆

林伯渠在国民参政会上提出结束一党统治、建立各抗日党派民主联合政府的主张。战后政权安排由此成为公开政治议程。中共借统一战线和参政平台争取其他党派与社会人士支持，要求战争合作进一步转向政治民主化。

结果与历史联系为七大《论联合政府》和1945年政治谈判提供直接承接。

9月思想文献

《为人民服务》讲演

地点 / 范围：陕北延安

中央警备团战士张思德在烧炭工作中牺牲，毛泽东在追悼会上讨论为人民工作的意义。事迹发生在战时后勤劳动中，而不是前线冲锋。讲演把普通战士与日常工作纳入对政党宗旨和公共责任的说明。

结果与历史联系后来成为重要的政治教育文本，使后勤劳动者进入党史人物叙述。

11月军事活动

八路军南下支队出发

地点 / 范围：延安至豫鄂湘粤

以三五九旅主力为基础的南下支队，带领部分南方工作干部离开延安，向中原和华南敌后发展。任务既包括军事行动，也包括开辟根据地与地方组织工作。长距离行军需要同沿途抗日力量联络，面临日伪和国民党军多重压力。

结果与历史联系将西北、中原与华南的斗争联系起来，扩展抗战后期战略布局。

3月5日民族与统一

广西僮族自治区成立

地点 / 范围：广西

广西僮族自治区正式成立，民族区域自治制度继续展开。自治区名称在1965年改为广西壮族自治区，阅读历史文件时应保留当时名称并说明后来的规范变化，而不以现名改写全部史料。

结果与历史联系自治区成立是地方国家制度建设的重要环节，其时间与宁夏、西藏等地不同。

4月7日社会民生

部署全国大规模造林

地点 / 范围：全国

中央和国务院要求发展造林事业，将林业与水土保持、农业生产和防护体系联系起来。此后各地组织植树造林；具体成效需根据存活率、管护及地方环境判断，不能仅按动员人数衡量。

结果与历史联系造林同时涉及生产资源与生态条件，反映国家建设中环境治理的早期实践。

4月22日思想文化

人民英雄纪念碑建成

地点 / 范围：北京天安门广场

纪念碑在天安门广场落成，以建筑、碑文和浮雕纪念近代以来为民族独立与人民解放牺牲的人们。它把不同历史时期的斗争纳入公共纪念空间，成为国家仪式与历史教育的重要地点。

结果与历史联系纪念碑不仅是建筑作品，也是观察国家如何组织公共历史记忆的实物资料。

5月5日—23日历史曲折

八大二次会议与大跃进

地点 / 范围：北京

八大二次会议通过建设总路线，随后大跃进在全国展开。高速度期待逐渐脱离生产条件，工农业指标层层抬高，经济决策中过度依赖政治动员，客观规律和实际资源约束被忽视。

结果与历史联系1981年历史决议把急于求成和左倾错误作为这一阶段严重挫折的重要原因。

8月17日—30日历史曲折

北戴河会议后公社化迅速扩展

地点 / 范围：河北北戴河及全国

中央政治局扩大会议后，大炼钢铁与农村人民公社化迅速形成高潮。高指标、生产瞎指挥、浮夸和共产风广泛出现，劳动、粮食及其他资源的组织方式被激烈改变，给工农业生产造成严重扰动。

结果与历史联系这不是单纯增加合作规模，而是超越当时生产力条件的制度与动员失误。

9月2日思想文化

北京电视台正式开播

地点 / 范围：北京

北京电视台正式播出节目，成为中国电视事业的早期起点。电视在当时尚未普及到普通家庭，但电子工业、传播技术和公共文化呈现形式开始出现新的结合，后于1978年改名中央电视台。

结果与历史联系正式开播、此前试播和后来改名是不同节点，不能把中国电视史起点写成1978年。

10月25日民族与统一

宁夏回族自治区成立

地点 / 范围：宁夏

宁夏回族自治区正式成立，自治区机关开始按照民族区域自治制度运行。地方建设需要统筹民族关系、农业灌溉、交通和干部培养等事务，制度设立与经济社会发展是持续的历史过程。

结果与历史联系同年广西与宁夏分别成立自治区，反映民族区域自治在不同地区的具体展开。

11月2日—10日历史曲折

第一次郑州会议开始纠偏

地点 / 范围：河南郑州

中央工作会议讨论人民公社化中的问题，开始区分社会主义与共产主义、集体所有与全民所有等关系。此后又有一系列会议试图纠正已经显露的过急做法，但纠偏尚未触及全部错误。

结果与历史联系应看到当年已出现修正尝试，也要说明错误继续发展，不能把开会等同于问题解决。

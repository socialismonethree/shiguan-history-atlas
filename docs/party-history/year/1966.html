2月7日思想文化

焦裕禄事迹广泛传播

地点 / 范围：河南兰考及全国

新华社播发介绍焦裕禄的通讯，他在兰考调查灾情、治理风沙盐碱内涝及关心群众生活的实践得到全国关注。焦裕禄已经于1964年病逝，1966年是其事迹广泛传播的年份，并非任职或逝世年份。

结果与历史联系焦裕禄成为县级干部服务群众的典型，影响此后长期的党性和干部作风教育。

3月8日、22日社会民生

邢台地震与抗震救灾

地点 / 范围：河北邢台

邢台地区接连发生强烈地震，造成严重人员伤亡和房屋破坏。中央和地方组织救援，部队、医务人员及各地物资赶赴灾区，周恩来参与指导救灾，并推动加强地震监测与研究。

结果与历史联系地震促使抗灾救援与地震科学研究受到重视，体现防灾工作需要长期公共投入。

5月4日—26日历史曲折

五一六通知通过

地点 / 范围：北京

中央政治局扩大会议通过五一六通知，以错误的阶级斗争判断和所谓防止资本主义复辟理论发动文化大革命。中央文革小组随后形成，原有党政组织和正常议事程序受到严重冲击。

结果与历史联系1981年历史决议否定文化大革命，将其定性为由领导者错误发动、被反革命集团利用的内乱。

7月1日军事国防

第二炮兵领导机构成立

地点 / 范围：北京及有关部队

人民解放军第二炮兵领导机构成立，战略导弹部队建设进入统一组织的新阶段。部队需要把导弹技术、训练、工程保障和指挥管理相结合，形成与常规部队不同的专业体系。

结果与历史联系这一设置有利于战略导弹力量发展，是国防现代化和核威慑体系形成的重要环节。

8月起历史曲折

红卫兵运动与破四旧冲击社会

地点 / 范围：北京及全国

红卫兵组织大量出现，大串联和破四旧迅速扩展。一批干部、教师、知识分子及普通居民遭批斗殴打，文物和私人财产受到毁坏，学校正常教学中断。暴力与个人崇拜在运动中相互强化。

结果与历史联系社会基本权利、教育秩序和文化遗产遭受巨大损害，是文革灾难的重要组成部分。

8月1日—12日历史曲折

八届十一中全会通过文革决定

地点 / 范围：北京

全会通过有关无产阶级文化大革命的决定，进一步推动运动在全国展开，党内领导机构也发生变化。对干部和知识分子的冲击日益扩大，批斗与组织失序迅速影响学校、工厂和国家机关。

结果与历史联系会议把严重错误转化为全国性政治行动，正常政治和社会秩序遭受系统性破坏。

10月27日科技教育

导弹核武器结合试验成功

地点 / 范围：中国有关试验地区

中国完成装有核弹头的地地导弹飞行爆炸试验，将核装置同运载系统结合验证。成果来自此前多年在核武器、火箭、制导及试验保障等方面的科研积累，相关人员在政治动荡中仍坚持工作。

结果与历史联系中国战略核力量形成进一步技术基础，成果不能归功于对科研与人才造成伤害的政治动乱。

1月3日经济社会

整合城乡居民基本医保

地点 / 范围：全国

国务院发布整合城乡居民基本医疗保险制度的意见，将城镇居民医保与新农合衔接为统一居民保障制度。改革试图减少城乡待遇与管理分割，提高参保、结算和公共服务的一致性。参保对象覆盖城乡居民，职工医保则仍属于不同的基本保障制度安排。

结果与历史联系医保建设从扩大人群覆盖进一步转向跨城乡制度整合。

1月5日经济社会

长江经济带强调生态优先

地点 / 范围：重庆、长江流域

习近平在推动长江经济带发展座谈会上提出把生态修复和环境保护放在重要位置。沿江开发由单纯追求项目和产业增长，转向统筹流域生态、交通、城市和产业布局的综合发展。长江经济带的规划随后发布，流域保护与跨区域产业交通协同进一步展开。

结果与历史联系长江流域发展战略更加明确生态约束，跨区域治理的重要性上升。

2月24日党的建设

部署“两学一做”学习教育

地点 / 范围：全国

中央办公厅印发面向全体党员的学习教育方案，内容涉及党章党规、系列讲话和合格党员实践。对象由领导干部进一步扩展到广大党员，翌年又部署常态化制度化。学习教育面向全体党员，体现党内教育由集中安排向经常性组织生活延伸。

结果与历史联系党内教育从阶段性集中活动进一步连接党员日常组织生活。

3月23日对外关系

澜湄合作机制启动

地点 / 范围：海南三亚

澜沧江湄公河合作首次领导人会议召开，正式启动相关合作机制。流域国家围绕发展与共同事务开展协调，交通、经贸、资源和民生等议题具有跨境联系。合作以跨境流域为共同地理基础，使发展项目与邻国关系获得具体协调平台。

结果与历史联系区域合作由国家间一般交往进一步落实到具体流域和发展问题。

4月22日对外关系

中国签署巴黎协定

地点 / 范围：国际气候合作场合

中国签署气候变化巴黎协定，参与全球气候治理的新制度安排。协定下的国家行动与国内能源、产业和环境政策相联系，签署本身并不意味着减排转型任务已经完成。国际气候责任与国家自主行动相结合，能源和经济结构调整成为后续重点。

结果与历史联系气候政策在国际承诺与国内发展转型之间建立更紧密联系。

6月20日科技文化

神威太湖之光获超算第一

地点 / 范围：中国无锡

采用国产处理器构建的神威太湖之光超级计算机在世界超级计算机排名中位居第一。系统既需要处理器与互联技术，也需要软件和应用能力，体现高性能计算领域的长期团队研发。超算排名反映特定测试性能，科学应用和软件体系建设仍是持续任务。

结果与历史联系为科学计算和工程模拟提供基础能力，同时推动自主软硬件体系发展。

7月8日党的建设

问责条例出台

地点 / 范围：全国

中央印发中国共产党问责条例，对党组织和领导干部失职失责的责任追究作制度安排。监督不仅关注个人廉洁，也涉及领导责任、决策落实及工作失误带来的后果。对履职责任的监督与个人违纪查处相配合，问责范围进一步明确。

结果与历史联系全面从严治党进一步从行为规范延伸到履职责任约束。

8月16日科技文化

墨子号量子科学实验卫星发射

地点 / 范围：中国

中国发射量子科学实验卫星墨子号，为在轨量子通信与基础物理实验提供平台。发射成功只是任务起点，后续卫星地面量子实验成果在二〇一七年陆续取得。翌年卫星地面之间的量子实验取得新结果，发射与实验成果在不同年份发生。

结果与历史联系基础科学研究与航天工程结合，为新型信息技术探索提供实验条件。

8月19日—20日经济社会

全国卫生与健康大会

地点 / 范围：北京

全国卫生与健康大会把人民健康放在发展优先位置，随后中央和国务院发布健康中国二〇三〇规划纲要。政策覆盖防病、医疗、健康环境和全生命周期服务，不只关注医院治病。健康中国规划进一步把预防、治疗、康复和健康环境放在长期目标中安排。

结果与历史联系公共卫生与健康服务从单一医疗问题扩展为综合发展目标。

9月25日科技文化

FAST射电望远镜落成启动

地点 / 范围：贵州平塘

五百米口径球面射电望远镜FAST落成启动，为脉冲星、射电天文等研究提供大型科学装置。设施建成后还需调试、观测和数据分析，科学发现并非在落成当天全部完成。大型装置的建设与运行连接精密工程、数据处理和天文科研人员协作。

结果与历史联系重大基础设施扩展中国天文研究能力，并带动精密工程和人才培养。

10月1日对外关系

人民币加入特别提款权货币篮子

地点 / 范围：国际货币基金组织

人民币正式加入国际货币基金组织特别提款权货币篮子。此举反映人民币在国际贸易和金融使用中的地位变化，也与中国金融开放、汇率机制和国际制度参与相联系。加入货币篮子涉及国际储备资产安排，并不是废除国内金融监管的决定。

结果与历史联系人民币国际化获得重要制度节点，但不等于资本账户完全开放。

11月7日、28日法治制度

网络安全立法与河长制部署

地点 / 范围：全国

全国人大常委会通过网络安全法，两办同月部署全面推行河长制。网络空间和河流水环境虽属不同领域，都通过明确责任与制度规范回应跨部门、跨区域治理难题。前者针对网络活动规则，后者以流域责任落实推动河湖治理，两者各有实施体系。

结果与历史联系国家治理规则进一步扩展到新技术领域和综合生态保护领域。

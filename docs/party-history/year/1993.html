1993

社会主义市场经济框架逐渐形成

宪法修改确认社会主义市场经济，十四届三中全会勾画制度框架；财政、金融、农村承包和教育领域推出配套改革。对外经济合作和两岸商谈也出现新进展。

1月13日—19日国防军事

制定新时期军事战略方针

地点 / 范围：北京

中央军委扩大会议调整军事战略方针，把作战准备重心放在现代技术、尤其高技术条件下的局部战争。军事建设由对形势的判断进一步落实为训练和能力建设要求。

结果与历史联系技术变化推动战略与组织建设调整，不能沿用旧战争模式理解新要求。

2月13日科技文化

教育改革与发展纲要出台

地点 / 范围：全国

中央和国务院提出本世纪末基本普及九年义务教育、基本扫除青壮年文盲的目标。教育改革将制度调整与基础教育普及相结合，强调扩大人口受教育机会。纲要把普及基础教育和扫盲放在世纪末目标中，说明教育改革不仅服务高校和少数人才，也要提高广大人口的基本受教育水平。

结果与历史联系义务教育普及和青壮年扫盲成为国家长期公共教育任务。

3月15日—31日法治制度

修宪确认社会主义市场经济

地点 / 范围：北京

八届全国人大一次会议修改宪法，写入社会主义市场经济有关内容，通过澳门基本法并批准机构改革。会议同时完成国家领导人员的换届安排。宪法同时明确中国处于初级阶段，机构改革首次突出转变政府职能，市场经济的确立因此伴随国家法律和管理方式调整。

结果与历史联系市场经济目标获得宪法依据，政府职能和国家机构继续适应改革需要。

4月27日—29日统一战线

首次汪辜会谈

地点 / 范围：新加坡

海协会会长汪道涵与台湾海基会董事长辜振甫举行会谈，签署共同协议等四项协议。双方受权民间机构通过协商处理具体往来事务。会谈由双方受权的民间机构领导人进行，主要处理具体交往事务；它与两岸各自政府直接签署政治协议具有不同性质。

结果与历史联系两岸形成较规范的事务协商渠道，为人员和经贸往来解决部分具体问题。

7月15日科技文化

提出重点建设高校和学科计划

地点 / 范围：全国

国家教委提出面向二十一世纪重点建设约一百所高校及一批重点学科的计划，后来简称“211工程”。它通过资源集中支持高等教育和学科能力建设。

结果与历史联系高等教育扩展与重点建设并存，不同政策目标应分开理解。

11月5日经济社会

延长土地承包期

地点 / 范围：全国农村

中央和国务院发布农业农村政策，提出原定耕地承包期届满后再延长三十年。稳定预期成为农村政策重点，农户得以围绕较长经营期限安排投入。此前家庭承包经营已经推广，较长承包期限有助于农户预期稳定；政策并未改变农村土地的集体所有性质。

结果与历史联系经营制度稳定性加强，为农户生产和长期投入提供政策条件。

11月11日—14日改革开放

十四届三中全会

地点 / 范围：北京

全会通过建立社会主义市场经济体制的决定，提出市场配置、宏观调控和现代企业制度等安排。改革由确认总体目标进入制度框架设计阶段。决定提出市场在国家宏观调控下对资源配置起基础性作用，并说明产权清晰、权责明确等现代企业制度要求，给配套改革提供基本原则。

结果与历史联系社会主义市场经济由总体目标进一步转入制度框架设计。

地点 / 范围：美国西雅图

12月15日、25日改革开放

分税制与金融改革部署

地点 / 范围：全国

国务院先后决定从1994年实施分税制财政管理，并部署金融体制改革。中央地方收入划分、中央银行职能及金融机构体系同时进入新的调整阶段。分税制改变地方财政包干方式，金融改革则区分政策性与商业性金融，并强化中央银行货币调控，二者都服务于统一市场运行。

结果与历史联系九十年代财税金融基本制度进入重建阶段，影响中央地方关系和企业融资环境。

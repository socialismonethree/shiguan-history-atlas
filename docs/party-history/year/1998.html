1月经济社会

部署天然林保护工程

地点 / 范围：国有林区

全国林业计划会议宣布实施天然林保护工程，调整木材产量并处理人员分流、资源保护和经营效益问题。生态保护由倡议转向具体工程和利益结构调整。工程把调减采伐与林区职工分流同时考虑，说明生态政策会改变地方产业和家庭收入，需要后续就业与保障措施共同支撑。

结果与历史联系森林资源保护从采伐管理走向系统工程，也推动林区经济转型。

3月5日—19日法治制度

国务院机构改革

地点 / 范围：北京

九届全国人大一次会议批准国务院机构改革，减少部分专业经济部门，加强宏观调控和执法监管，并决定朱镕基任国务院总理。政府职能继续适应市场经济调整。改革重点是减少直接干预企业经营的专业部门，强化财政金融、社会事务和市场监管等职能，使政府角色适应市场经济体制。

结果与历史联系国务院部门结构进一步调整，政府与企业的关系继续发生变化。

6月9日经济社会

保障下岗职工基本生活和再就业

地点 / 范围：全国

中央和国务院部署国企下岗职工基本生活保障与再就业。企业改革带来的人员调整产生直接民生压力，政策通过基本生活保障、就业服务等方式进行回应。文件提出劳动者自主择业、市场调节就业和政府促进就业相结合，试图在企业减员增效与职工生计之间建立政策支撑。

结果与历史联系就业管理从单位安置逐步转向市场和公共服务相配合，社保需求明显上升。

6月中旬—9月上旬经济社会

特大洪灾与抗洪抢险

地点 / 范围：长江、嫩江、松花江流域

南北多个流域遭受严重洪灾，军队、地方干部和群众共同投入抢险救灾。灾害应对既涉及紧急救援，也与水利建设、生态保护和灾后恢复相联系。洪灾既发生在长江流域，也影响嫩江、松花江流域，抢险和转移安置需要不同地区、军地部门与基层群众共同动员。

结果与历史联系救灾经验推动社会重视流域防洪、生态保护和应急组织体系。

6月26日法治制度

专属经济区和大陆架法通过

地点 / 范围：北京

全国人大常委会通过专属经济区和大陆架法，为相关海域权利和管理提供国内法律规范。海洋事务的法治建设继续推进。

结果与历史联系海洋法律、科学调查与外交实践各有不同作用。

7月党的建设

军队武警政法机关停止经商

地点 / 范围：全国

中央决定军队、武警部队和政法机关不再从事经商活动，调整公权力机关与市场经营之间的关系。政企利益交织问题通过组织性措施进行处理。停止经商使相关机构回归本职任务，减少依法履职与经营利益之间的冲突，资产移交和人员安排则需要具体实施。

结果与历史联系军警政法机关职能边界更加清楚，公权力与市场经营关系得到调整。

10月12日—14日经济社会

十五届三中全会讨论农村工作

地点 / 范围：北京

全会通过农业和农村工作重大问题的决定，提出面向二〇一〇年的农村发展目标。农村政策从稳定经营制度进一步扩展到农业和乡村综合发展。

结果与历史联系农村发展包含生产、公共服务与社会建设等多方面任务。

11月21日党的建设

“三讲”教育与廉政责任制

地点 / 范围：全国

中央部署县级以上领导班子和领导干部的“三讲”教育，同日与国务院印发党风廉政建设责任制规定，把思想教育与组织责任安排结合起来。

结果与历史联系教育活动与责任制度功能不同，不能用一次活动替代长期监督。

12月14日经济社会

建立城镇职工基本医保

地点 / 范围：全国城镇

国务院决定建立城镇职工基本医疗保险制度，调整职工医疗保障方式。保障安排从单位包办逐步走向社会统筹与个人责任相结合的制度探索。制度把医疗保障从特定单位的福利安排转向较广范围的社会保险，为后来居民医保扩展和制度整合提供基础。

结果与历史联系职工医疗保障有了全国性基本制度，企业改革中的疾病风险逐步社会化分担。

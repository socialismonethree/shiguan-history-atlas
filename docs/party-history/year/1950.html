2月14日外交

中苏签订同盟互助条约

地点 / 范围：苏联莫斯科

毛泽东访苏期间，中苏签署友好同盟互助条约及有关协定，安排安全合作和经济援助等事项。新中国在冷战初期选择与苏联建立同盟关系；这不是一般建交，而是涉及国家安全及建设资源的外交安排。

结果与历史联系理解这一条约，应同时看到当时的安全压力、建设需求和对外关系格局。

3月3日经济建设

统一国家财政经济工作

地点 / 范围：北京

政务院决定加强财政、金融和物资管理的集中统一，改变各地分散掌握收支与重要物资的状况。这些措施同稳定物价、恢复生产衔接，帮助新政权把战争时期的区域经济逐步纳入全国统一管理。

结果与历史联系财政统一是经济恢复的重要制度条件，也为全国性计划建设准备了基础。

5月1日社会民生

婚姻法公布施行

地点 / 范围：全国

新中国第一部婚姻法正式实施，确立婚姻自由、一夫一妻、男女平等和保护妇女儿童权益等原则。法律把婚姻家庭改革列为国家制度建设的一部分，实施过程中还需要宣传、司法和基层组织共同落实。

结果与历史联系它改变的不只是登记程序，还包括家庭关系中的权利义务和妇女法律地位。

5月1日军事国防

海南岛战役结束

地点 / 范围：海南岛

人民解放军通过渡海作战攻占海南岛，岛上国民党军队的主要抵抗被击败。海南岛的易手是解放战争后期军事行动的重要部分，显示部队在缺乏现代海空装备条件下进行跨海作战的实践。

结果与历史联系海南的解放改变了华南沿海军事态势，并使新政权建设扩展到海南全岛。

6月6日—9日党的建设

七届三中全会部署恢复经济

地点 / 范围：北京

全会围绕财政经济根本好转讨论工作安排。毛泽东提交有关经济状况的书面报告，并提出不要同时树立过多对立面，要求团结能够团结的力量，处理好社会改革与恢复生产的关系。

结果与历史联系会议为新中国早期党和政府统筹经济恢复与政治工作的部署提供了依据。

6月30日经济建设

土地改革法公布

地点 / 范围：中国大陆农村

土地改革法成为新解放区土地制度改革的法律依据。随后各地没收地主土地并向农民分配，改革在不同地区按具体情况分批推进；至1952年底，除部分少数民族地区外，大陆土地改革基本完成。

结果与历史联系它深刻改变农村土地占有关系；这次改革不能与后来农业合作化混为一谈。

8月7日—19日社会民生

首次全国卫生会议

地点 / 范围：北京

会议讨论新中国卫生事业的发展方向，把预防疾病、服务劳动群众以及中西医合作放到突出位置。公共卫生工作逐步从个别城市和医院扩展到全国性组织，防疫和基层卫生建设成为重要任务。

结果与历史联系卫生政策由诊疗延伸到疾病预防和社会动员，影响此后的卫生体系布局。

10月8日—25日军事国防

中国人民志愿军入朝作战

地点 / 范围：中国东北、朝鲜

中共中央作出出兵决策后，毛泽东下令组建中国人民志愿军，彭德怀任司令员兼政治委员。部队10月19日进入朝鲜，25日开始第一次战役，国内同时开展支援前线的社会动员与物资保障。

结果与历史联系战争直接影响新中国的安全环境、财政安排和工业国防建设，持续至1953年停战。

10月14日经济建设

治理淮河进入国家工程安排

地点 / 范围：淮河流域

政务院作出治理淮河的决定，针对流域水患组织工程规划和群众施工。治淮包括蓄洪、泄洪、河道整治等相互配合的工作，不是一座水坝即可完成的单项工程，随后多年持续建设。

结果与历史联系治淮把防灾、农业生产和区域水利建设联系起来，成为早期国家建设的实例。

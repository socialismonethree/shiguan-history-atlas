1月11日—22日党的会议

中共四大讨论领导权与工农联盟

地点 / 范围：上海

四大总结国共合作以来的经验，提出民主革命中的无产阶级领导权和工农联盟问题，并加强以支部为基础的组织建设。党的规模扩大，对基层工作的要求相应提高。会议表明中共对革命动力和自身角色的认识较此前进一步展开。

结果与历史联系明确领导权与工农联盟议题，并加强以支部为基础的组织建设。

1月组织建设

青年团更名为共产主义青年团

地点 / 范围：上海

中国社会主义青年团第三次全国代表大会决定改称中国共产主义青年团，并讨论执行中共四大决议与开展青年运动。名称变化反映政治定位进一步明确。团组织继续面向青年群体，以宣传、教育和群众工作支持国民革命的发展。

结果与历史联系青年团政治定位更加明确，组织工作更紧密配合日益高涨的国民革命。

3月12日统一战线

孙中山逝世与政治动员

地点 / 范围：北京及全国各地

孙中山在北京逝世，国共两党组织各界进行悼念，传播其遗嘱和政治主张。此后国民党内部围绕革命方向、与共产党关系等问题的分歧加深。悼念活动一方面扩大群众动员，另一方面也处于统一战线领导结构变化的关口。

结果与历史联系悼念扩大政治动员，孙中山去世又使统一战线内部领导关系发生变化。

5月1日—7日工农运动

中华全国总工会成立

地点 / 范围：广州

第二次全国劳动大会决定成立中华全国总工会，选举领导机构，讨论工会组织与工农联盟等问题。它汇集此前分散发展的工会力量，使全国工人运动具有更统一的组织平台，与同时高涨的农民运动形成呼应。

结果与历史联系形成全国性的统一工会机构，增强跨地区劳动运动协调。

5月15日工农运动

顾正红遇害

地点 / 范围：上海

上海日本纱厂劳动冲突中，工人顾正红被枪杀，多人受伤，引起工人和学生的抗议。租界当局对声援者的压制进一步激化矛盾。事件成为五卅运动的重要近因，劳动关系中的冲突由工厂内部扩展为全市的政治性抗议。

结果与历史联系工厂冲突向全市反帝抗议扩展，成为五卅运动的重要近因。

5月30日工农运动

五卅运动爆发

地点 / 范围：上海及全国各地

上海群众反帝示威遭租界巡捕开枪镇压，工人、学生和商人随即以罢工、罢课、罢市响应。运动迅速扩展到全国，中共参与组织与宣传。工人遭遇的暴力同民族权利问题结合，推动国民革命的社会动员达到新的规模。

结果与历史联系罢工、罢课、罢市形成全国声援，大革命的群众参与规模显著扩大。

5月党的建设

向警予任中央妇女部主任

地点 / 范围：上海

向警予在这一时期担任中共中央妇女部主任，并增补为第四届中央委员和中央局委员。她把妇女宣传、干部培养与群众组织联系起来；五卅事件后，又参与组织上海妇女投入反帝运动。妇女工作由个人倡议逐步成为党组织中的专门工作。

结果与历史联系这一任职及组织活动体现妇女工作在早期党的机构和群众运动中的位置，也提供了考察女性政治参与的具体线索。

6月19日起工农运动

省港大罢工

地点 / 范围：香港、广州

香港与广州沙面工人罢工，随后在广州成立省港罢工委员会，组织纠察、救济和封锁等工作。长期离厂与返乡的生活需要也成为组织者的重要任务。罢工延续到1926年，具有持续时间长、群众规模大和政治性强的特点。

结果与历史联系长期罢工发展出生活救济、纠察与组织管理网络，扩大反殖民政治影响。

7月1日统一战线

广州国民政府成立

地点 / 范围：广州

广州大元帅府改组为国民政府，所属军队随后整编为国民革命军。共产党人在部分军队承担政治工作，工农运动与军事准备相互推动。新政府以广东为根据地，为次年出师北伐提供了政治和组织条件。

结果与历史联系广东军政体系进一步整合，为次年北伐提供组织与政治条件。

廖仲恺遇刺

地点 / 范围：广州

10月党的会议

中共中央扩大会议与北方区委

地点 / 范围：北京

中央扩大会议讨论工农运动、军事和国共关系，提出农民土地要求，强调北方工作的地位。会后北方区执行委员会成立，李大钊任书记。中共的组织布局因此不仅围绕广东，也关注北方城市、铁路和军政局势。

结果与历史联系把农民土地要求和北方组织工作纳入中央部署，扩大南北革命联系。

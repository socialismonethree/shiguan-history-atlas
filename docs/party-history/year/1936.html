三大主力会师与停止内战的转机

东北抗联、红军东征西征和各界救亡活动共同发展，红军三大主力完成会师，西路军则陷入艰难作战。中共同东北军等力量的谈判逐步推进，西安事变最终和平解决，使联合抗日获得关键转机。

2月军事活动

东北抗日联军统编

地点 / 范围：中国东北

东北各支共产党领导和影响的抗日武装进行统编，逐步形成东北抗日联军。队伍由多民族爱国志士组成，在日伪严密统治和物资匮乏中持续游击作战。统编过程分阶段展开，各军和路军并非都在同一天成立。

结果与历史联系东北抗日力量向较统一建制发展，在长期游击战争中保留抵抗力量。

2月—7月军事活动

红军东征与西征

地点 / 范围：山西、陕甘宁边界

红一方面军先后进行东征和西征，寻求扩大抗日力量、根据地与活动空间。东征遭阎锡山等军队阻拦，刘志丹在战斗中牺牲；西征则向陕甘宁边界展开。行动同争取其他军队停止内战的谈判并行进行。

结果与历史联系扩大西北活动区域与抗日力量，刘志丹牺牲也使地方红军遭受重要损失。

3月底起组织建设

刘少奇主持北方局工作

地点 / 范围：天津、北平、华北各地

刘少奇受中央委派到天津主持北方局工作，调整过去不适合地下环境的做法，推动抗日联合和青年、工人组织发展。华北工作的重点逐渐由孤立行动转向保存组织、联系广泛救亡力量，为全面抗战后的地方动员准备条件。

结果与历史联系北方地下组织和救亡联系恢复发展，为全面抗战后的华北动员积累基础。

4月9日统一战线

周恩来与张学良会谈

地点 / 范围：陕北肤施

周恩来与张学良会谈停止内战、联合抗日等问题，并讨论通商和互派代表。东北军因故乡沦陷而具有强烈抗日愿望，中共借此开展争取工作。双方接触逐渐改变陕北地区的军事政治关系，也为西安事变后的谈判创造基础。

结果与历史联系中共同东北军关系改善，为联合抗日与西安事变和平解决积累互信。

5月31日统一战线

全国各界救国联合会成立

地点 / 范围：上海

多地救亡团体联合成立全国性组织，主张团结抗日、停止内战。沈钧儒、邹韬奋等参与领导，社会成员包括不同政治倾向人士。救国会把地方团体、舆论和群众活动相连接，反映抗日联合的社会要求正在扩大。

结果与历史联系社会救亡团体形成全国联系，要求停止内战与团结抗日的压力扩大。

6月起思想文献

斯诺访问陕北

地点 / 范围：陕北保安等

美国记者斯诺进入陕北，访问中共领导人、红军和根据地群众，记录其经历与政治主张。访谈后来形成《红星照耀中国》，1937年英文版出版，1938年中译本《西行漫记》面世。访问与出版属于不同时间节点。

结果与历史联系陕北与红军情况进入国际公共视野，相关著作后来影响国内外对中共的认识。

7月5日军事活动

红二方面军成立

地点 / 范围：四川甘孜

红二、红六军团在长征途中同红四方面军会合，随后组建红二方面军，贺龙任总指挥、任弼时任政治委员。在中央争取和部队共同要求下，两支方面军一同北上。番号变化反映组织整合，也承续各部此前的根据地经验。

结果与历史联系第三支红军主力形成，红二、四方面军共同北上，推动最终会师。

8月2日抗日战争

赵一曼遇害并留下致子遗书

地点 / 范围：黑龙江珠河，今尚志市

赵一曼在东北从事工人组织和抗日武装工作，1935年负伤被俘。1936年8月2日，她在被押赴刑场途中给儿子陈掖贤写下遗书，当天在珠河被日军杀害。书信把一位抗日战士的政治选择与母子离别联系起来，留下可以具体查验的个人史料。

结果与历史联系她的事迹是东北抗日斗争中女性参与的代表性个案；遗书为认识战争中的个人处境和家庭联系提供了原始材料。

10月9日、22日军事活动

红军三大主力会师

地点 / 范围：甘肃会宁、将台堡

红一、红四方面军在会宁会合，红一、红二方面军随后在将台堡会合，三大主力结束长途转移。会师使西北力量更加集中，为后来抗日战略转换创造条件。长征造成的人员与根据地损失也应保留在完整叙述中。

结果与历史联系红军主要力量在西北集中，为由国内战争转向全面抗战创造军事基础。

10月下旬—1937年3月历史教训

西路军西渡黄河与失败

地点 / 范围：宁夏方向、甘肃河西走廊

红四方面军一部奉命渡过黄河，后称西路军，寻求执行宁夏战役计划和打通援助道路。部队深入河西，在敌强、缺少根据地和补给等条件下苦战，1937年3月失败，大量将士牺牲或被俘。决策与执行过程应按具体阶段研究。

结果与历史联系西路军在缺乏依托的条件下付出惨重牺牲，打通援助道路的计划未能实现。

12月12日—25日历史转折

西安事变及和平解决

地点 / 范围：西安

张学良、杨虎城扣留蒋介石，要求停止内战、共同抗日。中共中央确定和平解决方针，派周恩来等赴西安谈判，最终蒋介石获释，政治局势转向合作抗日。各方的军事压力、谈判和社会救亡呼声共同影响结果。

结果与历史联系停止内战、联合抗日获得关键转机，第二次国共合作逐步成为现实可能。

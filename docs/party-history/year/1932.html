1932

抗日抵抗、军事争论与西北探索

淞沪抗战与东北抵抗推动社会救亡，中共的联合策略仍有局限。中央苏区围绕攻取城市还是向有利地区发展发生争论，宁都会议改变军事领导分工；红四方面军西移，陕甘地方武装则为新的根据地奠基。

1月28日起军事活动

淞沪抗战与群众支援

地点 / 范围：上海

日军进攻上海，十九路军及后来参战的第五军抵抗。中共组织工人罢工、募捐、救护和支援前线，文化界也发出抗日呼声。党在政策上仍有联合范围过窄等问题，不能把群众支援的实际成效同当时中央策略完全等同。

结果与历史联系抗日社会支援扩大，也使联合范围过窄的策略局限更加明显。

2月3日思想文献

文化界发表抗日呼吁

地点 / 范围：上海

上海文化界人士联名向国际社会控诉日本侵略，呼吁支持中国抗战。作家和艺术工作者通过宣言、报刊与国际联络参与救亡。其行动说明抗日运动的参与者和表达方式很广，不能只从军事组织或正式党籍理解文化界抗战。

结果与历史联系文化界抗日声音进入国际舆论，连接左翼文化与更广泛的民族救亡。

3月历史教训

赣州失利后的军事争论

地点 / 范围：江西赣州、江口

红军围攻赣州失利后，苏区中央局讨论下一步方向。毛泽东主张向敌统治较弱、群众基础较好的地区发展，与要求继续夺取中心城市的方针发生分歧。争论体现根据地实际经验和中央对全国形势判断之间的冲突。

结果与历史联系攻城失利引发军事方向争论，为宁都会议的分歧形成直接背景。

4月20日军事活动

红军东路军攻占漳州

地点 / 范围：福建漳州

红一、红五军团组成的东路军攻占漳州，缴获军用物资并筹措经费。行动发生在中央苏区向外发展和应对封锁的背景下。部队随后撤离，不应把短期军事占领误写为当地已建立长期稳定、完全控制的根据地政权。

结果与历史联系筹得物资和经费、打击敌军，为苏区缓解供给和军事压力。

夏军事活动

东北抗日义勇军发展

地点 / 范围：辽宁、吉林、黑龙江

九一八后形成的多种抗日队伍在东北继续抵抗，中共在其中开展联络和政治工作，并组织抗日游击力量。义勇军来源复杂、组织不一，日军围攻使其遭受重大困难。后来东北抗联的形成，是整合与长期斗争的结果。

结果与历史联系东北抗日游击力量持续成长，为后来统编抗联积累人员和组织基础。

10月上旬党的会议

宁都会议改变军事分工

地点 / 范围：江西宁都

苏区中央局在宁都开会，对毛泽东的军事主张作出错误批评，其在红军的领导职务受到调整。此后前方主要由周恩来、朱德指挥。会议与当时争取攻取中心城市的方针有关，是中央苏区军事领导变化的重要节点。

结果与历史联系毛泽东的军事领导职务被调整，周恩来、朱德承担前方主要指挥。

10月军事活动

红四方面军主力撤离鄂豫皖

地点 / 范围：鄂豫皖至川北

在国民党军进攻和错误指挥造成的困难下，红四方面军主力撤出鄂豫皖，转战至川北，原地仍有革命武装坚持。主力转移没有使地方斗争全部终止。新的川陕根据地将在次年发展，形成不同阶段的军事与地方组织格局。

结果与历史联系鄂豫皖主力转赴川北，地方留守与新根据地建设形成并行线索。

12月军事活动

陕甘游击队改编与根据地探索

地点 / 范围：陕西、甘肃边界

陕甘地区共产党领导的游击力量改编为红军，随后逐步建设以照金、南梁等为中心的根据地。当地武装经历多次挫折和恢复，群众基础与边界地形影响其生存。陕甘根据地后来成为中央红军长征到达的落脚区域。

结果与历史联系西北武装逐步发展，为陕甘根据地及中央红军后来的落脚提供基础。

12月统一战线

中国民权保障同盟发起

地点 / 范围：上海

宋庆龄、蔡元培、杨杏佛等发起民权保障组织，关注政治犯处境，要求保障民众权利、反对非法拘禁和酷刑。其成员并非都属于共产党。中共同广泛社会力量发生联系，说明民主权利运动具有超出单一政党的参与基础。

结果与历史联系民权保障成为跨党派社会议题，拓展民主人士参与革命和救亡的联系。

年底—1933年3月军事活动

第四次反“围剿”展开

地点 / 范围：江西中央苏区

国民党军继续进攻中央苏区，红军在周恩来、朱德指挥下运用集中优势兵力、伏击等办法作战，至次年取得第四次反“围剿”胜利。战役跨越两个年份，年度界面应保留其连续性，而不能把结束结果提前记作本年已完成。

结果与历史联系战役进入持续作战阶段，次年取得胜利并进一步检验红军运动战经验。

1月7日—3月30日经济建设

成套设备引进计划扩大

地点 / 范围：北京

全国计划会议讨论解决积累、工资、投资和产业配套问题，国务院推动从国外引进成套化肥、化纤、发电和钢铁等设备。后来形成的四三方案，把技术和设备引进作为改善经济能力的重要办法。

结果与历史联系技术引进推动一批工业项目建设，为此后开放条件下的产业升级积累经验。

3月29日党的建设

邓小平重新参加国务院工作

地点 / 范围：北京

在恢复组织生活与副总理职务的基础上，周恩来主持政治局会议，决定邓小平正式参加国务院业务组工作并参与外事活动。年底邓小平又参加中央和军委领导工作，重返主要决策岗位。

结果与历史联系干部恢复增强国家工作的组织力量，为1975年全面整顿提供关键条件。

6月10日社会民生

李庆霖来信反映知青困难

地点 / 范围：福建及全国

毛泽东给小学教师李庆霖的回信印发全党，来信反映子女上山下乡后生活和就业等实际困难。文件使知青安置问题受到更多注意，各地随后开展有关政策落实工作，但总体运动仍继续。

结果与历史联系个体家庭遭遇进入中央视野，显示知青问题并非只有宣传中的劳动教育意义。

8月5日—20日社会民生

首次全国环境保护会议

地点 / 范围：北京

国务院召开全国环境保护会议，讨论工业污染、城市环境和资源保护，制定有关试行规定。经济建设造成的污染开始作为专门政策问题处理，环境管理不再仅分散在卫生和单个生产部门。

结果与历史联系会议推动中国环境保护工作走向专门组织与制度安排，成为此后环保体系的起点之一。

8月24日—28日历史曲折

中共十大召开

地点 / 范围：北京

大会选出新的中央委员会，一部分文革中受打击的老干部重新进入中央领导机构，但政治和组织路线仍继续肯定九大。王洪文等进入高层，纠正文革根本错误的任务未获完成。

结果与历史联系组织上的部分恢复不能掩盖指导路线错误，政治斗争继续影响正常建设。

8月26日科技教育

百万次集成电路计算机试制成功

地点 / 范围：北京

中国科研人员试制成功每秒运算百万次的集成电路电子计算机，计算、器件与系统设计能力获得提升。科研系统虽受运动干扰，仍有队伍坚持攻关，为后续信息技术发展积累工程基础。

结果与历史联系计算机技术进步服务科研和工业运算，也显示基础器件与系统工程需要协同发展。

本年科技教育

籼型杂交水稻取得突破

地点 / 范围：湖南等地

袁隆平等组成的科研协作力量培育成功强优势籼型杂交水稻，解决育种中的关键环节。成果经过多地试验与后续鉴定后逐渐推广，不能把实验突破、鉴定和全国种植写成同一个时间点。

结果与历史联系杂交水稻为提高稻谷产量提供新技术路径，对粮食生产和农业科学产生长期影响。

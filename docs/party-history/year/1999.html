2月13日党的建设

农村基层组织工作条例出台

地点 / 范围：全国农村

中央印发农村基层组织工作条例，明确农村基层党组织的工作要求。家庭经营、乡村产业和人口流动变化，使基层组织需要在新条件下调整工作方式。

结果与历史联系乡村经济改革与基层组织建设构成相互关联的两条线索。

6月13日科技文化

推进素质教育

地点 / 范围：全国

中央和国务院部署深化教育改革、全面推进素质教育，强调提高国民素质。教育目标从规模扩张进一步涉及培养内容、能力与学生全面发展。素质教育要求从知识传授扩大到能力和身心发展，学校教育的培养目标与评价方式因此成为政策讨论的一部分。

结果与历史联系教育政策更重视人的全面发展，回应单纯升学和考试导向的局限。

6月17日经济社会

提出实施西部大开发

地点 / 范围：陕西西安

江泽民在西安召开的国企改革发展座谈会上提出实施西部大开发的战略任务。区域协调发展从原则讨论进一步进入跨区域政策部署。随后国务院推出相关政策措施，西部交通、能源、生态和产业等领域逐步形成综合开发安排，区域发展战略由沿海进一步向内陆延伸。

结果与历史联系西部地区获得更集中政策关注，国家发展布局开始着力协调地区差距。

8月20日科技文化

部署技术创新与产业化

地点 / 范围：全国

中央和国务院发布加强技术创新、发展高科技并实现产业化的决定，随后召开全国技术创新大会。企业、科研与产业发展的联系进一步强化。技术创新大会进一步组织相关部署，研究、技术转让、企业应用与高技术产业发展被放在同一政策链条中考虑。

结果与历史联系创新工作更加注重成果形成实际生产能力，企业与科研联系增强。

表彰两弹一星功勋科学家

地点 / 范围：北京

中央、国务院和中央军委表彰为两弹一星研制作出突出贡献的二十三位科技专家。表彰既评价科学家贡献，也强调国家工程中协作组织与长期投入的作用。

结果与历史联系纪念个人时仍需保留工程团队和参与群体的历史位置。

9月19日—22日改革开放

十五届四中全会部署国企改革

地点 / 范围：北京

全会通过国有企业改革和发展重大问题的决定，把企业制度、结构调整和发展问题放在综合框架中部署。国企改革与就业、金融和社会保障密切相连。决定把现代企业制度、战略调整和提高效益联系起来，同时需要社会保障等改革配套，国企转型不再只是企业内部的技术管理问题。

结果与历史联系国企改革继续深入制度与结构层面，并影响就业、财政和产业布局。

12月19日午夜—20日凌晨统一战线

澳门回归

地点 / 范围：澳门

中葡举行澳门政权交接，中国恢复对澳门行使主权，澳门特别行政区成立，驻澳部队开始履行防务职责。澳门基本法和“一国两制”安排进入实施阶段。交接后特区政府宣誓就职，驻澳部队承担防务，澳门基本法所规定的制度由过渡准备进入实际运行；治理仍延续澳门自身城市条件。

结果与历史联系澳门进入特别行政区发展阶段，一国两制实践扩展到另一地区。

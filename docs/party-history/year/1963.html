1月4日民族与统一

对台政策概括为一纲四目

地点 / 范围：北京

周恩来把有关台湾问题的原则概括为一纲四目，并通过渠道转达台湾方面。方案以国家统一为前提，对台湾原有军政安排、财政困难和社会改革节奏作出设想，是当时探索和平解决途径的表达。

结果与历史联系它为此后统一问题的政策探索留下历史资料，但当时并未转化为两岸达成的协议。

2月11日—28日历史曲折

社会主义教育运动部署

地点 / 范围：全国城乡

中央工作会议决定农村开展四清、城市开展五反，针对基层经济管理和干部作风问题展开教育。随着运动发展，越来越多问题被归为阶级斗争，后来出现打击面过宽和处理失当的情况。

结果与历史联系基层治理问题被政治化，为1960年代中期运动升级创造了环境，需连同其负面后果考察。

3月5日思想文化

全国开展向雷锋学习活动

地点 / 范围：全国

毛泽东的题词公开发表后，雷锋在部队和日常生活中助人、节约、尽责的事迹得到广泛传播。学习活动由军内扩展到学校、工厂和机关，成为社会主义道德教育及社会服务的长期主题。

结果与历史联系雷锋由一名普通战士成为公共道德榜样，学雷锋活动持续影响几代人的社会生活。

4月6日社会民生

首支援外医疗队赴阿尔及利亚

地点 / 范围：阿尔及利亚

中国向阿尔及利亚派出医疗队，医生和其他卫生人员在当地开展诊疗并协助卫生工作。这是中国政府向非洲国家派遣的第一支医疗队，此后援外医疗逐步形成持续的合作机制。

结果与历史联系医疗援助把外交合作与日常民生相连，成为中国同非洲国家关系的重要内容。

6月14日外交

中苏两党公开论争升级

地点 / 范围：北京、莫斯科

中共中央发表有关国际共产主义运动总路线的建议，随后又连续发表九篇论战文章。双方在革命、和平共处及国际运动领导等问题上分歧扩大，党际争论不断影响国家间关系。

结果与历史联系中苏同盟原有合作基础进一步受损，中国对外环境和国防建设压力随之变化。

11月17日经济建设

治理海河工作加强

地点 / 范围：海河流域

河北遭受严重水灾后，毛泽东提出根治海河的要求，流域河道、堤防与排水系统治理持续推进。工程跨越多个河系和地方，需要长期施工与统一安排，后来骨干河道逐步得到整治。

结果与历史联系水利建设改善华北防洪和农业条件，也显示大流域治理需要多年连续投入。

12月2日科技教育

新的科技发展规划获原则批准

地点 / 范围：全国

中央和国务院原则批准1963—1972年科学技术发展规划相关报告与纲要。规划围绕国家建设、国防和基础学科组织研究任务，把人才培养、科研布局和应用需要纳入较系统的安排。

结果与历史联系在经济调整期保持重点科研投入，帮助部分战略科技项目继续取得突破。

12月14日—翌年2月29日外交

周恩来访问亚非欧十四国

地点 / 范围：亚非欧有关国家

周恩来展开连续访问，同新独立国家及其他国家发展关系，提出对外经济技术援助的原则，强调尊重主权、平等互利和帮助受援国发展能力。访问将政治支持与具体合作相连接。

结果与历史联系中国对亚非国家外交网络扩大，经济援助逐渐形成较明确的政策方式。

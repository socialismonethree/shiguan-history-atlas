YEARLY ARCHIVE / 年度档案
1979

改革开放起步与对外关系转折

十一届三中全会后的改革方针进入具体试验阶段。蛇口工业区、广东福建特殊政策和企业改革开始推进，中美关系、对台方针及法制建设也发生重要变化；经济调整与开放试验同步进行。

1月1日统一战线

发表《告台湾同胞书》

地点 / 范围：北京、金门等

全国人大常委会发表面向台湾同胞的文告，提出和平统一方针。国防部长徐向前同时宣布停止对金门等岛屿的炮击。政策表达与军事措施相互配合，使两岸交往开始出现新的可能。文告发布当日的停止炮击措施结束了自一九五八年开始的持续炮击安排，中央同时把两岸人民的联系和往来置于新的政策表达中。

结果与历史联系和平统一成为公开政策方向，为后来探亲、通航和事务性协商提供了新的政治背景。

1月4日—22日党的建设

恢复重建纪律检查工作

地点 / 范围：北京

中央纪律检查委员会举行第一次全体会议，部署恢复纪律检查工作。随后，各地方的纪检机构陆续恢复和重建，组织保障与干部纪律成为拨乱反正和改革起步的配套事项。地方纪检机构的恢复并非一次完成，而是在中央会议后陆续展开，纪检系统由中央到地方重新形成工作网络。

结果与历史联系党内纪律处理和干部监督逐渐有了恢复后的专门机构，服务于组织秩序重建。

1月18日—4月3日思想理论

理论务虚会与四项基本原则

地点 / 范围：北京

党的理论工作务虚会讨论思想理论问题。邓小平于3月30日作专门讲话，提出四项基本原则，把现代化建设的政治方向与正在推进的思想解放、改革开放联系起来说明。讲话具体把社会主义道路、人民民主专政、党的领导和马克思列宁主义毛泽东思想列为政治前提，回应改革初期的方向争论。

结果与历史联系四项基本原则成为后续基本路线的重要组成，并影响政治思想领域的政策安排。

1月29日—2月5日对外关系

邓小平访问美国

地点 / 范围：美国

中美正式建交后，邓小平赴美国进行国事访问。这是新中国领导人首次访美，访问把两国关系的制度性变化落实到高层接触，并为此后的经济、科技和人员往来拓展空间。此行发生在一月一日中美正式建交之后，高层交往把长期接触与谈判形成的关系转折推进到新的阶段。

结果与历史联系为扩大中美经济科技和人员交往创造条件，也显示现代化战略对国际合作的重视。

1月31日改革开放

决定创办蛇口工业区

地点 / 范围：广东深圳

中共中央、国务院决定在广东蛇口建立对外开放工业区。它以具体工业开发项目探索引进外资、经营管理和对外经济联系，成为改革初期从局部试验积累经验的一个窗口。这一开放试验与七月广东、福建特殊政策安排先后出现，地方经营实践成为探索新管理方式的前沿，而非全国同时采用单一办法。

结果与历史联系蛇口成为早期对外开放和企业经营方式探索的重要窗口，为更大范围试验积累经验。

2月17日—3月16日国防军事

中越边境战争

地点 / 范围：中越边境

中国边防部队在中越边境实施军事作战。权威大事记将其称为“对越自卫反击战”；这一条目记录作战时段和边境背景，不把官方名称替代对战争全过程和代价的专门研究。

结果与历史联系改革初期国内建设与周边安全压力同时存在，边境局势是外交国防的重要背景。

4月5日—28日经济社会

提出国民经济调整方针

地点 / 范围：北京

中共中央工作会议讨论经济运行问题，决定实行调整、改革、整顿和提高相结合的方针。经济建设并非只追求项目和速度，也开始处理比例失衡、管理效率以及恢复秩序等现实问题。会议把经济比例调整、改善管理与改革结合，而不是在恢复建设后立即全面扩大投资；政策同时回应现实供给与运行效率。

结果与历史联系为改革初期经济运行作出调整，避免把建设目标与资源条件割裂。

7月1日法治制度

刑法等七部法律通过

地点 / 范围：北京

五届全国人大二次会议通过刑法、刑事诉讼法、中外合资经营企业法等七部法律，并修改宪法有关规定。刑事司法与对外经济活动同时获得更明确的法律依据。七部法律把刑事责任、刑事诉讼程序和外商合资经营等不同问题分别纳入规则，反映法制恢复与新经济活动并行。

结果与历史联系刑事司法获得重要基本法律，外商投资也开始有专门法律依据。

7月15日改革开放

广东福建实行特殊政策

地点 / 范围：广东、福建

中共中央、国务院批准广东、福建在对外经济活动中实行特殊政策和灵活措施，先在深圳、珠海试办出口特区。经济特区名称和四个特区的正式设置则在1980年推进。随后中央于一九八〇年将出口特区改称经济特区，并依法批准深圳、珠海、汕头和厦门设置特区，形成从政策试办到正式设立的过程。

结果与历史联系开放实践由局部探索逐步获得较明确制度和地域范围，推动特区建设。

1月1日工农运动

海丰县农会成立

地点 / 范围：广东海丰

海丰各地农会联合形成县级组织，彭湃任会长。农会除处理农民组织事务，还涉及教育、卫生、农业和纠纷调解等工作。其活动向陆丰、惠阳等地扩展，体现从单个乡村组织走向县域农民联合的过程。

结果与历史联系农民组织从村落发展到县级联合，推动海陆丰等地农运扩展。

1月12日统一战线

共产国际讨论国共关系

地点 / 范围：莫斯科

共产国际执委会就中国共产党与国民党的关系作出决议，支持党内合作方式，同时要求共产党保留自己的组织。文件影响中共随后讨论合作策略。国际指导与中国实际条件如何协调，是这一时期组织决策的重要背景。

结果与历史联系国共党内合作得到国际组织推动，也使保持共产党组织独立成为突出问题。

2月4日—9日工农运动

京汉铁路大罢工与二七惨案

地点 / 范围：郑州、武汉、长辛店等

京汉铁路工人因总工会成立受阻而举行全线罢工，军阀吴佩孚调军警镇压，林祥谦、施洋等遇害。罢工最终停止，许多工会被破坏。由1922年起形成的工运高潮转入低潮，组织者开始更迫切地思考联合其他社会力量的问题。

结果与历史联系罢工遭严重镇压，第一次工运高潮转入低潮，联合其他革命力量的必要性更加迫切。

4月组织建设

中央机关迁回上海

地点 / 范围：北京、上海

中共中央由北京迁回上海，在这座交通、出版和工商业活动集中的城市继续领导工作。此后中央机关又曾因革命形势变动而迁移。机关驻地的变化与交通联络、秘密活动条件及各地运动布局有关，不等同于党的工作只在驻地开展。

结果与历史联系中央机关重新依托上海的交通出版条件，继续协调全国组织与革命活动。

6月12日—20日党的会议

中共三大确定国共合作办法

地点 / 范围：广州

三大围绕国共合作展开讨论，决定共产党员以个人身份加入国民党，同时保留共产党自己的组织和纪律。大会选举中央执行委员会，毛泽东进入中央局。会议后，各地共产党人参与国民党改组，合作进入更具体的组织实施阶段。

结果与历史联系确定第一次国共合作的中共方针，推动各地党员参与国民党改组。

6月15日思想文献

《新青年》季刊创刊

地点 / 范围：广州

《新青年》以季刊形式出版，由瞿秋白主编，侧重马克思主义理论与国际共产主义运动的介绍。其刊名承续新文化运动的历史影响，但出版形态和政治定位已发生变化。瞿秋白译配的《国际歌》歌词也在这一传播网络中广为人知。

结果与历史联系强化马克思主义理论刊物和翻译传播，使文化教育成为组织工作的重要组成。

8月20日—25日组织建设

社会主义青年团二大

地点 / 范围：南京

青年团第二次全国代表大会召开，讨论青年运动与国民革命的关系，支持中共三大的合作方针，决定团员也以个人身份加入国民党。青年团在与党配合的同时继续承担联系青年、组织教育和培养干部的任务。

结果与历史联系青年组织落实合作政策，将国民革命动员扩展到更多青年群体。

10月20日思想文献

《中国青年》创刊

地点 / 范围：上海

青年团中央机关刊物《中国青年》创刊，面向青年讨论社会改造、个人道路与国民革命。多位早期共产党人参与编辑。刊物成为青年组织联系学生、工人和进步知识青年的平台，其读者与影响范围超出正式团员。

结果与历史联系形成持续面向青年的政治讨论平台，促进学生、工人和知识青年的联系。

11月1日思想文献

上海书店开办

地点 / 范围：上海

中共在上海创办书店，经售并出版《向导》《新青年》《前锋》《中国青年》等刊物。公开文化经营同政治宣传、组织联络结合起来，使理论读物进入更广泛的城市读者网络。书店后来受到军阀当局查封，显示出版活动受到政治压制。

结果与历史联系扩大革命刊物发行网络，连结公开文化活动与党的宣传组织工作。

11月24日—25日党的会议

三届一中全会部署国民党改组

地点 / 范围：上海

中央全会进一步讨论三大方针如何落实，部署各地参与国民党改组，并在国民党组织中通过共产党人的内部联络贯彻工作主张。随后李大钊赴广州协助筹备国民党一大。合作策略由原则逐步转化为各地组织工作的具体要求。

结果与历史联系把三大合作原则转化为地方组织任务，推进国民党一大的筹备。

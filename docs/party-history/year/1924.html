1924

国共合作与革命干部培养

国民党一大标志第一次国共合作形成，黄埔军校和农民运动讲习所提供干部培养平台。工人组织、农会、国民会议运动与早期武装工作同步发展，合作中的独立性和阶层利益差异也开始显现。

1月20日—30日统一战线

国民党一大与第一次国共合作

地点 / 范围：广州

国民党一大在孙中山主持下举行，共产党人参与宣言起草和组织改组，部分当选中央执行委员或候补委员。联俄、联共、扶助农工的政策得到确立。大会标志第一次国共合作正式形成，但双方仍保有不同的组织、政治目标和社会基础。

结果与历史联系第一次国共合作正式形成，为国民革命的军事、组织和群众工作提供共同平台。

2月7日工农运动

全国铁路总工会成立

地点 / 范围：北京

全国铁路工人代表秘密开会，成立全国铁路总工会。在二七惨案后的压制环境中，铁路工人尝试恢复跨线路、跨地区的组织联系。这一行动说明1923年的受挫并未使工人工作终止，组织形式则更重视隐蔽与联络。

结果与历史联系铁路工运在镇压后的低潮中恢复全国性联系，为后续运动保存组织力量。

5月10日—15日党的会议

中央扩大会议讨论合作中的独立性

地点 / 范围：上海

中央执行委员会扩大会议总结国共合作数月的工作，讨论组织、工人运动和合作策略，注意到共产党内部出现的迁就倾向。如何动员工农群众、又如何在合作中保持共产党自身作用，成为不断反复的现实问题。

结果与历史联系合作中的独立性和群众动员问题受到中央重视，成为此后反复讨论的政策议题。

5月开学、6月16日典礼军事活动

黄埔军校开办

地点 / 范围：广州黄埔

国共合作创办的陆军军官学校开始招收、训练学员，6月举行开学典礼。中共选派党团员和革命青年入校，多位共产党人先后承担政治工作。军校既培养军事干部，也把政治教育与部队组织结合起来，随后影响东征与北伐。

结果与历史联系为东征、北伐等培养军事政治干部，形成国共合作的重要军事教育基地。

7月3日工农运动

广州农民运动讲习所开课

地点 / 范围：广州

第一届农民运动讲习所正式开学，将组织农会、认识农村社会和开展群众工作作为干部培养的重要内容。此后连续办班，学员分赴各地。农民运动从地方经验向跨区域推广，需要的不仅是号召，也包括受训练的组织者。

结果与历史联系通过集中培训向各地输送农运干部，推动地方农会工作扩展。

7月15日起工农运动

广州沙面工人罢工

地点 / 范围：广州沙面

沙面工人反对英法租界当局限制中国人出入的新规定而罢工，持续一个多月后取得成果。这次斗争的直接对象是殖民租界的管理制度，反映工人劳动生活与民族权利问题的联系，并促使工人进一步加强自身组织。

结果与历史联系工人集体行动抵制租界限制，增强广州工会组织和反帝动员。

11月军事活动

铁甲车队改组

地点 / 范围：广州

中共广东区委在孙中山同意后，从黄埔毕业生中抽调党团员为骨干，吸收工农和知识青年，改组大元帅大本营铁甲车队。它在编制上处于国民革命体系内，却实际上受共产党组织影响和指挥，后来参加支援农民运动等行动。

结果与历史联系为中共早期直接影响革命武装积累经验，并使武装开始支援农民斗争。

11月19日统一战线

推动国民会议运动

地点 / 范围：上海及全国各地

中共发表时局主张，推动召开国民会议，呼应孙中山北上提出的政治要求。各地以促成会等形式动员群众，反对军阀统治和不平等条约。工人、学生、商人等参与使国民革命的社会动员逐渐突破早期的小范围组织。

结果与历史联系国民会议促成活动扩大反军阀、争取政治改革的社会动员。

广宁减租斗争获支援

地点 / 范围：广东广宁

广东广宁农会发动减租，遭地主武装阻挠，革命政府派铁甲车队支援。农会、党组织和革命武装在实际斗争中发生联系，反映农民要求已不只是宣传议题，而开始直接触及租佃关系与乡村权力。

本年（具体月日未详）群众运动

向警予参与领导上海女工斗争

地点 / 范围：上海闸北等地

向警予参与领导上海丝厂女工与南洋烟厂工人的罢工，并持续开展妇女宣传和干部培养。工厂中的女性劳动者成为早期工人运动的重要参与者，妇女工作也不只限于办学与社会救济。这些组织实践与随后上海更大范围的工人运动相衔接。

结果与历史联系女工组织与妇女干部培养扩大了早期群众工作的社会基础，为1925年妇女参加五卅运动积累了组织经验。

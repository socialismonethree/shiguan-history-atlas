1月7日党的建设

党员权利保障条例试行

地点 / 范围：全国

中央印发党员权利保障条例试行文本，对党内权利的行使和保障作出规定。后来正式条例的制定与修订，应与这一试行阶段分别记载。

结果与历史联系党内纪律建设与党员权利保障是相关而不同的制度内容。

1月30日统一战线

江泽民提出发展两岸关系八项主张

地点 / 范围：北京

江泽民发表关于推进祖国统一的讲话，提出发展两岸关系的八项主张。讲话在交流扩大与政治分歧持续并存的背景下，阐述中央对台工作方针。八项主张围绕结束敌对状态、扩大交往等方向阐述政策，既延续和平统一方针，也回应两岸交流扩大后的现实问题。

结果与历史联系中央对台方针得到新一轮集中表达，并影响后续两岸政策讨论。

2月9日党的建设

规范党政干部选拔任用

地点 / 范围：全国

中央印发干部选拔任用工作暂行条例，对党政领导干部任用程序作出制度规范。干部制度逐步从政策要求转向更明确的程序性规定。

结果与历史联系选人用人关系组织运行，不能只以个别人物升迁来理解。

3月18日法治制度

教育法通过

地点 / 范围：北京

八届全国人大三次会议通过教育法，对教育制度、学校和受教育者等作基本规范。此前教育改革和普及目标由此获得更广泛的法律支撑。教育法为教育的基本制度、学校和受教育者关系作共同规范，使不同层次教育活动能够在统一法律框架下开展。

结果与历史联系教育改革与公共教育发展获得基本法律依据。

5月6日科技文化

确立科教兴国战略

地点 / 范围：全国

中央和国务院作出加速科技进步的决定，确定实施科教兴国战略。科技与教育被放在国家长期发展能力的关键位置，创新、人才和经济增长的联系进一步强化。科技进步被要求同经济和社会发展结合，教育培养与科研能力建设也由此上升到国家长期战略，而不再只看短期项目产出。

结果与历史联系科技和教育在现代化建设中的基础地位更加明确。

9月25日—28日经济社会

十四届五中全会规划跨世纪发展

地点 / 范围：北京

全会通过九五计划和二〇一〇年远景目标建议，要求推动经济体制向市场经济转变、增长方式向集约型转变。江泽民讨论改革发展稳定等重大关系。建议把增长方式转变列为全局性任务，反映资源投入、效率和结构问题逐渐突出；经济改革不再只追求制度放开和总量扩张。

结果与历史联系转变发展方式成为跨世纪规划的重要目标，影响随后产业与资源环境政策。

11月29日统一战线

第十一世班禅继任获批准

地点 / 范围：西藏、北京

第十世班禅转世灵童经金瓶掣签认定，国务院批准坚赞诺布继任第十一世班禅额尔德尼。事件属于宗教事务、历史制度和国家管理相交汇的领域。

结果与历史联系阅读宗教史条目应区分宗教传统、行政程序与不同方面的认同。

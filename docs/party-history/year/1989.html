1989

政治风波、中央调整与治理整顿

春夏之交的政治风波对政治和社会生活产生重大影响，中央领导机构随之调整。中苏关系正常化、经济治理整顿和多党合作制度文件，则构成本年其他关键脉络。事件评价应注明资料口径。

4月15日、22日政治进程

胡耀邦逝世与悼念活动

地点 / 范围：北京

胡耀邦于四月十五日逝世，中央发布讣告，二十二日举行追悼大会。悼念活动与此后学生和社会公众的政治诉求相联系，北京等城市出现大规模集会与示威。此后事件迅速发展，不能把全部参与者视为同一组织或同一种诉求。

结果与历史联系胡耀邦逝世成为本年春夏政治危机的直接背景之一，社会关系与中央决策均受到影响。

4月26日政治进程

人民日报社论对事态作政治定性

地点 / 范围：北京

《人民日报》发表《必须旗帜鲜明地反对动乱》社论，将当时事态定性为政治动乱，反映中央对局势的判断。所据党史资料还记载此前政治局常委讨论与邓小平谈话。这里将社论定性明确归于官方文本，而非以其概括所有参与者的实际动机。

结果与历史联系社论成为理解中央决策、参与者反应和此后危机升级的重要文献节点。

5月13日—19日政治进程

天安门广场绝食请愿

地点 / 范围：北京天安门广场

部分学生在天安门广场开展绝食请愿，政治危机进一步扩大。同期戈尔巴乔夫访华，中苏关系正常化与国内集会示威在同一时段发生。官方年度资料记载了绝食的时间，但其中对参与者的政治判断应与行动事实分开。

结果与历史联系绝食与集会扩大了社会关注度，并与随后中央宣布戒严的决策过程直接相接。

5月16日对外关系

中苏关系实现正常化

地点 / 范围：北京

邓小平会见来访的苏联领导人戈尔巴乔夫，中苏关系实现正常化。此前长期对立的双边关系经过谈判与接触出现转折，成为冷战末期中国外交的重要变化。戈尔巴乔夫访华后发表中苏联合公报，双方国家关系正常化也带动两党关系恢复，结束长期对立的一个重要阶段。

结果与历史联系周边外交环境出现重大转折，为此后的中俄等关系发展提供历史背景。

5月20日10时起法治制度

北京部分地区实行戒严

地点 / 范围：北京市部分地区

国务院总理李鹏签署命令，决定自五月二十日十时起在北京市部分地区实行戒严。政府公报所载报告说明了决定和执行背景，戒严部队开始向市内调动，进城过程中遭到群众阻拦，政治对峙继续。此为五月戒严，不能与六月军队清场合并成同一日。

结果与历史联系政府处置从政治交涉进入戒严和军事部署阶段，首都社会生活与政治危机进一步变化。

6月3日晚—4日凌晨政治进程

戒严部队进城、武力清场与伤亡

地点 / 范围：北京城区道路及天安门广场

戒严部队于六月三日晚向北京市区开进，沿途发生军队开枪、冲突和军民伤亡，四日凌晨进入天安门广场并清场。政府公报中的陈希同报告明确记载军人及非军人的受伤和死亡，并叙述广场撤离过程。该报告将事件称为“反革命暴乱”，这里注明其官方定性口径，不据单一报告断言最终伤亡总数。

结果与历史联系军事镇压结束广场集会，但人员伤亡、中央领导变动与国际反应对中国政治社会生活产生持续影响。

6月23日—24日党的建设

十三届四中全会调整中央领导

地点 / 范围：北京

十三届四中全会撤销赵紫阳所任中央主要职务，选举江泽民为中央委员会总书记。中央领导机构变动是政治风波后的直接政治结果之一。全会增选中央政治局常委并调整书记处成员，提出治理整顿、思想工作和党的建设等任务，政治风波后的中央工作布局由此形成。

结果与历史联系中央领导核心与组织安排发生变化，对九十年代政治与政策延续产生重要影响。

地点 / 范围：北京

11月6日—9日党的建设

十三届五中全会

地点 / 范围：北京

全会通过继续治理整顿和深化改革的决定，同意邓小平辞去中央军委主席职务，决定江泽民任中央军委主席。经济调整与中央军事领导职务交接同会处理。全会提出包括本年在内用三年或更长时间完成治理整顿，同时处理党的中央军委主席交接；国家军委职务则在次年更替。

结果与历史联系中央领导机构继续调整，经济治理整顿也获得更明确的时间安排。

12月26日法治制度

城市居民委员会组织法通过

地点 / 范围：北京

全国人大常委会通过城市居民委员会组织法，为城市基层群众自治组织提供法律依据。它与农村村民委员会制度一道，构成基层自治制度建设的重要内容。

结果与历史联系居民委员会不同于基层政府，需准确区分其组织性质。

12月30日统一战线

完善多党合作和政治协商制度

地点 / 范围：全国

中央发布坚持和完善中国共产党领导的多党合作和政治协商制度的意见，明确这一制度在国家政治生活中的地位，并说明共产党与各民主党派合作的基本方针。文件把长期共存、互相监督、肝胆相照和荣辱与共作为合作方针，明确民主党派在制度内参政议政的基本关系。

结果与历史联系多党合作与政治协商在改革新阶段进一步获得中央制度性文件说明。

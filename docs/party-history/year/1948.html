1948

战略决战与全国政权的准备

解放军逐步取得军事优势，辽沈、淮海、平津三大战役相继展开。中央迁西柏坡，推动新政协、华北政府和币制统一，准备从分区根据地走向全国治理；土地改革纠偏与党委制度建设也回应新的社会和权力问题。

1月起政策建设

纠正土地改革中的过左偏差

地点 / 范围：各解放区

中央和有关领导继续指出土地改革、整党中的过左问题，要求保护中农、区别地主与富农、保护工商业并反对乱打乱杀。政策纠偏反映改革动员与生产、社会稳定之间的复杂关系，地方执行与中央文件之间也存在差异。

结果与历史联系帮助稳定农村联盟和生产，为城市接管与经济恢复减少障碍。

3月23日起组织建设

中央机关转赴西柏坡

地点 / 范围：陕北、晋西北、河北西柏坡

毛泽东等率中央机关与解放军总部东渡黄河，随后到西柏坡同中央工委会合，中央后方委员会等结束原有分工。领导机关重新集中，交通、军政联络与华北根据地条件更加有利，全国战争指挥进入新的阶段。

结果与历史联系西柏坡成为三大战役与筹建新中国的重要中央工作地点。

4月30日统一战线

五一口号与新政协倡议

地点 / 范围：西柏坡、各解放区及香港等

中共中央发布纪念五一劳动节口号，提出召开新的政治协商会议、筹建民主联合政府。各民主党派和社会人士陆续响应，随后经不同路线进入解放区。战争胜利的前景与新的政治制度筹备开始更直接地结合。

结果与历史联系推动多党合作与新政协筹备，为1949年建国形成政治联盟。

5月9日起政策建设

华北机构合并与政府筹建

地点 / 范围：晋察冀、晋冀鲁豫地区

中央决定合并晋察冀和晋冀鲁豫解放区有关领导机构，成立华北局和联合行政机构，9月华北人民政府成立。区域整合使财政、司法、交通和行政政策更便于协调，也为全国政权建设培养制度与干部经验。

9月12日—11月2日军事活动

辽沈战役

地点 / 范围：辽宁、吉林、黑龙江

东北野战军通过锦州、长春、沈阳等方向作战，击败国民党在东北的主要力量，控制东北全境。战役改变全国兵力对比，使东北主力能够随后入关。围困与大规模战斗也给城市和民众造成严重困难，胜利不能只用歼敌数字叙述。

结果与历史联系解放军获得工业和战略后方，全国军事优势发生重要转变。

华东野战军攻取济南，打破国民党在山东的重要城市据点。战役需要攻城、阻援、地下联络和城市接管配合，显示解放军大城市作战能力提升。进入城市后，秩序、生产和居民生活成为与军事胜利相伴的新任务。

9月20日组织建设

健全党委制的决定

地点 / 范围：各级党组织

中共中央要求建立健全党委会议制度，以集体讨论处理重要问题，防止个人包办。随着各地军事和政权规模扩大，组织领导需要明确议事规则。决定强调集体领导，既服务于战争时期协调，也关系未来地方与全国治理。

11月1日军事活动

统一全军组织和番号

地点 / 范围：人民解放军各部

中央军委规定统一全军组织及部队番号，团和分区以上有关单位使用中国人民解放军名称。不同区域长期形成的编制逐步标准化，便于大兵团协同、后勤和人员管理。正式番号的统一与此前解放军称谓的使用有先后区别。

12月1日政策建设

中国人民银行成立并发行人民币

地点 / 范围：河北石家庄

华北地区有关银行合并成立中国人民银行，发行人民币，推动不同解放区货币逐步统一。战争推进使区域财政金融联系更加密切，币制统一需要相应的发行、兑换与管理网络，为此后全国经济恢复奠定基础。

结果与历史联系是从分区经济走向全国金融制度的重要节点。

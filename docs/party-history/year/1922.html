1922

纲领、党章与第一次工运高潮

党开始同时处理全国组织建设、民主革命纲领和群众运动问题。二大形成第一部党章，工运由香港、安源等地向全国发展，党内也讨论通过何种方式同国民党合作。运动有胜利，也有流血和失败。

1月12日起工农运动

香港海员罢工

地点 / 范围：香港、广州

香港海员为增加工资、反对不合理待遇举行罢工，其他行业随后加入。罢工者返广州获得支援，运动最终迫使资方让步。此次行动与内地党组织推动的工人运动相互呼应，开启这一时期全国工运上升的局面。

结果与历史联系罢工取得成果并扩大港穗工人联系，推动全国第一次工运高潮兴起。

1月工农运动

黄爱、庞人铨被杀与抗议

地点 / 范围：长沙

长沙华实纱厂罢工遭镇压，青年团员黄爱、庞人铨被捕后遇害。湖南党组织与各地群众开展抗议和声援。这一事件使组织者直接面对军阀权力对劳动运动的暴力压制，也反映工人经济诉求与当时政治环境难以分割。

结果与历史联系对罢工的镇压激起跨地区抗议，也暴露劳动运动面临的军阀暴力。

5月1日—6日工农运动

第一次全国劳动大会

地点 / 范围：广州

中国劳动组合书记部发起的全国劳动大会在广州召开，来自不同地区和政治背景工会的代表参加。会议讨论工人共同政治要求、劳动条件和团结方式，在分散罢工之外推动全国工会之间建立更有组织的联系。

结果与历史联系建立工会之间更广泛的全国联系，为以后全国总工会成立积累基础。

5月5日—10日组织建设

社会主义青年团一大

地点 / 范围：广州

中国社会主义青年团召开第一次全国代表大会，通过纲领、章程并产生中央领导机构。各地青年团体由此形成全国性的组织联系。青年团同共产党关系密切，但具有自身面向青年开展教育、宣传和组织工作的职责。

结果与历史联系形成全国性的青年团中央组织，增强青年教育与动员的协调。

6月15日思想文献

公开发表对时局的主张

地点 / 范围：上海

中共中央发表《中国共产党对于时局的主张》，把反对外来压迫、军阀统治和建立民主政治联系起来，面向社会表达政党主张。文件所回应的不只是工人待遇，还包括国家统一、政治制度与国内外力量关系等现实问题。

结果与历史联系中共首次公开系统表达现实政治主张，扩大其面向社会的政治活动。

7月16日—23日党的会议

中共二大与首部党章

地点 / 范围：上海

中共二大区分最高与最低纲领，提出反帝反封建的民主革命任务，通过第一部党章并决定加入共产国际。会议产生新的中央执行委员会。与一大相比，它更明确地把长期社会目标和中国当时需要解决的政治任务联系起来。

结果与历史联系把近期革命任务、组织章程和国际组织关系作出较明确规定。

8月29日—30日统一战线

西湖会议讨论党内合作

地点 / 范围：杭州西湖

中央执行委员会在杭州开会讨论同国民党合作的方法，在充分争论后接受党员以个人身份加入国民党的办法。合作以推动国民革命为目标，同时涉及共产党如何保持组织与政治独立的问题，随后成为三大讨论的中心议题。

结果与历史联系推动党员个人加入国民党的合作办法，为次年三大决策作准备。

8月工农运动

劳动立法运动展开

地点 / 范围：上海及各工运地区

劳动组合书记部提出《劳动法大纲》，围绕组织自由、工作时间、劳动待遇和工人教育提出要求，并推动劳动立法运动。它将具体罢工中的诉求概括为更普遍的劳动权利议程，尝试通过社会动员扩大工运影响。

结果与历史联系把工厂中的具体诉求上升为劳动权利议程，扩大工运社会影响。

9月13日思想文献

《向导》周报创刊

地点 / 范围：上海

中共中央机关报《向导》开始出版，讨论时局、革命纲领和群众斗争等问题。报刊成为分散各地组织共享政治判断、回应社会争论的媒介。它同此前的思想启蒙刊物有所承接，也更突出全国性政党的政治宣传需要。

结果与历史联系建立持续的中央机关报传播渠道，使地方组织更及时共享政治主张。

9月14日—18日工农运动

安源路矿罢工获胜

地点 / 范围：江西萍乡安源

安源煤矿与株萍铁路工人举行罢工，要求改善待遇、保障组织权利和改变把头压迫。当地党组织通过工人俱乐部等开展组织工作，罢工后资方接受主要条件，俱乐部得到巩固。运动由此成为早期中共工运的重要经验。

结果与历史联系巩固安源工人俱乐部，形成教育、组织和罢工谈判相结合的实践经验。

10月16日—11月19日工农运动

开滦五矿同盟罢工

地点 / 范围：河北唐山、开滦矿区

开滦多矿工人为劳动条件与待遇举行联合罢工，遭矿方和军警压制，发生流血伤亡。罢工未实现预定目标，但将大型矿区的工人组织问题带到全国视野。应把它同安源的不同结果对照，避免把第一次工运高潮写成连续胜利。

结果与历史联系虽未达到目标，联合罢工仍扩大矿区工人的组织联系，并显示斗争环境的严酷。

6月27日科技文化

蛟龙号下潜七千米级

地点 / 范围：海洋试验区

蛟龙号载人潜水器下潜达到七千零六十二米，推进中国深海载人科研与勘探能力。任务综合检验潜水器、母船保障和深海作业系统。七千米级能力使潜水器能到达更广泛深海区域，科研任务涉及样品、环境和海底观察，技术纪录背后是装备和科研系统协作。

结果与历史联系深海科学研究与资源调查的实际作业范围进一步拓展。

9月25日国防军事

辽宁舰交付海军

地点 / 范围：中国

中国第一艘航空母舰辽宁舰交付海军，胡锦涛出席仪式。航母平台入列后，舰载航空、人员训练和保障体系仍需持续建设。辽宁舰由平台入列进入训练和保障体系建设，舰载机、人员和编队能力逐渐配套，航母发展由技术准备转向实际部队运行。

结果与历史联系中国海军开始形成航空母舰这一新的装备和训练体系。

11月8日—14日党的建设

中国共产党第十八次全国代表大会

地点 / 范围：北京

十八大确定全面建成小康社会与深化改革目标，把科学发展观确立为指导思想并写入党章。大会从道路、理论和制度关系出发部署下一阶段任务。大会将全面建成小康社会与深化改革相联系，把道路、理论和制度共同作为中国特色社会主义的基本内容，选举产生新的中央委员会。

结果与历史联系为后续领导交接和现代化建设新阶段确立政治与组织基础。

11月15日党的建设

十八届一中全会

地点 / 范围：北京

全会选举习近平为总书记，决定其任中央军委主席，选举新一届中央政治局常委并批准王岐山任中央纪委书记，完成党的中央领导机构交接。新当选常委包括习近平、李克强、张德江、俞正声、刘云山、王岐山和张高丽，习近平同时在与记者见面时说明施政目标。

结果与历史联系中央领导机构实现交接，新一届中央的工作部署开始展开。

12月4日党的建设

中央八项规定通过

地点 / 范围：北京

中央政治局通过改进工作作风、密切联系群众的八项规定，对调查研究、会议活动、公务接待等作出要求。中央领导机关从自身工作方式入手推进作风整顿。规定针对调查研究、会议文件、出访和公务活动等具体行为，要求中央政治局先作示范，作风整顿从领导机关的日常运作入手。

结果与历史联系公务行为与群众关系成为此后全面从严治党和反腐败的重要切入点。

12月7日—11日改革开放

习近平考察广东强调继续改革

地点 / 范围：广东

习近平在广东考察，讨论改革进入深水区后的利益和体制问题，强调继续推进重要领域改革。新一届中央领导对改革开放延续性作出政治表达。考察把广东这一改革先行地区同全国改革任务联系，指出改革深化将涉及利益调整和制度障碍，需要继续突破而不是停留在既有成绩。

结果与历史联系新一届中央对改革延续性作出明确表达，为次年全面深化改革部署形成背景。

12月29日经济社会

关注农村特别是贫困地区小康

地点 / 范围：河北

习近平考察河北时强调，全面小康的难点在农村和贫困地区。发展目标由总体指标进一步落实到地区与群体差异，为后来精准扶贫部署提供背景。讲话把贫困地区和农村视为全面小康的薄弱环节，要求不以总体增长掩盖群体和地域差异，后来精准扶贫理念进一步展开。

结果与历史联系减贫和农村公共服务成为全面小康实现过程中的突出任务。

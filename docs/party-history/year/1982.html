1月1日改革开放

一号文件肯定农村责任制

地点 / 范围：全国农村

中共中央批转全国农村工作会议纪要，肯定包产到户等责任制属于社会主义集体经济的生产责任制。地方农民与基层干部的实践，由此获得更清晰的中央政策支持。文件没有将包产到户简单视为脱离集体经济，而是给不同责任制实践作制度解释；随后数年中央连续发布农村工作一号文件。

结果与历史联系农户经营预期和生产主动性获得政策支持，农村改革从地方探索进一步推广。

1月11日统一战线

提出“一国两制”概念

地点 / 范围：北京

邓小平会见李耀滋时提出“一个国家，两种制度”的概念，探索统一国家内部不同制度并存的安排。相关政策后来在对台、香港和澳门问题上进一步展开。概念先针对统一问题提出，随后结合台湾和香港问题继续阐明，允许同一国家内部在特定条件下实行不同社会制度。

结果与历史联系为解决香港澳门问题提供制度思路，也持续构成中央对台政策的重要内容。

1月13日党的建设

提出干部队伍“四化”

地点 / 范围：北京

邓小平在中央政治局扩大会议上提出干部队伍革命化、年轻化、知识化、专业化的方针。它回应了现代化建设对知识、年龄结构和专业能力的新要求。干部“四化”把政治要求与年龄、知识和专业能力结合，反映经济科技管理日益复杂后，组织工作需要适应现代化建设。

结果与历史联系干部选拔和培养更加关注专业素质及队伍结构，配合领导制度更新。

2月20日党的建设

建立老干部退休制度

地点 / 范围：全国

中共中央作出关于建立老干部退休制度的决定，使干部退出日常领导岗位逐步有制度依据。它与干部年轻化相配合，推动领导职务终身化问题的解决。退休制度为老干部退出领导岗位提供程序条件，也给年轻和专业干部成长腾出空间，改变职务长期由个人占据的传统安排。

结果与历史联系推动干部领导职务终身制问题的解决，使组织更新逐步制度化。

8月17日对外关系

中美发表八一七公报

地点 / 范围：北京、华盛顿

中美两国政府发表联合公报，讨论美国向台湾出售武器问题。公报成为中美关系的重要政治文件之一，反映台湾问题对双边关系持续产生的影响。

结果与历史联系中美合作与分歧同时存在，建交并不意味着关键争议自动消失。

9月1日—11日党的建设

中国共产党第十二次全国代表大会

地点 / 范围：北京

十二大讨论现代化建设方向，邓小平在开幕词中提出建设有中国特色的社会主义。大会通过新党章，提出世纪末经济发展目标，并决定设立中央顾问委员会。大会报告提出到世纪末工农业年总产值翻两番的分步目标，通过新党章；中央顾问委员会的设立则服务于新老干部交替的过渡安排。

结果与历史联系大会把新的道路概括、经济目标和党内组织安排联系起来，形成改革初期的总体部署。

9月12日—13日党的建设

十二届一中全会

地点 / 范围：北京

全会选举胡耀邦为中央委员会总书记，决定邓小平任中央军委主席，并批准中央顾问委员会和中央纪律检查委员会有关领导人选。中央领导体制在十二大后形成新安排。

结果与历史联系党内各领导机构职责不同，人物职务需按当年准确区分。

9月24日对外关系

中英开始就香港问题高层接触

地点 / 范围：北京

邓小平会见英国首相撒切尔夫人，说明中国恢复对香港行使主权的立场。会谈是香港问题谈判的重要起点，正式联合声明则在1984年签署。中方在会见中明确一九九七年收回香港的立场，谈判不只涉及行政管理，也触及主权、过渡和未来制度安排。

结果与历史联系香港问题进入正式高层磋商阶段，为两年后的联合声明创造条件。

10月12日国防军事

潜艇水下发射运载火箭成功

地点 / 范围：预定海域

中国首次以潜艇从水下向海上预定目标区发射运载火箭并取得成功。这是水下平台、火箭系统及保障体系相结合的试验，显示海基战略技术的发展。

结果与历史联系国防科技工程通常经过多阶段试验，单次成功不等于全部建设完成。

12月4日法治制度

现行宪法通过并施行

地点 / 范围：北京

五届全国人大五次会议通过全面修改后的宪法，重新安排国家主席、国家中央军委及其他国家机构，明确特别行政区等制度。它构成此后国家制度运行的重要法律基础。宪法还明确国家可以在必要时设立特别行政区，调整农村政社合一体制；这些规定后来与港澳制度和乡镇政权改革相衔接。

结果与历史联系国家机构与重要社会制度重新获得宪法规范，奠定此后法制建设的重要基础。

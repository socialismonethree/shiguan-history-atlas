3月5日、11月18日科技文化

八六三计划形成

地点 / 范围：北京

四位科学家建议加强高技术研究，邓小平作出批示；同年11月，中央和国务院转发高技术研究发展计划纲要。计划名称源自首次批示的1986年3月。王大珩、王淦昌、杨嘉墀和陈芳允的建议进入中央决策，计划着眼跟踪世界高技术发展，采用国家组织的研究布局。

结果与历史联系形成面向长期技术能力的重大科研计划，连接科学家建议与国家战略资源。

4月12日法治制度

义务教育法等法律通过

地点 / 范围：北京

六届全国人大四次会议通过义务教育法、民法通则和外资企业法。基础教育、民事关系及外资经营分别获得法律制度支持，反映改革对不同领域法制建设的需求。三部法律分别服务于受教育权、民事交往和外资经营，体现现代化需要在教育、社会关系与开放领域同时补足法律制度。

结果与历史联系法律建设覆盖面扩大，为经济活动与公共服务提供不同层次的规则支持。

7月8日科技文化

国内卫星通信网建成

地点 / 范围：全国

中国国内卫星通信网正式建成，卫星技术与地面通信系统形成连接。它使此前的卫星发射成果进一步转化为实际通信能力，为跨地区信息传输提供条件。

结果与历史联系科技工程的意义需要从研制成功与实际应用两个阶段考察。

8月10日国防军事

预备役部队列入解放军建制

地点 / 范围：全国

军队有关总部发出通知，规定预备役部队正式列入人民解放军建制。军队组织体系由此进一步明确现役力量与后备力量之间的关系。

结果与历史联系国防建设包含后备力量制度，并不限于常备部队建设。

9月15日党的建设

出台国有工业企业基层组织条例

地点 / 范围：全国

中央印发全民所有制工业企业基层党组织工作条例。在企业经营机制改革背景下，党的基层组织如何开展工作成为需要明确制度的问题。

结果与历史联系经济体制变化也带来企业内部领导关系和组织工作方式的调整。

9月28日思想理论

十二届六中全会讨论精神文明

地点 / 范围：北京

全会通过社会主义精神文明建设指导方针决议，讨论其战略地位、任务和基本方针。现代化建设的目标由此同时强调物质生产、思想文化和社会风气。决议说明精神文明建设的地位、任务与指导方针，并把社会风气和党风改善同经济发展环境联系，强调二者不能脱节。

结果与历史联系物质建设之外的公共价值、文化和社会风气成为国家发展安排的重要部分。

12月5日改革开放

继续推进企业改革

地点 / 范围：全国

国务院发布深化企业改革、增强企业活力的规定，延续扩大自主权等探索。城市改革逐步从单项措施走向企业经营机制的综合调整。此前放权、利改税等措施已改变部分经营关系，国务院继续要求完善企业经营条件，回应企业活力不足和管理机制问题。

结果与历史联系改革持续向企业日常经营和资源配置深入，为后续市场体制探索积累经验。

12月30日思想理论

提出反对资产阶级自由化

地点 / 范围：北京

邓小平在与中央负责同志谈话时重申四项基本原则，提出反对资产阶级自由化。随后中央于1987年发出相关通知，政治思想讨论与改革进程继续相互影响。

结果与历史联系理解这一时期需同时看经济改革推进与政治思想领域的争论。

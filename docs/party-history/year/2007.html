3月16日法治制度

物权法与企业所得税法通过

地点 / 范围：北京

全国人大通过物权法和企业所得税法，分别规范财产权利和企业税收安排。市场经济发展需要明确产权关系，也需要使不同企业适用更统一的税收规则。物权法明确财产关系的基本规则，企业所得税法推进内外资企业税收制度统一，两部法律分别回应市场主体交易和公平竞争需求。

结果与历史联系产权保护和统一税制进一步完善市场经济的制度基础。

4月14日科技文化

北斗二号首星发射

地点 / 范围：中国

中国发射北斗二号首颗导航卫星，开始第二代卫星导航系统建设。导航系统从早期探索继续迈向更大覆盖范围和持续服务能力。

结果与历史联系卫星导航需要星座、地面系统和应用共同发展。

6月3日经济社会

发布应对气候变化国家方案

地点 / 范围：全国

国务院印发应对气候变化国家方案，把温室气体问题、能源利用和发展方式放在政策框架内。气候治理开始形成较完整的国内行动安排。

结果与历史联系环境政策进一步与全球议题及国家发展战略相联系。

7月10日经济社会

城镇居民医保试点

地点 / 范围：全国相关城市

国务院部署城镇居民基本医疗保险试点，着重回应此前未被职工医保覆盖人群的医疗保障问题。医保制度由职工保障进一步向更广泛居民延伸。试点主要面向此前未纳入职工医保的城镇居民，制度要逐步形成筹资、管理与报销机制，再通过各地实践扩大覆盖。

结果与历史联系城镇医疗保障由就业单位向居民身份扩展，为城乡医保整合提供经验。

7月11日经济社会

全国建立农村最低生活保障

地点 / 范围：全国农村

国务院要求在全国建立农村最低生活保障制度，将符合条件的农村贫困人口纳入保障。城乡社会救助体系的覆盖由此进一步扩大。通知把符合条件的农村贫困人口作为保障对象，低保与产业扶贫、救济等方式各有功能，共同回应基本生活和发展能力问题。

结果与历史联系农村社会救助形成全国性制度，兜底保障与开发式扶贫相互补充。

8月30日法治制度

反垄断法与就业促进法通过

地点 / 范围：北京

全国人大常委会通过反垄断法和就业促进法，一方面维护市场竞争，另一方面明确促进就业的制度责任。改革中的效率与社会保障需要共同处理。

结果与历史联系市场竞争秩序和劳动者就业权益同时进入法律建设。

10月15日—21日党的建设

中国共产党第十七次全国代表大会

地点 / 范围：北京

十七大系统说明科学发展观，提出全面建设小康社会的新任务，并把科学发展观写入党章。经济社会快速发展中的不平衡问题被纳入大会对发展道路的讨论。报告说明科学发展观的发展、以人为本、协调可持续与统筹兼顾等内容，提出实现全面小康的新要求，并形成新一届中央委员会。

结果与历史联系党的发展理念更系统关注人的生活、社会结构和资源环境条件。

2月27日思想文化

讨论正确处理人民内部矛盾

地点 / 范围：北京

毛泽东发表有关如何处理人民内部矛盾的讲话，讨论社会主义社会矛盾与不同性质问题的处理方法。讲话后来修订发表，研究时应区别现场讲话时间、文本修改和正式刊布三个环节。

结果与历史联系理论上区分不同矛盾，原本有助于防止把一般意见分歧当成敌我冲突。

4月20日社会民生

部署消灭血吸虫病

地点 / 范围：全国相关疫区

国务院发出防治血吸虫病的指示，推动查病、治疗、灭螺和环境整治等工作。疾病流行与水利、农业生产及居民生活密切相关，因此防治必须依靠医疗与社会措施配合。

结果与历史联系这一行动展示预防为主的公共卫生方针如何落实到具体传染病治理。

4月25日经济建设

首届广交会举办

地点 / 范围：广东广州

中国出口商品交易会在广州举办，组织国内产品展示并接洽海外客商。此后广交会形成定期举行的贸易平台，在对外经济联系受到冷战环境限制时，仍提供商贸往来窗口。

结果与历史联系对外贸易并非改革开放后才开始，早期贸易形式与后来的开放程度需要区分。

4月27日党的建设

全党整风运动部署

地点 / 范围：全国

中央要求以整顿作风、克服官僚主义等问题为内容开展整风，鼓励对党政工作提出意见。运动原有改善工作和处理社会矛盾的目标，但在随后形势判断变化中迅速转向反右斗争。

结果与历史联系把整风和反右按时间分开，才能理解政策初衷、转向及其后果之间的关系。

6月起历史曲折

反右派斗争严重扩大化

地点 / 范围：全国

整风过程中出现的意见被越来越多地按敌我问题处理，大批知识分子、干部和普通群众被错划为右派。1981年历史决议明确指出反右派斗争被严重扩大化，后续几十年的人生和社会生活因此受到影响。

结果与历史联系对这一事件应讲清错划与迫害造成的长期伤害，不能把全部受影响者笼统当作敌对分子。

10月15日经济建设

武汉长江大桥通车

地点 / 范围：湖北武汉

武汉长江大桥举行通车典礼，京汉、粤汉铁路通过桥梁衔接，公路交通也获得跨江通道。大桥建设需要桥梁设计、钢材制造和水下施工等技术配合，是早期重大基础设施成果。

结果与历史联系跨江交通改善运输网络，说明基础设施对全国统一市场和工业布局的重要作用。

11月2日—21日外交

毛泽东再次访问苏联

地点 / 范围：苏联莫斯科

毛泽东率团参加十月革命四十周年活动，并出席各国共产党和工人党代表会议。中国同社会主义国家的政治联系仍居重要地位，但后来中苏关系走向分歧，需要同这一时期的合作相区别。

结果与历史联系国际会议是理解冷战格局和社会主义国家间关系的重要现场。

本年经济建设

第一个五年计划完成

地点 / 范围：全国

一五计划到年底完成，钢铁、机械、能源和交通等基础部门能力明显扩展，一批现代工业企业建成。工业化取得初步基础，但农业、消费、技术人才和经济比例仍是此后建设必须面对的问题。

结果与历史联系评价一五既要看到工业体系增长，也要避免把初步工业基础等同于全面现代化。

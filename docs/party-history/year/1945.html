YEARLY ARCHIVE / 年度档案
1945

抗战胜利与和平建国之争

七大和第一个历史决议加强党内政治与组织统一。日本投降结束长期抗战，受降与地区控制随即成为国共竞争焦点。重庆谈判达成双十协定，但军队、政权等核心分歧仍在，民众争取和平民主的运动继续增长。

4月20日思想文献

通过第一个历史决议

地点 / 范围：延安

六届七中全会原则通过《关于若干历史问题的决议》，集中总结建党以来尤其土地革命时期的路线问题。决议在整风基础上促进高级干部统一认识，也为对犯错同志采取团结方针提供政治基础。它不是对全党历史所有问题的最终穷尽。

结果与历史联系为七大召开减少党内历史分歧，形成新的政治与组织团结。

4月23日—6月11日党的会议

中共七大

地点 / 范围：延安

七大讨论抗战胜利前后的政治方向，通过新党章，确立毛泽东思想为党的指导思想并选举中央委员会。毛泽东作政治报告，刘少奇作党章修改报告，朱德作军事报告。会议把党的自身建设同民主联合政府和全国政治任务联系起来。

结果与历史联系在抗战胜利前形成较完整的政治纲领和组织安排，扩大党的全国影响。

4月24日思想文献

《论联合政府》报告

地点 / 范围：延安

毛泽东向七大提出政治报告，分析抗战形势与战后道路，主张建立民主联合政府，并讨论新民主主义政治、经济和文化。报告既回应民族战争的结束前景，也回应中国内部民主改革的要求，为中共随后同国民党谈判提供政治依据。

结果与历史联系使战后政权安排成为中共公开政治纲领的重要内容。

6月19日党的会议

七届一中全会

地点 / 范围：延安

新一届中央委员会召开全会，选举中央政治局和书记处等，毛泽东任中央委员会主席、政治局主席和书记处主席。五位书记形成七大后中央日常领导核心。组织程序承接党章与大会选举，为战后迅速变化的形势提供统一领导。

结果与历史联系明确七大后中央领导结构，与此前临时和战时安排形成制度性衔接。

8月9日起军事活动

对日全面反攻部署

地点 / 范围：延安及各解放区

在苏联对日作战和国际战局变化中，毛泽东发表对日最后一战的声明，朱德连续发布反攻命令。各解放区部队向日伪据点和交通线推进，争取受降、恢复地区并扩大力量。军事行动与战后控制权问题随即相互交织。

结果与历史联系抗日胜利临近，同时开启国共双方争取受降与地区控制的竞争。

8月15日、9月2日历史转折

日本宣布并正式签署投降

地点 / 范围：中国及世界反法西斯战场

日本于8月15日宣布接受投降条件，9月2日签署投降书，长期抗战取得胜利。中国军民付出巨大牺牲，中共领导的敌后抗战、国民党正面战场以及海内外多种力量均为抵抗作出贡献。9月3日后来成为中国抗战胜利纪念日。

结果与历史联系民族解放斗争取得重要胜利，但国内和平与战后制度仍有待解决。

8月28日—10月10日统一战线

重庆谈判与双十协定

地点 / 范围：重庆

毛泽东等赴重庆同国民党谈判，讨论和平建国、军队和解放区等问题，双方签署会谈纪要。协定确认和平民主方向，但重大军事、政权分歧未获彻底解决。谈判期间地方冲突仍在持续，协议文本同其后实际执行应分别考察。

结果与历史联系为和平建国提供一度可能，也使国共核心分歧更公开地呈现。

9月19日军事活动

向北发展、向南防御

地点 / 范围：延安、东北和华北

中共中央确定向东北、华北发展力量的战略，调派大批干部和部队进入东北，同时调整南方部队部署。东北工业、地理和苏军进驻后的局势，使该地区成为战后竞争的重要方向。战略部署并非各地同时照同一路线移动。

结果与历史联系改变战后全国力量分布，为东北根据地和解放战争战略格局创造条件。

9月21日军事活动

编组野战军

地点 / 范围：各解放区

中央书记处部署扩兵与编组野战军，推动部队由分散游击编制向较集中机动作战组织转变。抗战后期成长的地方武装需要整编、训练和统一指挥，才能适应战后大规模军事冲突的可能性。组织转型伴随政治工作与后勤调整。

结果与历史联系为由抗日游击战争转向解放战争中的运动战作组织准备。

10月25日历史转折

台湾受降

地点 / 范围：台湾、澎湖

中国政府在台湾举行受降仪式，日本在台湾长达半个世纪的殖民统治结束，台湾和澎湖回到中国主权管辖之下。该事件属于抗战胜利后的受降安排，同内地国共谈判和新的政治竞争处于同一战后时段。

结果与历史联系为理解抗战胜利、台湾历史与战后国家格局提供重要节点。

11月工农运动

一二·一运动

地点 / 范围：云南昆明

昆明学生反对内战、要求民主的集会和罢课遭到镇压，发生一二·一惨案。学生与教师继续抗议，运动获得各地声援。和平民主诉求在社会中扩大，显示国共谈判之外，知识界和青年也在积极参与决定战后中国的道路。

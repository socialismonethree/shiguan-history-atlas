1月26日经济建设

五反运动启动

地点 / 范围：全国大中城市

中央要求在大中城市开展反行贿、反偷税漏税、反盗骗国家财产、反偷工减料和反盗窃经济情报的斗争。运动主要针对工商领域违法行为，到当年10月结束，同三反运动的对象和任务有所区别。

结果与历史联系五反影响了国家与私营工商业的关系，并与随后工商业社会主义改造相衔接。

4月5日经济建设

荆江分洪工程开工

地点 / 范围：湖北荆江地区

治理长江水患的荆江分洪一期工程全面施工，工程通过设置分洪蓄洪设施分担干流洪水压力。它需要河道、堤防、居民迁移及施工组织配合，体现新中国早期大型水利建设的统筹动员。

结果与历史联系分洪工程是流域防洪体系的一环，不能把防洪效果归于某一个孤立设施。

4月21日法治制度

惩治贪污条例公布

地点 / 范围：全国

中央人民政府公布惩治贪污条例，把对公共财产侵占和贪污行为的惩处纳入法规。条例出台同当时三反运动相联系，也说明仅靠政治动员之外，国家开始以法律形式规定相关犯罪和责任。

结果与历史联系这是观察新中国早期反腐与法律制度建设关系的重要法律文本。

6月10日社会民生

全国体育组织建设推进

地点 / 范围：北京

中华全国体育总会成立大会期间，毛泽东提出发展体育、增强体质的要求。体育逐渐进入群众生活、学校教育和国家政策安排，既有竞技体育组织，也包括面向普通人的身体锻炼。

结果与历史联系这一节点反映国家建设议程包含人口健康与群众体育，而不只有生产指标。

7月1日经济建设

成渝铁路通车

地点 / 范围：四川、重庆

成渝铁路建成，成都与重庆之间获得铁路干线联系。这条铁路由新中国自行组织建设并使用国产材料，工程跨越复杂地形，是西南地区交通网络扩展的重要起点。

结果与历史联系铁路改善沿线人员与物资运输条件，也为西南工业布局提供交通支撑。

8月9日民族与统一

民族区域自治实施纲要公布

地点 / 范围：全国

实施纲要对民族自治地方的设立、自治机关组成及自治权利作出规定。它把共同纲领中的民族政策进一步转化为可执行的制度安排，此后各自治区的建立仍经历不同时间和过程。

结果与历史联系民族区域自治是一项制度建设，不能把所有民族地区的建制时间写成同一年。

年底经济建设

大陆土地改革基本完成

地点 / 范围：中国大陆农村

经过分地区推进，除部分少数民族地区外，中国大陆土地改革基本完成。农民获得土地及相应生产资料，农村土地占有结构发生变化；农业生产组织此时仍与后来高级合作社、人民公社有根本区别。

结果与历史联系土地改革结束与农业合作化兴起之间存在制度转换，不应把几个阶段合并叙述。

年底经济建设

国民经济恢复任务基本完成

地点 / 范围：全国

工农业生产在战争破坏后的基础上恢复并实现增长，交通和市场联系也得到重建。财政经济统一、物价稳定与生产恢复相互作用，国家由恢复阶段转向工业化计划建设的条件逐渐形成。

结果与历史联系1952年常被用作后续建设的比较基期，统计应注意当年价格和可比口径。

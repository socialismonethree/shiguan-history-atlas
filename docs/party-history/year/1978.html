历史转折与改革开放起步

真理标准讨论推动思想解放，科学教育和干部政策恢复，十一届三中全会作出工作中心转移和改革开放的重大决策。国家由长期政治运动走向以现代化建设为中心的新时期。

1月28日党的建设

推动重新安排被闲置干部

地点 / 范围：北京

中央组织部召集国家机关有关负责人讨论待分配干部工作，强调干部是国家宝贵力量，应依据实际安排岗位。此前长期受审查或下放的人员逐步获得复查与重新工作机会，专业管理力量开始回流。

结果与历史联系人才恢复补充了建设所需干部，也为更广泛平反工作建立组织基础。

4月5日起历史曲折

摘帽与错划右派改正

地点 / 范围：全国

中央批准摘掉全部右派帽子的报告，随后要求对错划者进行改正。摘帽与改正原有错误结论是不同工作，前者于当年基本完成，后者持续至1980年，许多受害者得以恢复名誉与工作。

结果与历史联系这一过程修复反右扩大化造成的重大伤害，推动有错必纠原则在全国落实。

5月24日法治制度

人民检察院重新设置

地点 / 范围：全国

中央根据新宪法通知重新设置人民检察院，恢复同公安机关、人民法院既配合又制约的司法职能。文革中遭破坏的检察体系开始重建，为纠正冤案和恢复法律监督准备组织条件。

结果与历史联系公检法正常分工逐步恢复，国家治理开始重新重视法制和程序保障。

5月27日—6月5日思想文化

文艺团体恢复工作

地点 / 范围：北京及全国

全国文联召开扩大会议，文联、作协、音协、剧协、影协、舞协等恢复工作。文艺界逐步清理政治迫害和单一创作模式的影响，作品、组织交流与专业讨论开始恢复。

结果与历史联系文艺生态重新获得较多发展空间，为新时期文学艺术的繁荣准备人才与机构条件。

中美公布建交公报

地点 / 范围：北京、华盛顿

中美宣布自1979年1月1日起相互承认并建立外交关系，美国同时宣布结束同台湾当局的所谓外交关系。自1972年开始的正常化谈判取得实质结果，双方随后建立正式使馆和国家间关系。

结果与历史联系建交改善中国外部环境，为扩大国际经济、科技与教育交流提供重要条件。

12月18日—22日党的建设

十一届三中全会召开

地点 / 范围：北京

全会停止使用以阶级斗争为纲的口号，决定把党和国家工作中心转向经济建设，实行改革开放，强调民主集中制和健全法制。中央纪律检查委员会重新成立，陈云任第一书记，历史遗留问题继续得到处理。

结果与历史联系全会开启改革开放和社会主义现代化建设新时期，思想、政治与组织路线出现重大转折。

12月23日经济建设

宝山钢铁总厂动工

地点 / 范围：上海

宝山钢铁总厂举行动工典礼，项目引进国外先进技术和设备，建设现代大型钢铁联合企业。工程经历后续调整和分期投产，涉及产业能力、技术引进、资金及配套管理等多方面安排。

结果与历史联系宝钢成为改革开放初期技术引进与工业升级的代表项目，也暴露大型工程论证和管理的重要性。

12月24日历史曲折

彭德怀陶铸追悼与恢复名誉

地点 / 范围：北京

中央为彭德怀和陶铸举行追悼大会，恢复他们的名誉，否定此前强加的错误政治结论。对已逝受害者的平反与大批在世干部复查相互推进，体现从政治标签回到事实依据的转变。

结果与历史联系重大冤案纠正有助于恢复党内民主和社会信任，也把历史教训带入新时期制度建设。

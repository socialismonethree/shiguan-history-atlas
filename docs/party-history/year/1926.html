1926

北伐推进与合作危机

北伐改变军阀割据的军事格局，推动两湖工农运动迅速增长。但中山舰事件、整理党务案和群众运动触及的社会利益，使国共合作内部的裂痕扩大。阅读时需同时看到前线胜利与政治危机。

2月21日—24日党的会议

中央特别会议讨论北伐

地点 / 范围：北京

中央特别会议分析军阀战争、广州政府处境和全国革命形势，讨论从不同方面为北伐作准备。会议所面对的是南北军事力量交错的局面，既涉及国民革命军的行动，也涉及沿途群众组织和地方工作的配合。

结果与历史联系中央把北伐同地方组织、工农动员相联系，推动政治军事准备。

3月18日工农运动

三一八惨案

地点 / 范围：北京

北京群众因反对列强最后通牒举行集会和请愿，执政府卫队向请愿者开枪，造成大量死伤。中共北方区委等参与组织抗议，并继续揭露镇压。事件表明北方反帝运动同反对军阀政府的斗争密切交织。

结果与历史联系请愿遭血腥镇压，激化北方反帝与反军阀斗争，造成重大人员伤亡。

3月20日统一战线

中山舰事件

地点 / 范围：广州

蒋介石以中山舰行动为由实行戒严，拘押李之龙、监视共产党人并解除部分工人纠察队武装。中共与苏联顾问未能有效制止其扩大权力。事件改变广东革命阵营的力量关系，预示国共合作中的裂痕日益显露。

结果与历史联系蒋介石扩大军权并压缩共产党活动空间，国共合作出现严重危机。

5月3日—9月11日工农运动

毛泽东主持第六届农讲所

地点 / 范围：广州

第六届农民运动讲习所由毛泽东任所长，招收来自多省的学员。课程与调查、组织训练相结合，结业人员分赴地方推动农会工作。农运人才培养与北伐进程相互衔接，成为工农群众运动快速扩展的重要条件。

结果与历史联系培养一批分赴各地的农运干部，为北伐时期农村组织增长提供人才。

5月15日—22日统一战线

整理党务案限制合作

地点 / 范围：广州

国民党二届二中全会通过整理党务案，限制共产党人在国民党高级机构任职的比例和活动空间。蒋介石由此进一步控制党务与军权。共产党人在统一战线中的政治影响受到压缩，如何应对退让与独立性问题更加尖锐。

结果与历史联系共产党人在国民党内的任职与活动受到进一步限制，双方力量关系失衡。

7月9日军事活动

国民革命军誓师北伐

地点 / 范围：广州至湖南、湖北等

国民革命军正式出师北伐，主要攻击吴佩孚、孙传芳等军阀势力。共产党人参与军队政治工作并发动工农支援。军事推进为群众运动创造条件，农会、工会的活动反过来提供交通、情报与物资等支持。

结果与历史联系军阀主要势力受到打击，工农运动随军事推进在更多地区高涨。

8月—10月军事活动

叶挺独立团参与攻克武汉

地点 / 范围：汀泗桥、贺胜桥、武汉

北伐军接连突破汀泗桥、贺胜桥等要地，随后攻占武汉三镇，吴佩孚主力遭到重创。叶挺独立团在多次战斗中承担重要任务。随着军事胜利，湖北工人、农民运动迅速扩大，武汉逐渐成为全国政治活动的重要中心。

结果与历史联系北伐军取得武汉并重创吴佩孚，湖北成为革命政治与群众活动的重要区域。

8月4日组织建设

中央发布反贪腐通告

地点 / 范围：上海

中共中央向党内发出通告，要求清除贪污腐化者。随着共产党人在革命政府、军队和群众机构中承担更多职务，如何约束权力、保持组织纪律成为现实问题。该文件为观察早期党内纪律建设提供了明确的文献节点。

结果与历史联系随着革命机构中的党员增多，反贪腐纪律成为党的明确组织要求。

10月24日工农运动

上海工人第一次武装起义

地点 / 范围：上海

上海工人配合北伐形势发动武装起义，但组织准备和群众发动不足，行动很快失败。失败后中共并未停止城市工作，而继续调整联络与组织。它是翌年第二、第三次武装起义的前奏，不能只从后来第三次成功倒推过程。

结果与历史联系城市武装起义首次受挫，组织者继续调整准备，为次年后续行动积累经验。

10月—年底工农运动

两湖农民运动迅速扩大

地点 / 范围：湖南、湖北

北伐军进入两湖后，农会大规模发展，农民要求打击土豪劣绅、改变租税与乡村权力关系。这些斗争触动地主以及部分国民党军政人员利益，统一战线内部的社会分歧更趋明显。农民运动的地位成为党内外争论焦点。

结果与历史联系农会挑战旧乡村权力，扩大群众力量，也加深与部分军政阶层的利益冲突。

1934

反“围剿”失利与长征开始

中央苏区的政权建设在战争重压下继续，反“围剿”却走向失败。红六军团、中央红军、红二十五军先后转移，南方留守力量继续游击。湘江战役的惨重损失促使战略方向调整，黎平会议开启重要变化。

1月15日—18日党的会议

六届五中全会

地点 / 范围：江西瑞金

中央全会讨论政治形势、苏维埃运动与工会工作，并调整领导机构。会议仍错误估计革命形势，在若干政策上强化“左”的要求。它召开于第五次反“围剿”日趋困难之时，却未能有效纠正军事和政治路线的问题。

结果与历史联系错误估计形势和政策要求继续强化，未能有效扭转反“围剿”的被动局面。

1月22日—2月1日党的会议

第二次全国苏维埃代表大会

地点 / 范围：江西瑞金

大会听取政权、军事和经济工作报告，修改有关制度文件，选举新的中央执行委员会。土地、劳动、教育和民生等成为政权工作的重要内容。大会说明苏区虽处战争压力之下，仍在探索较完整的行政和社会治理制度。

结果与历史联系苏区政权在行政、劳动、教育和经济等领域继续形成制度与干部经验。

4月20日统一战线

对日作战基本纲领发表

地点 / 范围：上海及各地

中国共产党推动形成抗日政治纲领，由宋庆龄、何香凝等社会人士签名发表，主张武装自卫、驱逐日本侵略者。相关组织随后展开联络。它说明在内战仍持续时，跨党派的民族救亡议程已经发展，并逐渐寻求更广泛社会支持。

结果与历史联系抗日政治倡议获得跨党派人士签名，扩大救亡联合的社会范围。

7月军事活动

北上抗日先遣队出发

地点 / 范围：江西瑞金至闽浙皖赣

红七军团改编为北上抗日先遣队，离开中央苏区，向闽浙皖赣活动，兼有牵制敌军和扩大抗日影响的任务。后来与方志敏部会合组成红十军团。部队在围堵下遭严重损失，先遣行动不能写作已打通直接抗日战线。

结果与历史联系红十军团形成并继续牵制敌军，但围堵最终造成严重人员损失。

8月7日起军事活动

红六军团西征

地点 / 范围：湘赣至湘鄂川黔边

红六军团由湘赣根据地突围西进，10月同贺龙率领的红三军会师。红三军恢复红二军团番号，双方随后发展湘鄂川黔根据地。转移过程中既有探索战略出路，也有寻找新的兵员、给养与群众基础的实际任务。

结果与历史联系红二、红六军团会合，推动湘鄂川黔根据地成长并探索新的战略出路。

10月中旬历史转折

中央红军开始长征

地点 / 范围：江西瑞金、于都等

第五次反“围剿”失利后，中共中央和中革军委率中央红军主力离开中央苏区，向外线战略转移。部队连同机关辎重约八万余人，最初仍按预定路线前进。长征的开始是严重挫折后的求生转变，不是预先安排的胜利巡行。

结果与历史联系中央苏区主力被迫离开原有基地，长征开始，军事指挥和路线调整成为迫切问题。

10月起军事活动

南方根据地留守与三年游击战争

地点 / 范围：江西、福建、广东等南方八省

主力长征后，苏区分局、军区和政府办事处继续组织留守斗争。各地红军游击队在封锁围攻下保存力量，生活与作战条件极其艰苦，许多干部牺牲。南方游击战争后来为新四军组建保留了重要军事和组织基础。

结果与历史联系保留南方革命组织与武装，经过三年斗争成为后来新四军的重要来源。

11月16日起军事活动

红二十五军长征

地点 / 范围：鄂豫皖至鄂豫陕地区

红二十五军从鄂豫皖转入外线，进入鄂豫陕地区开展行动并建立新的根据地。原地仍有红二十八军等坚持。它后来先于中央红军到达陕甘，与当地部队会合，对西北革命力量的发展具有重要作用。

结果与历史联系红二十五军转入外线，发展鄂豫陕力量并为后来陕甘会师作准备。

11月27日—12月1日历史教训

湘江战役

地点 / 范围：广西全州、兴安一带

中央红军为突破封锁线进行激烈战斗，最终渡过湘江，但遭受极其惨重的损失，人数较出发时锐减。指挥僵化、行动迟缓与敌军合围等因素共同影响战局。危机促使部队内部对原来军事领导和战略路线的怀疑加深。

结果与历史联系红军突破封锁却付出惨重代价，部队对既有军事领导的不满与反思加深。

12月18日党的会议

黎平会议决定转兵

地点 / 范围：贵州黎平

经历湘江损失和通道转兵讨论后，中央政治局在黎平改变原定赴湘西北计划，决定向贵州北部进军。新方向避开敌军重兵布置，为进一步改变被动局面创造条件。会议是遵义会议前战略决策调整的重要一环。

结果与历史联系改向贵州北部进军，避开原定路线的敌军重兵，为遵义会议和后续转折创造条件。

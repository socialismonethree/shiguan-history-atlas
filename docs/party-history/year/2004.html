1月5日科技文化

繁荣哲学社会科学

地点 / 范围：全国

中央发布繁荣发展哲学社会科学的意见，推动相关研究和人才培养。国家发展与社会转型需要历史、经济、法律和社会等领域的知识支持。

结果与历史联系现代化知识体系既包括自然科学，也包括人文社会科学。

2月26日、8月26日科技文化

加强未成年人和大学生思想教育

地点 / 范围：全国

中央和国务院先后部署未成年人思想道德建设与大学生思想政治教育，分别面向不同年龄和教育阶段。教育工作更强调学校、家庭和社会之间的联系。

结果与历史联系不同教育对象和制度场景应分开，不把两个文件视为同一事项。

3月10日思想理论

阐述科学发展观要求

地点 / 范围：北京

胡锦涛在中央人口资源环境工作座谈会上讨论科学发展观的内涵，把人口、资源与环境放在经济社会发展的整体安排中。人口、资源和环境问题在会上被放到同一发展框架中，强调政策不能只追求短期产出，还需考虑长期承载与公共需要。

结果与历史联系协调和可持续要求进一步进入具体治理议程。

7月28日科技文化

北极黄河站建成

地点 / 范围：挪威新奥尔松

中国首个北极科学考察站黄河站建成投入使用，与南极考察形成南北极科研布局。基地为长期观测与跨学科研究提供条件。

结果与历史联系极地科研是长期数据和国际合作的积累，不只是一项建站纪录。

9月16日—19日党的建设

十六届四中全会

地点 / 范围：北京

全会通过加强党的执政能力建设的决定，同意江泽民辞去中央军委主席职务，决定胡锦涛接任。组织领导交接与治理能力建设同会推进。执政能力建设决定讨论领导经济社会发展、处理复杂问题等任务，中央军委职务交接则通过全会组织程序进行。

结果与历史联系新一届中央领导逐步完成党政军主要职务交接，治理能力成为党的建设重点。

11月7日党的建设

部署保持共产党员先进性教育

地点 / 范围：全国

中央印发开展保持共产党员先进性教育的意见，活动从二〇〇五年开始分批推进。工作把理论学习、组织生活和党员作用联系起来。活动后来分批覆盖不同党组织，围绕理论学习、党员责任和整改工作展开；它与此后群众路线等活动有各自的时间和内容。

结果与历史联系党员教育被用于改进基层组织与执政作风，并形成阶段性集中教育经验。

12月24日国防军事

提出新世纪军队历史使命

地点 / 范围：北京

胡锦涛在中央军委扩大会议上说明军队在新阶段的任务，涉及国家安全、发展利益和国际和平合作。军事使命被放在更广阔的国家利益背景中。任务表述兼顾国家发展机遇期、国家利益和国际和平合作，反映经济开放与海外联系扩大后军队面临的新需求。

结果与历史联系国防使命逐渐从传统领土防卫扩展到更广泛的国家安全与发展利益保障。

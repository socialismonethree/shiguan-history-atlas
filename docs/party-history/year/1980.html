1980

制度改革与开放试验继续展开

党内生活准则、领导制度改革和企业自主权改革同时推进；中国恢复在国际金融机构中的代表权，经济特区建设也进入制度化阶段。人口政策和国防科技同样是这一年的重要内容。

1月16日思想理论

提出八十年代三大任务

地点 / 范围：北京

邓小平在中央召集的干部会议上讨论形势与任务，把维护世界和平、实现祖国统一和现代化建设联系起来。这是观察改革初期国内工作重点与对外战略如何安排的一份重要讲话。

结果与历史联系现代化建设被置于国内政治和国际环境的整体判断之中。

2月23日—29日党的建设

十一届五中全会

地点 / 范围：北京

全会通过关于党内政治生活的准则，针对“文化大革命”破坏党内生活的教训重建制度要求。胡耀邦当选中央政治局常委、中央委员会总书记，中央领导机构进一步调整。准则针对党内生活中个人专断、组织纪律等问题提出规范，中央书记处等组织安排与领导人员调整同时推进。

结果与历史联系党内政治生活重建有了专门规范，为干部和组织工作恢复提供依据。

3月14日—15日经济社会

召开西藏工作座谈会

地点 / 范围：北京

中共中央召开西藏工作座谈会，研究西藏建设和民生发展。会议要求有计划、有步骤地推动经济社会发展，是改革时期针对区域实际情况调整工作的重要会议。

结果与历史联系统一部署之外，需要结合地区条件确定发展和政策落实方式。

4月17日、5月15日对外关系

恢复国际金融机构代表权

地点 / 范围：国际货币基金组织、世界银行

中国先后恢复在国际货币基金组织和世界银行中的代表权。这使中国能够以正式成员代表身份参与两机构活动，为后续利用国际资金、专业知识和经济交流创造条件。恢复代表权后，中国能以正式身份参加两机构有关活动，经济开放因此延伸到国际金融和发展合作的制度层面。

结果与历史联系对外经济合作增加制度性渠道，为后续资金、经验与专业知识交流提供条件。

5月18日科技文化

远程运载火箭发射成功

地点 / 范围：中国至太平洋预定海域

中国向太平洋预定海域发射运载火箭并取得成功。试验涉及远程飞行、测量和落区保障等环节，是中国航天与国防技术体系的一次综合性检验。

结果与历史联系体现长期积累的科技工业能力，不能把集体工程归于单一人物。

8月18日法治制度

讨论党和国家领导制度改革

地点 / 范围：北京

邓小平在中央政治局扩大会议上发表关于领导制度改革的讲话，把权力过分集中、干部制度等问题放在制度层面讨论，强调组织制度对政治运行具有长期影响。讲话将改革的重点放在领导制度、组织制度的弊端及其长期影响上，认为制度问题对个人行为具有持续约束，要求改进权力运行方式。

结果与历史联系把历史教训引向制度改革议程，为后来干部退休、机构与组织制度调整提供思想依据。

9月2日改革开放

推广国营企业自主权改革

地点 / 范围：全国

国务院批转关于扩大企业自主权试点的报告，要求从1981年起在国营工业企业中全面推开。改革试图调整企业与行政主管部门的关系，使企业经营有更多主动空间。先行试点的经验被要求从下一年在国营工业企业中推广，表明改革由个别单位的经营探索转向更普遍的管理政策。

结果与历史联系企业与主管部门之间的经营权限逐步调整，成为后续城市改革的重要基础。

9月25日经济社会

发布人口控制公开信

地点 / 范围：全国

中共中央向党员、团员发出人口增长问题公开信，提倡一对夫妇只生育一个孩子。这是当时人口政策的重要文件；后来的政策调整应按其实际年份另行理解。公开信面向党员和团员，说明当时中央把人口增长同现代化资源条件联系起来的判断；这一政策后来又经不同阶段调整。

结果与历史联系人口控制成为当时国家工作的重要内容，长期影响家庭安排与人口结构。

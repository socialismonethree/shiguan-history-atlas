4月5日国防军事

武警部队总部成立

地点 / 范围：北京

中国人民武装警察部队总部在北京成立。新的组织设置使武警建设和任务管理具有明确机构载体；这一时期的指挥体制与2018年改革后的体制不能混用。

结果与历史联系国防与公共安全力量的组织形式在改革时期持续调整。

4月24日改革开放

国营企业试行利改税

地点 / 范围：全国

国务院批转财政部的利改税试行办法，探索把国营企业向国家上缴利润的方式改为依法纳税。改革试图通过分配关系调整，改变企业与国家财政之间的传统联系。与继续扩大企业自主权相配合，利改税尝试使企业保留和上缴收益的关系更加清楚，改革因此触及国家与企业的分配机制。

结果与历史联系为建立更规则化的企业财政关系积累经验，也显示税制改革与企业改革不可分割。

6月4日—22日统一战线

全国政协六届一次会议

地点 / 范围：北京

全国政协六届一次会议选举邓颖超为全国政协主席。新一届政协围绕国家建设和统一战线工作展开履职，构成改革时期国家政治生活的重要组成部分。

结果与历史联系政协的政治协商、民主监督等作用，需要与国家权力机关职能区分。

6月6日—21日法治制度

国家机构换届

地点 / 范围：北京

六届全国人大一次会议依照新宪法选举和决定国家机构领导人员，李先念任国家主席、彭真任全国人大常委会委员长，赵紫阳任国务院总理。国家机构调整逐步落实。会议在一九八二年宪法框架下恢复国家主席等安排，国家中央军委和国务院领导体制的有关规定通过换届落实。

结果与历史联系新宪法所规定的国家机构体系通过具体人事和组织程序进入运行。

8月25日法治制度

作出严厉打击刑事犯罪决定

地点 / 范围：全国

中共中央部署严厉打击刑事犯罪活动，应对当时治安问题。阅读这一时期的治理措施，既要了解社会秩序背景，也应把政治决策与刑事立法、司法程序的关系分开考察。政策以集中行动方式处理刑事治安问题，显示中央在经济社会变化中对秩序和安全的判断，随后刑事执法与社会治理受到明显影响。

结果与历史联系治安问题进入国家集中治理议程，也使法律程序与治理手段的关系更加重要。

10月1日科技文化

教育“三个面向”题词

地点 / 范围：北京

邓小平为景山学校题词，提出教育面向现代化、世界和未来。题词把学校教育与国家建设、国际交流和长期人才培养联系起来，成为教育改革讨论中的重要表述。

结果与历史联系现代化需要人才培养方式变化，教育改革不是经济改革之外的孤立事项。

10月11日—12日党的建设

十二届二中全会部署整党

地点 / 范围：北京

全会通过关于整党的决定，安排分期分批整顿党的作风和组织。这项工作延续数年，至1987年基本结束，其范围与后来党内教育活动各有具体时代背景。整党按单位和层级分期分批进行，工作并非一次会议即可结束，而是持续到一九八七年基本完成，覆盖组织和作风整顿。

结果与历史联系党内整顿与经济改革同步推进，试图改善组织运行和干部行为。

10月12日法治制度

推动农村政社分开

地点 / 范围：全国农村

中共中央、国务院要求农村实行政社分开，建立乡政府。人民公社原有政权与经济组织合一的体制逐步改变，全国至1984年底基本完成政社分设。乡政府承担基层政权职责，经济组织从原来公社体制中逐步分出；改革把政治行政管理与生产经营分开处理。

结果与历史联系人民公社政社合一体制逐步退出，基层行政和农村经济组织关系发生变化。

12月6日科技文化

银河一号通过鉴定

地点 / 范围：湖南长沙

国防科技大学研制的银河一号巨型计算机通过国家鉴定，运算能力达到亿次级。它补上中国巨型计算机研制的重要空白，也体现国防科研与计算技术发展的联系。

结果与历史联系大型科技成果建立在团队、工业条件与长期科研积累之上。

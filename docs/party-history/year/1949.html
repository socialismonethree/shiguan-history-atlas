1949

新中国成立与全国治理起步

三大战役结束后，解放军渡江并继续全国进军；中央七届二中全会部署由乡村转向城市。新政协制定共同纲领和政府组织制度，中华人民共和国成立，城市接管、行政整合、经济恢复与外交建交成为新的中心任务。

1月10日、31日军事活动

淮海、平津战役结束

地点 / 范围：淮海、华北地区

淮海战役于1月10日结束，平津战役于31日结束。连同此前辽沈战役，国民党主要战略兵团遭到重大打击，解放军推进到长江以北的有利位置。不同战役的起止和作战方式各异，合称三大战役不表示它们是同一场连续会战。

结果与历史联系全国军事态势根本变化，为渡江作战与新政权筹建创造条件。

1月15日军事活动

四大野战军番号确定

地点 / 范围：人民解放军各战区

中央军委明确西北、中原、华东、东北野战军依次改称第一、第二、第三、第四野战军，华北主力另由总部直属。番号调整与统一组织相承接，适应全国进军。各野战军的成立历史、指挥系统和随后地域行动仍应分别辨认。

1月31日—2月7日国际联系

米高扬访问西柏坡

地点 / 范围：河北西柏坡

苏联代表米高扬访问西柏坡，与中共领导人讨论战争形势、新政权性质及内外政策。双方就未来关系交换意见。中共同时逐步明确处理旧外交关系、帝国主义在华权益和国际阵营的原则，新中国外交布局开始形成。

结果与历史联系将即将到来的建国同国际承认、援助和外交政策准备联系起来。

3月5日—13日党的会议

七届二中全会

地点 / 范围：河北西柏坡

中央全会讨论全国胜利后的政治、经济和外交方针，决定党的工作重心由乡村转向城市，提出恢复发展生产与国家工业化方向。毛泽东强调继续保持谦虚谨慎和艰苦奋斗，回应执政后可能面临的权力、生活与工作作风变化。

结果与历史联系为从革命党走向全国执政、由农村战争转向城市治理确立准备方向。

3月23日—25日组织建设

中央机关进驻北平

地点 / 范围：西柏坡、北平

中央机关离开西柏坡，25日抵达北平，与民主人士、军队和地方组织接触，开始在新环境中处理军事、政治协商和接管事务。进驻并不等于全国战争结束，南方、西北和西南仍有大量作战和治理任务等待展开。

结果与历史联系全国政治中心形成，为新政协和中央人民政府筹建提供工作地点。

4月1日—20日统一战线

北平和平谈判未达协议

地点 / 范围：北平

中共同南京国民党政府代表在北平谈判，提出国内和平协定方案。双方经过磋商，但南京政府拒绝接受最后文本，和平解决全国战争的机会未能实现。谈判与军队渡江准备同时进行，文本分歧最终由军事进程取代。

结果与历史联系谈判失败直接承接渡江战役，展示政治解决与军事准备的并行。

4月20日—23日军事活动

渡江战役与南京解放

地点 / 范围：长江中下游、南京

人民解放军在总前委协调下突破长江防线，23日进入南京。进军依赖渡船、侦察、地方交通和民众支援，多个方向互相配合。南京政权崩溃后，国民党部分军事和政治力量继续向南方及台湾转移，战争没有立即完全结束。

结果与历史联系打破国民党划江而治设想，推动全国军事和政治格局进一步改组。

5月27日政策建设

上海解放与城市接管

地点 / 范围：上海

解放军控制上海后，接管工作围绕军纪、社会秩序、金融、粮食和工商业展开。特大城市的生产、市场和居民生活要求新的行政能力。军事胜利只是起点，稳定经济和建立群众信任随即成为共产党城市工作的直接考验。

结果与历史联系为新中国治理大城市和恢复国民经济积累重要经验。

刘少奇率团访苏

中国人民政治协商会议一届全体会议

地点 / 范围：北平、北京

10月2日—3日国际联系

中苏建立外交关系

地点 / 范围：北京、莫斯科

苏联决定同中华人民共和国建立外交关系，中国政府复电同意互派大使，中苏正式建交。新国家需要建立外交承认网络，并处理旧中国遗留的条约、机构和侨民等问题。外交工作由此前的党际和地方接触转向中央国家机关承担。

结果与历史联系苏联成为最早同新中国建交的国家，为随后国际关系开展提供起点。

10月21日政策建设

政务院成立

地点 / 范围：北京

中央人民政府政务院成立，由周恩来任总理，承担国家行政事务。政府机构需接续和整合各解放区治理经验，面对财政、工商业、教育、社会秩序与人员安置等问题。新中央政府的建立并非所有政策一夜实施完成，而是持续建设过程。

结果与历史联系形成中央行政系统，推动从战时分区管理向全国统一治理转变。

11月—12月军事活动

向西南进军与大陆战局变化

地点 / 范围：重庆、成都及西南地区

人民解放军继续向西南推进，重庆、成都等城市相继解放，国民党在大陆的主要军事控制进一步瓦解。地方接管、改造交通和恢复社会秩序与军事行动紧密相随。部分边疆地区及海岛的解放和统一任务仍延续到之后年份。

结果与历史联系新政权的实际控制范围继续扩大，全国统一与地方治理成为持续任务。

12月国际联系

毛泽东访问苏联

地点 / 范围：莫斯科

毛泽东赴苏联访问，讨论两国关系和合作问题，周恩来次年赴苏参加具体谈判，1950年签订新的条约。1949年的访问是谈判的开始，不能把条约签署日期前移。经济、国防与国际环境共同构成新国家外交的现实背景。

结果与历史联系推动中苏关系由建交进入条约和合作安排的实质谈判。

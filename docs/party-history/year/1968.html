5月起历史曲折

清理阶级队伍运动扩大

地点 / 范围：全国

以清查历史问题和所谓阶级敌人为名的运动在各单位扩展，大量干部与普通群众遭审查、隔离或批斗。政治指控往往取代证据和程序，许多冤假错案由此产生，个人及家庭受到长期伤害。

结果与历史联系社会恐惧和组织失序加深，显示法制和公民权利被破坏的严重后果。

10月13日—31日历史曲折

刘少奇遭错误开除党籍

地点 / 范围：北京

扩大的八届十二中全会在严重不正常条件下，对刘少奇作出完全错误的政治结论和组织处理，把迫害推到极端。1969年刘少奇在开封含冤去世，1980年十一届五中全会才为其平反。

结果与历史联系这是文革中最重大的冤案之一，集中反映正常组织原则和法律保障遭到践踏。

12月22日社会民生

知识青年上山下乡高潮

地点 / 范围：全国城乡

有关知识青年到农村接受再教育的指示公布后，大量城镇青年被安排到农村和边疆。个人求学、就业与家庭规划被改变，许多青年经历艰苦劳动与社会磨炼，也承受教育中断和生活困境。

结果与历史联系这一运动影响一代人的生命历程，后来返城、就业和恢复高考成为重要社会议题。

12月29日经济建设

南京长江大桥全面通车

地点 / 范围：江苏南京

南京长江大桥铁路、公路两部分全面建成通车，跨江交通能力明显增强。工程由中国自行设计建造，桥梁基础、钢梁制造及架设等技术相互配合，连接长江两岸重要运输线路。

结果与历史联系大桥体现工程技术与产业配套能力的进步，也改善华东地区铁路与公路网络。

本年历史曲折

各地革命委员会相继建立

地点 / 范围：全国

地方原有党政机构遭夺权后，军队干部、群众组织代表和部分干部组成的革命委员会逐步建立。形式上的权力重组没有恢复被破坏的民主集中制与法制，派性和对干部群众的清查仍在继续。

结果与历史联系全国治理结构发生非常态变化，正常组织恢复需要此后多年努力。

本年历史曲折

干部下放五七干校

地点 / 范围：全国有关地区

机关干部被组织到五七干校参加劳动与政治学习，许多人离开原岗位，家庭生活和专业工作受到影响。不同干校条件不一，但全国性下放同机构冲击和政治审查交织，不能只作为一般劳动教育叙述。

结果与历史联系党政机关和专业系统人才配置遭受扰动，部分被迫下放者在后来才恢复工作。

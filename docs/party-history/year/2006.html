1月26日科技文化

部署建设创新型国家

地点 / 范围：全国

中央和国务院就实施科技规划纲要作出决定，强调增强自主创新能力。创新被安排为国家长期发展能力的关键，不再只是企业或研究机构的局部任务。决定以科技规划纲要为基础，要求企业、科研机构和教育体系形成联系，把技术能力作为经济转型的关键而非辅助条件。

结果与历史联系自主创新成为国家发展战略重点，科技投入与产业升级关系更加紧密。

1月31日经济社会

保障农民工权益

地点 / 范围：全国

国务院发布解决农民工问题的意见，涉及就业、公共服务和权益保障。大规模农村劳动力流动对原有城乡管理制度提出要求，政策开始更集中回应这一群体的处境。文件提出逐步建立城乡统一劳动力市场、保障权益的政策体系和公共服务制度，回应工资、就业与进城生活中的制度障碍。

结果与历史联系农民工问题从劳务输出扩展为权益、城市服务和社会管理的综合议题。

提出社会主义荣辱观

地点 / 范围：北京

胡锦涛在参加政协联组讨论时提出社会主义荣辱观，强调社会道德与行为规范。相关宣传和教育面向干部、学校及社会生活展开。

4月15日经济社会

部署促进中部崛起

地点 / 范围：中部地区

中央和国务院发布促进中部地区崛起的意见，在既有沿海开放、西部开发和东北振兴之外增加区域发展部署。产业、农业和交通条件成为中部政策的重要背景。中部地区在粮食、能源、制造和交通等方面具有重要作用，政策在不同区域战略之间补充连接，避免发展资源只向少数地区集中。

结果与历史联系区域协调战略形成更全面的空间布局，为中部产业和公共建设提供支持。

10月8日—11日经济社会

十六届六中全会讨论社会建设

地点 / 范围：北京

全会通过构建社会主义和谐社会重大问题的决定，把社会建设与经济、政治、文化建设相联系，强调公平正义、公共秩序和人与自然关系等方面。决定提出使社会建设与经济、政治、文化建设协调，强调公平正义与社会秩序等要求，发展任务不再局限于物质生产增长。

结果与历史联系社会建设获得更集中部署，民生保障和公共服务成为发展目标的重要部分。

1月6日历史人物

陈毅逝世

地点 / 范围：北京

陈毅因病逝世，毛泽东参加其追悼活动，周恩来主持相关安排。陈毅长期参与军队和外交工作，文革中因反对一些错误做法受到批判，他的逝世引发干部和社会各界广泛悼念。

结果与历史联系对陈毅的悼念也反映人们对老一辈领导人和恢复正常政治生活的期待。

2月5日经济建设

决定引进成套化工技术设备

地点 / 范围：北京

周恩来同意国家计委关于进口成套化纤、化肥设备的报告，随后报中央批准。石油工业增长为发展化工提供原料，国家试图通过引进技术补足设备短板，增加农业投入和居民生活用品。

结果与历史联系技术引进有助于改善产业配套，也为1973年扩大成套设备引进准备基础。

2月21日—28日外交

尼克松访华与上海公报

地点 / 范围：北京、杭州、上海

尼克松访华，同毛泽东、周恩来会谈。双方在上海发表联合公报，阐明各自立场并讨论推进关系正常化，台湾问题仍有分歧。这次访问结束长期隔绝，高层对话机制开始形成。

结果与历史联系中美关系正常化进程由此启动，冷战时期国际力量格局也受到重要影响。

3月13日外交

中英外交关系升为大使级

地点 / 范围：北京、伦敦

中国和英国签署联合公报，将双方外交代表由代办升为大使，英国撤销驻台湾官方代表机构。两国在已经存在外交联系的基础上改善代表层级，因此不能把这一日期写作首次建交。

结果与历史联系中英关系的升级扩展中国同西欧国家的正常交往，为后续经贸往来提供条件。

4月24日党的建设

重申干部处理中的惩前毖后

地点 / 范围：全国

周恩来审查同意的报刊社论重新强调惩前毖后、治病救人，针对文革中任意打击干部的问题，推动部分干部恢复工作和纠正不实指控。落实政策并不顺利，仍受到派性和政治运动阻碍。

结果与历史联系干部政策松动有助于恢复国家管理和专业工作，但尚未形成全面拨乱反正。

8月21日军事国防

讨论结束三支两军任务

地点 / 范围：全国

中央征询对三支两军的意见，提出已经恢复党委工作的地方和单位不再长期由军队代行相关职责。军队逐步退出部分地方政治事务，地方组织与生产管理开始获得恢复空间。

结果与历史联系军地职责回归有利于恢复正常治理，也有利于军队把主要精力转向训练建设。

9月25日—30日外交

中日邦交正常化

地点 / 范围：北京

日本首相田中角荣应邀访华，双方就战争历史、台湾和外交关系进行谈判。9月29日发表联合声明，宣布建立外交关系，两国长期不正常状态由此结束，人员、贸易与文化交流逐步扩大。

结果与历史联系中日建交改善中国周边关系，并为1978年缔结和平友好条约奠定基础。

12月历史曲折

批评极左与调整被迫中断

地点 / 范围：北京及全国

周恩来等在林彪事件后推动批评极左思潮，改善经济和干部工作，但有关努力又被错误指向反对所谓极右。政治路线没有根本改变，经济调整和干部恢复受到新的限制。

结果与历史联系这一反复说明仅处理林彪集团并不足以纠正文革根本错误，全面转折仍未实现。

1月15日科技教育

决定发展原子能事业

地点 / 范围：北京

中央书记处扩大会议作出发展原子能事业的决策。核科学与国防工业从科研、人才、设施和组织等环节启动，后来的原子弹试验建立在多年持续积累上，不能把决策年等同于技术完成年。

结果与历史联系这是核工业和核武器研制的重要起点，科技成果背后有长期组织协同。

1月18日军事国防

一江山岛战役

地点 / 范围：浙江沿海

人民解放军对一江山岛实施陆海空协同作战，攻占该岛。随后大陈岛及周边岛屿局势发生变化，浙江沿海的主要国民党据点相继失去，战役也成为部队探索联合登陆作战的实践。

结果与历史联系这场战役与1950年海南岛渡海作战条件不同，可用来观察军兵种协同的变化。

3月21日—31日党的建设

党的全国代表会议

地点 / 范围：北京

全国代表会议通过成立中央和地方监察委员会等决议，董必武任中央监察委员会书记。原有纪律检查委员会由新的监察委员会取代，党内监督机构在执政条件下进一步调整。

结果与历史联系机构名称和职责有历史变化，不能把1955年的设置直接等同于今天的纪委监察制度。

4月18日—24日外交

万隆会议与求同存异

地点 / 范围：印度尼西亚万隆

周恩来率中国代表团出席亚非会议。面对参会国家制度、宗教和外交立场差异，中国代表团主张寻找反殖民、求和平等共同点，同时承认分歧，以协商争取会议合作。

结果与历史联系万隆会议拓展中国与亚非国家的交往，也成为理解多边外交方法的重要案例。

5月13日民族与统一

提出争取和平解决台湾问题

地点 / 范围：北京

周恩来在全国人大常委会扩大会议上报告亚非会议情况，谈到在可能条件下争取用和平方式解决台湾问题。这反映当时对台政策开始探索军事对峙之外的途径，而非两岸关系已经发生根本改变。

结果与历史联系这一表达是此后和平统一政策思想发展中的早期节点，不能与后来的完整方案倒置。

7月30日法治制度

兵役法通过

地点 / 范围：全国

一届全国人大二次会议通过兵役法，人民解放军从志愿兵役制转向义务兵役制。兵员补充、服役和退役安排获得制度框架，与军队薪金制和后续军衔制改革共同构成正规化建设。

结果与历史联系兵役制度关系军队与社会的长期联系，不能只看一次征兵行动。

9月军事国防

人民解放军首次实行军衔制

地点 / 范围：北京及全军

军队开始实行军衔制度，朱德、彭德怀等十人获元帅军衔，其他将官、校官、尉官也分级授衔。军衔既标明指挥关系和资历，也服务于现代军队的组织管理，该制度在1965年一度取消。

结果与历史联系首次授衔体现军队正规化进程；荣誉评价与具体职务并非完全相同。

本年经济建设

农业合作化加速

地点 / 范围：全国农村

农业生产合作社发展速度明显加快，土地、工具和劳动的组织方式随之改变。1981年历史决议在肯定社会主义改造总体方向的同时指出，1955年夏季以后部分改造要求过急、工作过粗、形式过于简单。

结果与历史联系应把制度转变的成就与具体推进中的偏差一并讲清，不能只用入社数量判断效果。

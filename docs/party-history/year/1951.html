2月26日社会民生

劳动保险条例颁布

地点 / 范围：全国

政务院颁布劳动保险条例，规定对一部分企业职工试行劳动保险，涉及疾病、工伤、生育、养老和死亡等保障。它采取分步实施方式，不能把初期适用范围理解为当时已经实现全民社会保障。

结果与历史联系条例为新中国企业职工社会保险制度建立了早期法律框架。

3月28日—4月9日党的建设

第一次全国组织工作会议

地点 / 范围：北京

会议讨论新形势下的党员标准和基层组织状况，通过整顿党的基层组织等决议。随着执政范围扩大，党组织面临党员快速增加和干部来源复杂等问题，整党建党成为中央组织工作的重要任务。

结果与历史联系从战争环境转入全国执政，需要重新解决基层组织质量、纪律和党员教育问题。

5月23日民族与统一

十七条协议签订

地点 / 范围：北京、西藏

中央人民政府与西藏地方政府代表签署有关西藏和平解放办法的协议。按照协议安排，人民解放军进藏部队于10月进驻拉萨；此处采用2021年权威大事记所记10月26日，不沿用旧资料不同日期。

结果与历史联系协议及其执行是新中国处理西藏事务的重要历史节点，后来发展须放回具体年代。

7月10日军事国防

朝鲜停战谈判开始

地点 / 范围：朝鲜开城

中朝方面与对方开始停战谈判。此前和谈期间，前线战斗并未停止，双方围绕军事分界线、战俘等问题持续磋商，直到1953年才签署停战协定，不能把开始谈判当成战争已经结束。

结果与历史联系作战与谈判并行，构成抗美援朝战争后半段的重要特征。

9月20日—30日经济建设

农业互助合作政策讨论

地点 / 范围：北京

全国第一次互助合作会议讨论农业生产组织方式，通过互助合作决议草案。改革后的农户仍以个体经营为主，互助组和初级合作社被用来探索劳力、牲畜、工具的协作使用，政策先经试行再正式发布。

结果与历史联系这是从土地改革后的个体农业走向合作化的政策环节，不能倒置为土地改革本身。

9月29日思想文化

知识分子思想改造展开

地点 / 范围：北京、天津及全国

周恩来向北京、天津高校教师作报告，随后中央要求学校开展思想改造和组织清理。运动促使知识分子进入新的政治教育体系，也使教育和学术活动受到政治运动的影响，需要区分政策目的与具体执行。

结果与历史联系知识分子政策关系到人才使用和思想文化生活，后续多次调整反映了其复杂性。

10月思想文化

《毛泽东选集》第一卷出版

地点 / 范围：全国

第一卷把毛泽东在革命时期的一部分重要著作编为正式选集，便于党员干部和社会读者系统学习。其后第二、第三、第四卷分别出版，形成研究中共革命思想及历史的重要文献系列。

结果与历史联系选集的编辑出版是理论传播和党内教育建设的一部分，出版年不等于各篇写作年。

12月1日党的建设

三反运动在全国展开

地点 / 范围：全国

中央作出反贪污、反浪费、反官僚主义等决定，三反运动随之展开。运动集中查处一些重大贪污案件，刘青山、张子善案受到严肃处理；同时，理解运动还需关注纪律监督制度与群众动员方式的关系。

结果与历史联系它显示执政初期对干部廉洁和公共财产管理的重视，具体案件应按事实与程序阅读。

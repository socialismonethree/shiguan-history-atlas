3月8日—25日国防军事

台海军事演习

地点 / 范围：东海、南海、台湾海峡

人民解放军在有关海域进行导弹训练和海空、联合军事演习。权威资料将行动与反对“台独”、维护国家统一的立场相联系，台海紧张局势也影响两岸和国际关系。

结果与历史联系军事行动应放在两岸政治与地区安全背景中理解。

3月19日统一战线

研究新疆稳定工作

地点 / 范围：北京、新疆

中央政治局常委会专题研究新疆稳定工作，随后中央逐步加强干部支援和对口支援安排。地区治理把社会稳定与经济发展联系起来。中央后来从内地省市、机关和企业选派干部赴新疆工作，地区治理与干部、资源支援形成持续联系，政策实施跨越多个年份。

结果与历史联系对口支援和干部支援逐渐成为区域治理与发展的一项机制。

4月5日党的建设

地方党委工作条例试行

地点 / 范围：全国

中央印发地方委员会工作条例试行文本，对地方党委的工作运行作制度规定。它把党的地方领导机构活动纳入较明确的组织程序。

结果与历史联系地方治理既有国家行政体系，也有党的领导与组织体系。

10月7日—10日思想理论

十四届六中全会

地点 / 范围：北京

全会通过加强社会主义精神文明建设的决议，强调物质文明与精神文明协调发展。市场经济推进过程中，社会价值、公共风气和文化建设成为集中讨论对象。决议把精神文明视为社会全面进步的组成，讨论经济体制转变中道德、文化和社会风气问题，并要求相应组织和政策工作配合。

结果与历史联系发展议程进一步强调物质生产之外的公共文化和社会规范。

12月9日—12日经济社会

全国卫生工作会议

地点 / 范围：北京

全国卫生工作会议讨论卫生服务改革和发展，相关中央文件于次年发布。医疗卫生资源配置和群众服务需求在改革深入后更加突出。会议后的中央卫生改革文件于一九九七年发布，显示会议讨论到政策落地之间存在衔接过程，卫生服务体制成为新阶段改革重点。

结果与历史联系卫生改革逐步进入中央综合部署，为后来医改和公共卫生政策提供背景。

本年（具体月日未详）人物与社会

史来贺获全国优秀共产党员称号

地点 / 范围：河南新乡刘庄

史来贺在这一年获全国优秀共产党员称号。他长期在刘庄从事农村基层工作，其人物资料记录了组织农田改造、棉花种植和乡村企业发展的经历。这项荣誉把一个村庄的基层组织实践带入全国典型宣传；上述长期经历不等于均在1996年内完成。

结果与历史联系农村基层党组织负责人成为全国表彰和宣传对象，为考察乡村治理、集体经济发展与干部工作提供了具体人物线索。

1月12日人物与社会

刘胡兰在云周西村被杀害

地点 / 范围：山西文水云周西村

刘胡兰此前参加当地妇救会工作，并在1946年成为中共候补党员。1947年1月12日，阎锡山部队进入云周西村，她被捕后遭杀害。毛泽东随后为她题词；当年8月1日，中共晋绥分局追认她为正式党员。她的事迹由此成为解放区广泛传播的纪念内容。

结果与历史联系这一事件反映解放战争时期基层妇女工作者面临的冲突与危险，其纪念传播也成为此后革命文化的重要组成部分。

2月—3月统一战线

国共谈判联络机构撤回

地点 / 范围：南京、上海、重庆、延安

国民党当局要求共产党在南京、上海、重庆等地的谈判和联络人员撤离，人员于3月陆续返回延安。长期谈判留下的公开联系渠道被切断，政治协商与军事调处空间进一步收缩，国共关系转入全面破裂状态。

结果与历史联系标志战后和平谈判机制基本终止，地下与统战工作转入更困难环境。

3月18日—19日军事活动

撤离延安、转战陕北

地点 / 范围：陕西延安及陕北各地

国民党军重点进攻陕北，中央机关和守军撤出延安，以保存力量、机动作战。毛泽东等留在陕北指挥全国战争，彭德怀率部进行青化砭、羊马河、蟠龙等战斗。放弃一城同保持战略指挥和有生力量之间存在不同层次的取舍。

结果与历史联系敌军占领延安没有消灭中共中央与陕北部队，随后战局逐步改变。

3月29日—30日组织建设

中央机关分为三部分

地点 / 范围：陕西枣林沟、华北、晋西北

中央根据战争形势调整机关行动，毛泽东等留陕北，刘少奇、朱德等赴华北组成中央工作委员会，叶剑英、杨尚昆主持中央后方委员会。分工兼顾战略指挥、华北工作和后勤保障，在高风险条件下保持中央运作。

结果与历史联系使中央领导不因单一地点受围而中断，并为西柏坡时期准备条件。

5月1日政策建设

内蒙古自治政府成立

地点 / 范围：内蒙古王爷庙

内蒙古人民代表会议产生自治政府，乌兰夫任主席。这是中共领导建立的第一个省级少数民族自治政府，形成民族区域自治的重要实践。新政权在战争与地区整合中推进民族平等、地方治理和社会改革，发展过程具有本地特点。

结果与历史联系为新中国民族区域自治制度积累组织和治理经验。

孟良崮战役

地点 / 范围：山东蒙阴、沂南一带

华东野战军在山东战场集中兵力歼灭国民党整编第七十四师，打击其对山东解放区的重点进攻。战役依赖主力、阻援部队和地方群众协同，改变华东战场态势。胜利不是孤立的名将对决，而是整体部署与支前组织共同作用。

5月20日工农运动

五二〇学生运动

地点 / 范围：南京、北平及多城

南京等地学生举行反饥饿、反内战、反迫害游行，遭军警镇压，抗议随之扩展。物价、教育与生活危机成为青年政治参与的直接原因，中共地下组织推动和支持运动。学生行动同工人、农民等的不满汇合，形成国统区重要社会压力。

结果与历史联系爱国民主运动发展为配合解放战争的另一条战线。

地点 / 范围：黄河以南、大别山区

7月17日—9月13日政策建设

全国土地会议

地点 / 范围：河北西柏坡

中共中央工委主持全国土地会议，总结各地土地改革并制定《中国土地法大纲》。会议试图以较统一的政策处理地主土地与农民要求，但随后一些地区执行仍出现侵犯中农、工商业等过左问题，需要继续纠正。

结果与历史联系为解放区土地制度变革确立纲领，也提出如何掌握政策界限的问题。

12月25日—28日党的会议

杨家沟十二月会议

地点 / 范围：陕西米脂杨家沟

中央扩大会议讨论《目前形势和我们的任务》，总结战争转折，阐释政治纲领、三大经济纲领和十大军事原则。报告把作战经验同未来经济制度相联系。会议处于解放军转向主动进攻后的阶段，为后续决战与治理准备方向。

结果与历史联系使军事原则、土地政策和国家经济构想形成更系统的政治部署。

1月16日组织建设

中共中央南方局成立

地点 / 范围：重庆

中共在重庆建立南方局，负责南方国民党统治区、部分沦陷区及海外的组织和统战工作，联系八路军、新四军办事处以及《新华日报》等公开机构。工作同时需要公开合法活动和秘密组织纪律，面对复杂的合作与限制环境。

结果与历史联系中共在国统区、沦陷区和海外的组织统战工作拥有更集中的区域领导。

1月17日—2月4日政策建设

陕甘宁边区第一届参议会

地点 / 范围：延安

边区参议会听取政府工作报告，通过抗战时期施政纲领并选举政府。政权建设面对战争动员、经济负担、基层秩序和不同群体参与等实际问题。参议制度体现统一战线下的制度探索，其运作需同边区具体环境结合考察。

结果与历史联系边区参政与政府建设推进，为统一战线条件下的地方治理积累经验。

2月2日政策建设

延安生产动员与大生产开端

地点 / 范围：延安及各根据地

中共中央召开生产动员大会，倡导机关、部队等发展生产，以克服供给困难。随后各根据地逐步采取不同形式生产自救，南泥湾屯垦是后来形成的著名实例。运动的规模和方式随战争、封锁与地方自然条件而变化。

结果与历史联系生产自救逐步推广，为随后大生产和保障供给奠定基础。

3月—5月军事活动

一一五师入鲁与陆房突围

地点 / 范围：山东鲁西、泰肥地区

八路军一一五师一部进入山东，同当地武装合作开辟抗日地区，5月在陆房反击日军围攻并突围。部队入鲁加强当地敌后力量，也需要解决不同武装和地方组织的协同。山东根据地后来成为重要抗战与解放战争基地。

结果与历史联系山东敌后抗战力量加强，鲁西、鲁南工作与主力部队联系更加紧密。

5月—11月军事活动

新四军江南、江北指挥机构建立

地点 / 范围：安徽庐江、江苏溧阳等

新四军逐步设立江北和江南指挥机构，整编部队并向敌后展开。不同地区的作战、交通与群众组织条件需要分别应对。组织调整为华中根据地的扩展提供军事协调，也承接中央关于向北发展的战略要求。

结果与历史联系华中不同方向部队得到协调，为新根据地发展和后来的联合指挥创造条件。

7月7日思想文献

抗战两周年时局宣言

地点 / 范围：延安、全国各地

中共发表抗战两周年宣言，强调继续抗战、维护团结和推动进步，以回应投降、分裂与政治倒退的危险。宣言是在日军侵略、汪精卫投敌以及国共摩擦加剧的背景下提出，不应脱离当时局势只读成一般性口号。

结果与历史联系反对投降分裂的政治立场更加明确，有助于争取和维持广泛抗日合作。

10月4日思想文献

《〈共产党人〉发刊词》

地点 / 范围：延安

毛泽东在党内刊物发刊词中总结革命经验，讨论统一战线、武装斗争与党的建设之间的关系。三者分别涉及联合社会力量、军事斗争和组织自身建设，并非可以相互代替。文本为抗战时期理解政党建设提供重要框架。

结果与历史联系统一战线、武装斗争与党的建设被系统联系，影响后续建党与革命认识。

10月—12月军事活动

晋察冀反“扫荡”与黄土岭战斗

地点 / 范围：河北北岳区、黄土岭

晋察冀部队在友军配合下反击日军进攻，黄土岭战斗击毙日军高级指挥官。军事行动依赖根据地情报、交通和群众支援。日军反复“扫荡”与根据地的恢复、建设交替发生，敌后战争是一场长期争夺而非短期占领。

结果与历史联系反击敌军“扫荡”，保卫晋察冀根据地并打击日军指挥力量。

11月人物事迹

白求恩逝世与纪念

地点 / 范围：河北唐县

白求恩在晋察冀医疗工作中因感染病逝，毛泽东撰文纪念其对中国抗战的服务。评价应与其战地救护、培训医护和改进医疗组织的实际工作相联系。国际友人的贡献既属于个人事迹，也嵌入抗战医疗和国际援助网络。

结果与历史联系失去重要国际医疗骨干，其事迹成为此后政治和医务教育的重要资源。

12月—1940年春统一战线

第一次反共高潮与自卫斗争

地点 / 范围：华北、华中、陕甘宁边区等

国民党顽固派在多地限制和进攻共产党领导的武装及根据地，合作关系遭遇严重危机。中共一方面坚持抗战与统一战线，另一方面组织必要自卫、开展政治交涉，抵制进攻。反摩擦斗争与对日作战在这一时期同时存在。

结果与历史联系根据地自卫与政治交涉限制进攻，合作抗日仍得以在冲突中继续。

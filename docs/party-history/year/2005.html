1月3日党的建设

建立惩治和预防腐败体系

地点 / 范围：全国

中央发布实施纲要，把教育、制度和监督结合起来，部署惩治与预防腐败体系建设。反腐败工作更强调各项机制之间的联系。

结果与历史联系查处案件与制度预防需要配合，不能以单一环节替代整体治理。

2月19日改革开放

支持非公有制经济发展

地点 / 范围：全国

国务院发布鼓励支持和引导个体私营等非公有制经济的意见，涉及市场准入和发展条件等问题。基本经济制度要求通过具体政策改善不同主体经营环境。意见将非公有制经济发展与社会主义基本经济制度相联系，强调支持、引导并行，企业经营环境成为政策落实的具体领域。

结果与历史联系非公有制经营主体获得进一步政策支持，市场经济的多种所有制结构继续发展。

3月5日—14日法治制度

反分裂国家法通过

地点 / 范围：北京

十届全国人大三次会议通过反分裂国家法，并选举胡锦涛为国家中央军委主席。对台方针获得法律表达，国家军事领导交接完成相应程序。

结果与历史联系同一次会议处理的两项事项应分别理解其制度性质。

4月17日经济社会

国家突发公共事件总体应急预案

地点 / 范围：全国

国务院印发总体应急预案，建立较综合的突发公共事件应对框架。非典等事件使公共卫生、自然灾害和社会风险的预防处置更加受到重视。预案明确以总体框架统筹自然灾害、公共卫生等突发事件的应对，部门与地方需要在预警、协调和处置方面形成连接。

结果与历史联系国家应急工作从个别危机处置逐步走向系统预案和组织体系建设。

4月27日法治制度

公务员法通过

地点 / 范围：北京

全国人大常委会通过公务员法，对公务员管理作出法律规范。政府职能转变需要相应的人员录用、考核和权利义务制度配套。

结果与历史联系行政组织改革与公务员制度建设相互联系。

4月29日统一战线

国共两党领导人会谈

地点 / 范围：北京

胡锦涛与中国国民党主席连战会谈，双方发布两岸和平发展共同愿景。这是两党主要领导人相隔六十年后的正式会谈。双方在会后发表共同愿景，以政党交流讨论两岸和平发展和往来合作，形成一九四五年以来两党主要领导人正式会谈的新节点。

结果与历史联系两岸政党接触扩大，为此后经贸与社会交流创造新的政治空间。

7月21日改革开放

改革人民币汇率形成机制

地点 / 范围：全国

经国务院批准，中国人民银行宣布实行以市场供求为基础、参考一篮子货币调节的有管理浮动汇率制度。汇率不再按此前方式单一安排。新机制参考一篮子货币而不是简单固定于单一货币，汇率变化与市场供求及政策调节形成新关系，对贸易和金融经营产生影响。

结果与历史联系汇率制度开始更适应开放程度提高的经济条件，人民币国际化也获得制度背景。

10月8日—11日经济社会

十六届五中全会谋划十一五

地点 / 范围：北京

全会通过第十一个五年规划建议，把降低单位产出能源消耗列入发展目标。规划更加突出结构、资源环境和增长质量等要求。十一五建议把节能目标与经济社会发展同步安排，说明发展评价开始更明确受资源和环境约束，政策考核不再只看总量。

结果与历史联系规划更注重结构、效率和社会协调，为科学发展观落实提供政策载体。

12月29日经济社会

决定废止农业税

地点 / 范围：北京、全国农村

全国人大常委会决定自二〇〇六年起废止农业税条例，延续多年的减轻农民税费负担改革达到重要节点。废止决定与正式实施跨越两个年份。税费减负此前已逐步推进，此次由全国人大常委会决定废止条例，使农民税费负担变化从政策措施进入正式制度终结。

结果与历史联系国家与农村的财政关系转向更加重视支持农业和公共服务供给。

12月31日经济社会

部署社会主义新农村建设

地点 / 范围：全国农村

中央和国务院发布推进社会主义新农村建设的意见，把农业生产、农民生活和农村公共服务等放在综合发展框架中。文件把生产发展、生活改善和基层建设联系起来，农村建设任务开始更系统涵盖道路、卫生、教育与生活环境等公共领域。

结果与历史联系三农政策由减负与经营改革进一步拓展到农村公共服务和综合建设。

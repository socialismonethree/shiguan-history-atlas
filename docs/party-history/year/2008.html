1月15日党的建设

加强反腐倡廉建设

地点 / 范围：北京

胡锦涛在中央纪委全会上强调完善惩治和预防腐败体系。党风廉政工作继续从单个案件处理扩展到制度、教育和监督相结合的框架。

结果与历史联系制度约束与监督机制成为执政党建设的重要组成部分。

3月5日—18日法治制度

探索大部门体制

地点 / 范围：北京

十一届全国人大一次会议批准国务院机构改革方案，探索职能有机统一的大部门体制，并完成国家机构领导人员换届。改革试图改进部门间职能交叉和协调问题。改革把职能有机统一作为方向，试图减少相近职责分散在不同部门的问题，政府管理方式与公共服务任务共同进入机构调整。

结果与历史联系国务院组织结构继续适应市场经济和社会建设需要。

5月12日经济社会

汶川特大地震与救援

地点 / 范围：四川汶川及周边

四川汶川发生特大地震，军队、专业救援队伍、医护人员和志愿者等投入救援，随后展开安置和重建。灾害对生命、家园与公共基础设施造成重大损害。救援阶段涉及搜救、医疗、道路通信恢复和受灾群众安置，随后还需重建住房学校与公共设施，社会参与与国家组织共同发挥作用。

结果与历史联系抗震救灾推动应急体系、公共安全和重建政策不断完善，也留下深刻社会记忆。

地点 / 范围：全国

8月1日经济社会

京津城际铁路运营

地点 / 范围：北京、天津

京津城际铁路通车运营，成为中国高速铁路发展的重要节点。交通时间缩短加强城市联系，也为后续高铁网络建设积累运营和技术经验。

结果与历史联系高速交通改变区域经济与城市间的日常联系。

8月8日—24日、9月6日—17日科技文化

北京奥运会与残奥会

地点 / 范围：北京

北京举办第二十九届夏季奥运会和第十三届夏季残奥会。赛事涉及场馆建设、志愿服务、城市交通、无障碍环境和国际交流等多个方面。奥运与残奥会分别举行，国际运动员和观众汇集北京，志愿者、无障碍设施与城市交通共同支撑赛事，公共服务接受集中检验。

结果与历史联系中国与世界的体育人文交流扩大，城市建设和社会参与积累新经验。

10月7日、11月5日经济社会

应对国际金融危机

地点 / 范围：北京、全国

中央研究国际金融危机影响，国务院随后部署扩大内需、促进经济平稳增长的措施。外需受冲击后，投资、就业和宏观政策调整成为重点。美国次贷危机外溢后，出口、企业经营与就业面临压力，国务院通过扩大内需等政策应对，宏观稳定与结构调整同时成为任务。

结果与历史联系中国经济政策加强逆周期应对，外部风险对国内发展的影响更加明显。

12月15日统一战线

两岸直接三通启动

地点 / 范围：两岸多个城市

两岸同时启动海运直航、空运直航和直接通邮，人员、货物和信息交流减少中转环节。此后定期航班等安排继续完善。海运、空运和邮政同时减少中转，随后两岸定期航班与投资安排进一步完善，直接联系从政策沟通转化为日常运行网络。

结果与历史联系两岸人员与货物往来更便利，交流的社会经济基础得到扩大。

12月26日国防军事

海军赴亚丁湾护航

地点 / 范围：亚丁湾、索马里海域

中国海军首批舰艇编队赴亚丁湾和索马里海域执行护航，依据联合国有关决议参与保护航运安全。海军远海持续行动能力得到实际检验。护航以保护重要航运通道为任务，编队需要跨越较长距离并持续保障，海军远海行动经验由此在实际任务中积累。

结果与历史联系中国军队参与海外公共安全与国际合作的范围进一步扩大。

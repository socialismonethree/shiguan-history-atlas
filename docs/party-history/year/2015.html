1月3日经济社会

机关事业单位养老保险改革

地点 / 范围：全国

国务院部署机关事业单位工作人员养老保险制度改革，调整此前不同就业部门之间的养老安排。社会保障制度在扩围之外继续推进衔接与公平，改革也涉及缴费、待遇和职业年金等配套机制。

结果与历史联系养老制度改革进一步跨越原有部门边界，对劳动流动和公共保障产生长期影响。

3月26日党的建设

部署“天网”追逃追赃行动

地点 / 范围：国内外

中央反腐败协调小组部署“天网”行动，通过多部门协作开展国际追逃追赃。腐败案件的人员和资产跨境流动，使国内纪检司法工作需要与外交、金融及国际执法合作形成衔接。行动把追逃人员与追缴资产联系，并需要不同国家和法律制度之间的协作。

结果与历史联系反腐败工作空间从国内进一步延伸到境外追逃与赃款追缴。

3月29日—4月7日对外关系

海军执行也门撤离任务

地点 / 范围：也门、亚丁湾

也门局势恶化后，正在附近海域护航的中国海军舰艇参加撤离，先后撤出六百余名中国公民，并协助十五国的外国公民离境。远海部署力量转用于突发危机中的人员保护。这一任务利用已有护航编队就近行动，显示日常远海部署在危机中的保障作用。

结果与历史联系显示海外利益保护、海军行动与外交协调之间的实际联系。

5月1日法治制度

法院实行立案登记制

地点 / 范围：全国法院

全国法院实行立案登记制，对依法应当受理的案件作程序调整，着重回应群众反映的立案难问题。司法改革由宏观制度讨论进入当事人接近法院和提出诉讼的具体环节。立案程序改变之后，案件审理、司法资源与纠纷化解仍需后续配套改革。

结果与历史联系诉权保障成为司法制度改革的一个可直接感知的领域。

5月18日—20日统一战线

中央统战工作会议与条例

地点 / 范围：北京

中央统战工作会议讨论新时代统一战线任务，同期中央印发统一战线工作条例试行文本。统一战线工作的对象、组织责任和工作机制被进一步制度化，以适应社会阶层和对外交往变化。

结果与历史联系统一战线建设由政策传统继续转化为较明确的党内法规安排。

7月31日科技文化

北京获得冬奥会举办权

地点 / 范围：马来西亚吉隆坡、北京

国际奥委会决定北京举办二〇二二年冬季奥运会。申办成功之后，冬季项目发展、场馆建设、区域交通和赛事组织进入长期筹备阶段，实际举办则在本知识库截止年份之后。北京与张家口的区域交通和场馆协作由此进入多年筹备期。

结果与历史联系北京体育与城市发展进入冬奥筹备阶段，不能把未来赛事成果写作本年已完成。

8月30日经济社会

建立中央生态环保督察制度

地点 / 范围：全国

两办印发生态环境保护督察方案试行文本，建立中央层面的环保督察安排。环境治理不仅要求企业守法，也开始追究地方党委政府等相关主体落实保护责任的情况。制度将环保目标与地方履责联系，扩大了监督对象和责任追究的制度范围。

结果与历史联系生态环保责任由行业监管进一步进入跨层级监督体系。

9月3日国防军事

抗战胜利七十周年纪念与裁军宣布

地点 / 范围：北京

纪念抗战暨世界反法西斯战争胜利七十周年大会举行，习近平检阅部队并宣布裁减军队员额三十万。战争纪念与国防改革方向在同一场合表达，后续编制体制改革继续推进。此后军队领导指挥体制、军种和战区调整按部署逐步实施。

10月5日人物事迹

屠呦呦获诺贝尔奖

地点 / 范围：瑞典公布、中国科研机构

屠呦呦获得诺贝尔生理学或医学奖，其青蒿素研究受到国际认可。相关成果源于长期药物研究、实验改进及团队协作，不应把传统医药启发与现代科学验证简单对立，也不把集体工程抹去。

结果与历史联系体现中国本土科研成果对全球疾病防治的贡献，并推动社会关注科研长期积累。

11月7日统一战线

两岸领导人首次会晤

地点 / 范围：新加坡

习近平与台湾地区领导人马英九在新加坡会晤，交换对两岸关系和平发展的意见。这是自一九四九年以来两岸领导人首次会面，建立直接沟通先例，但并未消除双方长期政治分歧。会面以双方领导人身份进行，为直接沟通设立新的历史先例。

结果与历史联系两岸高层接触达到新节点，其后关系走向仍受各方政治变化影响。

地点 / 范围：北京

亚洲基础设施投资银行成立

地点 / 范围：北京

亚洲基础设施投资银行正式成立，为亚洲及相关地区基础设施融资提供多边平台。该机构通过成员共同参与和国际金融规则开展运作，与单个国家的双边援助或企业投资不同。其成员数量后来增加，多边机构运作与单个项目的融资审批需分别理解。

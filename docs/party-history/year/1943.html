1943

组织集中、生产恢复与审干教训

中央机构进一步集中，群众路线与调查研究被系统讨论，双拥和大生产帮助根据地逐步恢复。与此同时，审干中的“抢救”扩大化造成冤错，需要甄别纠正。共产国际解散后，中共自主处理革命问题的制度环境变化。

1月15日、25日政策建设

双拥运动兴起

地点 / 范围：陕甘宁边区

边区政府和留守部队分别作出拥军、拥政爱民的决定，推动军民之间解决生产、优抚、纪律和日常关系问题。双拥并非只举行庆祝活动，也涉及伤亡家属照顾、军队尊重群众利益和政府支持部队等实际事务。

结果与历史联系改善军政军民关系，为长期战争条件下的社会协作提供制度和活动基础。

3月20日组织建设

中央机构调整

地点 / 范围：延安

中央政治局决定调整精简中央机构，推定毛泽东为政治局主席和书记处主席，书记处由毛泽东、刘少奇、任弼时组成。领导分工的集中，同整风和战争中的协调需要相联系。应把机构调整的实际内容同以后正式党章规定区别开来。

结果与历史联系进一步集中中央领导和日常决策，为七大前中央组织运作确立安排。

3月27日思想文献

张闻天总结晋陕调查

地点 / 范围：陕北、晋西北

张闻天在长期深入农村调查后发表《出发归来记》，讨论调查研究的态度和方法。调查涉及生产、土地、社会关系与民众生活，强调把书本认识放回实际检验。这项工作是在整风背景下对领导作风和政策依据的具体实践。

结果与历史联系为党内调查研究传统增加实际范例，并把基层经验引入中央讨论。

4月起历史教训

审干与“抢救”扩大化

地点 / 范围：延安等地

整风转入审查干部后，对特务渗透的估计被严重夸大，出现逼供、轻信口供和冤枉干部等错误。“抢救”运动使许多人遭不实指控，后来中央开展甄别纠正。思想教育的成效与审干扩大化造成的伤害，必须分别交代。

结果与历史联系暴露干部审查中的程序和判断问题，促使后来强调调查、证据和甄别。

6月1日思想文献

《关于领导方法的若干问题》

地点 / 范围：延安

中共中央通过领导方法文件，阐释一般号召与个别指导、领导与群众相结合的办法，概括从群众意见中集中、再回到群众实践的工作过程。文件回应干部在基层工作中容易只发指示、不作具体调查和指导的问题。

结果与历史联系把群众路线进一步概括为领导工作的基本方法，影响此后组织实践。

6月10日国际联系

共产国际正式解散

地点 / 范围：莫斯科、延安

共产国际在反法西斯战争环境下正式解散，中共中央此前已表示同意。中共从成立以来同共产国际保持的组织关系由此结束，独立处理本国革命问题的制度环境发生变化；过去国际联系带来的帮助和错误影响仍需分别总结。

结果与历史联系中共同国际共产主义组织关系进入新阶段，自主决策地位进一步明确。

夏统一战线

抵制第三次反共高潮

地点 / 范围：陕甘宁边区、重庆等

国民党顽固派借共产国际解散加大政治压力，并准备对边区采取军事行动。中共通过抗议、舆论、统一战线和军事准备加以抵制，未让事态发展成大规模内战。对日战争仍在继续，维护抗战与防止内部冲突成为并行任务。

结果与历史联系第三次反共高潮受到制止，为继续抗日保存合作空间和军事实力。

11月26日起政策建设

边区劳动英雄大会

地点 / 范围：延安

边区召开劳动英雄大会并举办生产展览，交流农业、工业和互助劳动经验。毛泽东在会上讨论组织群众生产的办法，大生产由机关部队自给进一步联系到群众合作。典型经验的推广同时需要结合不同地区的实际条件。

结果与历史联系促进生产经验交流与互助合作，帮助根据地逐步渡过财政经济困难。

本年军事活动

敌后根据地恢复与反“清乡”

地点 / 范围：华北、华中、华南

各根据地军民继续反“扫荡”、反“蚕食”和反“清乡”，逐步恢复部分地区与交通联系。华北、华中和华南条件不同，作战、生产和地下组织相互支援。1941—1942年的严重困难并非突然结束，而是在持续抵抗中有所缓解。

结果与历史联系为1944年局部反攻积累兵力、群众组织与区域联系的条件。

1月14日统一战线

中央民族工作会议

地点 / 范围：北京

江泽民在中央民族工作会议上讨论民族关系、区域自治和国家统一。改革发展时期的民族工作同时面对地区经济差异和制度落实等任务。

结果与历史联系民族地区发展与国家制度建设相互联系，不能只作口号化理解。

1月18日—2月21日改革开放

邓小平南方谈话

地点 / 范围：武昌、深圳、珠海、上海

邓小平在多地考察时讨论发展、改革和判断政策成效的标准，说明计划与市场并非区分两种社会制度的唯一依据。谈话推动了围绕改革方向的认识转变。谈话还提出以生产力、综合国力和人民生活作为判断改革成效的标准，并强调发展与共同富裕目标，回应姓社姓资等认识争论。

结果与历史联系推动思想解放与政策再出发，使建立社会主义市场经济体制的目标更易形成共识。

2月25日法治制度

领海及毗连区法通过

地点 / 范围：北京

全国人大常委会通过领海及毗连区法，以国内法律形式规定有关海域制度。海洋事务逐步进入更明确的法律规范框架，与国防和外交工作相联系。

结果与历史联系海洋权益的法律表达与具体外交争议应区分层次阅读。

3月8日科技文化

部署中长期科技发展

地点 / 范围：全国

国务院印发国家中长期科学技术发展纲领，把科技发展放在较长时间尺度安排。现代化建设既需要近期生产技术，也需要对基础研究和未来能力作规划。

结果与历史联系科技政策由单项攻关逐步向长期体系布局发展。

10月12日—18日党的建设

中国共产党第十四次全国代表大会

地点 / 范围：北京

十四大确定经济体制改革的目标是建立社会主义市场经济体制，并将邓小平建设中国特色社会主义的理论和基本路线写入党章。大会总结改革以来的实践，提出加快发展的任务。大会报告总结十一届三中全会以来经验，将改革方向从计划和市场关系的争论转化为明确制度目标，党章也作相应修改。

结果与历史联系九十年代财税、金融、企业和社会保障改革获得共同的总体方向。

10月19日党的建设

十四届一中全会

地点 / 范围：北京

全会选举江泽民为中央委员会总书记，决定其任中央军委主席，并批准尉健行为中央纪委书记。大会形成的政策目标由新一届中央领导机构组织推进。党中央领导机构在十四大后完成组织安排，中央纪委领导更替亦通过规定程序确认，为新一阶段改革部署提供组织保障。

结果与历史联系大会路线与中央组织体系衔接，改革政策进入进一步制定实施阶段。

11月统一战线

两岸形成事务性商谈共识

地点 / 范围：海协会与台湾海基会

海协会与台湾海基会就事务性商谈中如何表述一个中国原则进行沟通。所据官方资料将双方形成的相关共识称为后来所说的“九二共识”，这一名称属于后来的概括。两机构的沟通针对商谈中的具体表述方式，属于两岸事务交往中的政治前提讨论；“九二共识”一词是在后来才被概括使用。

结果与历史联系有关共识成为此后两岸协商的重要政治议题，名称、形成过程和不同解释需要区分。

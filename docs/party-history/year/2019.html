1月2日统一战线

纪念《告台湾同胞书》四十周年

地点 / 范围：北京

习近平在纪念会上提出新阶段推进和平统一的政策主张，涉及一个中国原则、两岸融合发展和相关制度探索。讲话与一九七九年文告相呼应，但所处两岸政治和国际环境已发生变化。

结果与历史联系中央对台政策在新的背景下作集中阐述，并持续影响两岸关系讨论。

政法工作条例与会议

3月15日改革开放

外商投资法通过

地点 / 范围：北京

十三届全国人大二次会议通过外商投资法，年底配套实施条例公布，统一规范外商投资活动及相关保障。改革开放进入更重视规则统一、投资保护和营商环境的阶段。统一法律出台后，实施条例与具体监管安排又将原则转化为操作规则。

结果与历史联系外资管理由分散制度逐步转向统一法律框架。

3月19日法治制度

公务员职务与职级并行

地点 / 范围：全国

中央办公厅发布公务员职务与职级并行规定，在领导职务之外设置职业发展与待遇安排。制度调整回应基层公务员晋升通道等问题，使人员管理不只依靠领导岗位数量。职级与领导职务相区分，为不担任领导岗位的公务员提供新的职业发展安排。

结果与历史联系干部激励与公务员职业发展方式得到新的制度安排。

5月9日经济社会

建立国土空间规划体系

地点 / 范围：全国

中央和国务院发布建立国土空间规划体系并监督实施的意见，整合不同类型空间规划，统筹生态、农业和城镇等用途。规划不仅决定项目落在哪里，也约束开发边界和资源使用。空间用途与开发边界因而需要在同一规划体系内协调，监督实施也被纳入制度。

结果与历史联系国土空间管理由多种规划并行转向更加统一的制度体系。

5月21日党的建设

“不忘初心、牢记使命”主题教育

6月6日科技文化

发放5G商用牌照

地点 / 范围：全国

工业和信息化部向四家运营商发放5G牌照，中国移动通信进入第五代网络商业部署阶段。商用建设需要基站、频谱、终端和应用等配套，技术试验与大规模服务因此衔接起来。牌照发放使网络建设进入商用阶段，运营和应用仍需多年持续投入。

结果与历史联系新型通信基础设施为产业数字化和社会信息服务提供条件。

9月18日经济社会

黄河流域生态保护战略

地点 / 范围：河南郑州、黄河流域

习近平主持黄河流域生态保护和高质量发展座谈会，把流域保护与发展提升为国家战略。黄河上中下游条件差异显著，治理需要统筹水资源、生态修复和地区经济活动。黄河全流域不同地区的用水与生态条件差异，使治理必须兼顾上下游关系。

结果与历史联系流域治理进一步突破单一行政区界限，强调跨区域协同。

1月11日—2月7日党的建设

七千人大会总结经验教训

地点 / 范围：北京

中央、省、地、县等层级七千余名干部参加扩大的中央工作会议。会议总结大跃进以来的问题，开展批评和自我批评，强调民主集中制及贯彻经济调整方针，力图统一对困难形势的认识。

结果与历史联系会议有助于改进中央与基层沟通，为推进调整创造条件，但没有彻底纠正所有左倾认识。

2月13日经济建设

生产队成为公社基本核算单位

地点 / 范围：全国农村

中央要求将人民公社的基本核算单位由生产大队改为生产队，使劳动组织、分配和财务核算更接近实际生产条件。政策对社、队及农户的经济利益关系重新划界，减少过大的统一调配。

结果与历史联系生产队核算稳定了此后较长时期的农村集体经济制度，有利于恢复生产责任。

2月21日—23日经济建设

西楼会议分析财政经济形势

地点 / 范围：北京

刘少奇主持中央政治局常委扩大会议，讨论预算与整体经济形势。会议认为困难比原先估计更严重，强调以农业为基础进行全面调整，并为进一步压缩建设规模、稳定市场和恢复财政平衡准备措施。

结果与历史联系更切实的困难判断推动调整加力，陈云等在后续财经工作中发挥重要作用。

3月2日科技教育

周恩来重申知识分子的作用

地点 / 范围：广东广州

周恩来在科学工作及文艺座谈活动中讨论知识分子问题，重新肯定绝大多数知识分子属于劳动人民，强调建设事业离不开科学家和专业人才。报告意在改善此前政治运动对知识界造成的不利环境。

结果与历史联系它推动知识分子政策调整，促进科研教育工作恢复和人才积极性发挥。

3月20日经济建设

对港鲜活商品快运列车开行

地点 / 范围：湖北等地至香港

供应香港鲜活、冷冻商品的快运货物列车从湖北江岸站开出，上海、郑州随后也开行相关快车。铁路运输、口岸和商品组织相配合，为香港居民提供较稳定的食品供应。

结果与历史联系内地与香港在特殊历史条件下仍保持密切民生与贸易联系，形成长期供应渠道。

9月24日—27日历史曲折

八届十中全会扩大阶级斗争论断

地点 / 范围：北京

八届十中全会召开，毛泽东进一步强调社会主义时期的阶级斗争。此后一些恢复生产的意见被扣上政治帽子，对包产到户等探索的批判加重，彭德怀等人的申诉也受到不当处理。

结果与历史联系阶级斗争扩大化开始冲击调整中的政策探索，并为后来政治运动升级埋下隐患。

10月20日起军事国防

中印边境战争

地点 / 范围：中印边境

边境紧张发展为中印双方军事冲突，中国边防部队展开作战。此后中国宣布停火并单方面后撤，战争使两国关系明显恶化；有关边界争议与各方历史主张仍需与战场经过分开理解。

结果与历史联系战争影响中国西南安全和亚洲外交格局，和平共处外交面临严峻的边界现实。

12月14日科技教育

核工业专门委员会成立

地点 / 范围：北京

中央决定设立十五人专门委员会，由周恩来任主任，加强原子能工业、核武器研制与试验工作的统一协调。科研、工厂、军队和物资部门借此加强配合，解决跨部门项目中的组织与资源问题。

结果与历史联系国家层面的集中协调成为此后核试验取得突破的重要组织保障。

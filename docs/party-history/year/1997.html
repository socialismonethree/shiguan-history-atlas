2月19日人物事迹

邓小平逝世

地点 / 范围：北京

邓小平逝世。他是改革开放和现代化建设的重要领导者，相关历史作用应结合一九七八年前后的转折、南方谈话以及政策形成过程理解，不把集体和群众实践简化为个人决定。

结果与历史联系人物逝世是历史分期线索，但制度和政策仍有自身延续性。

3月14日经济社会

设立重庆直辖市

地点 / 范围：北京、重庆

八届全国人大五次会议批准设立重庆直辖市，同时通过国防法等法律。行政区划调整与西部地区、长江上游的经济社会发展安排相联系。

结果与历史联系行政地位变化会影响区域规划、资源配置和城市治理。

3月28日党的建设

党员领导干部廉洁从政准则试行

地点 / 范围：全国

中央发布党员领导干部廉洁从政若干准则试行文本，对权力与利益边界提出制度要求。市场化发展中的公共权力监督继续成为党的建设重点。

6月4日科技文化

部署九七三基础研究计划

地点 / 范围：全国

国家科技领导小组决定制定重点基础研究发展规划，随后组织实施九七三计划。战略目标导向的基础研究获得新的组织方式与支持。计划强调国家战略目标导向的基础研究，不同于只着重短期技术产品的支持方式，科研资源开始围绕较长期科学问题组织。

结果与历史联系提升基础科研供给，为产业和重大工程积累长期知识能力。

6月30日午夜—7月1日凌晨统一战线

香港回归

地点 / 范围：香港

中英举行香港政权交接，中国恢复对香港行使主权，香港特别行政区成立，驻港部队开始履行防务职责。基本法和“一国两制”由过渡安排进入实际运行。香港特区政府随后宣誓就职，驻港部队接替防务，国家主权恢复、地方政府成立和特别行政区法律制度同时进入实际运行。

结果与历史联系一国两制由谈判与法律准备走向香港的日常治理实践。

7月经济社会

亚洲金融危机爆发

地点 / 范围：亚洲地区

亚洲金融危机爆发并影响区域经济环境。中国此后部署金融改革、整顿金融秩序与风险防范，外部金融冲击成为国内政策安排的重要背景。中央和国务院年底要求深化金融改革、整顿金融秩序并防范风险，外部冲击加快了对金融体系稳健性和监管问题的关注。

结果与历史联系危机使开放条件下的金融安全和宏观稳定成为更加突出任务。

9月2日经济社会

建立城市居民最低生活保障制度

地点 / 范围：全国城市

国务院要求在全国建立城市居民最低生活保障制度。市场化改革和国企调整过程中，面向低收入居民的社会救助制度逐渐形成。制度把符合条件的城市低收入居民纳入最低生活保障，与企业职工保险承担不同功能，为缺乏基本生活收入者提供兜底渠道。

结果与历史联系城市社会救助从局部探索转向全国制度安排，回应转型中的民生风险。

9月12日—18日党的建设

中国共产党第十五次全国代表大会

地点 / 范围：北京

十五大把邓小平理论确立为党的指导思想并写入党章，明确初级阶段基本经济制度，提出依法治国。大会把世纪之交的发展目标与改革经验联系起来。大会提出公有制为主体、多种所有制经济共同发展，强调依法治国，经济体制、社会制度与法治建设由此形成相互联系的任务。

结果与历史联系基本经济制度与法治目标在大会中明确，指导世纪之交改革布局。

11月8日经济社会

三峡工程大江截流

地点 / 范围：湖北宜昌

三峡水利枢纽工程成功实现大江截流，工程建设进入重要阶段。截流不同于全工程竣工或全部机组投产，后续建设持续多年。工程截流是施工中的关键节点，此后还要经历蓄水、机组安装和发电运行，同时持续处理移民安置、生态和流域管理问题。

结果与历史联系长江水利工程建设进入新阶段，对发电、航运和沿线社会产生长期影响。

全面调整与调查研究

1月1日历史曲折

信阳事件报告暴露错误认识

地点 / 范围：河南信阳

中央批转信阳地区有关报告，但报告把粮食减产和大量人口饿病死亡主要归咎于阶级敌人，混淆政策失误与敌我问题。原党史研究室年度资料明确指出这一批示助长了整风整社中的左倾错误。

结果与历史联系这一事件说明对灾难原因的错误判断，会使救灾和纠偏再次受到政治化处理的阻碍。

1月14日—18日经济建设

八届九中全会确定八字方针

地点 / 范围：北京

全会决定对国民经济实行调整、巩固、充实、提高的方针，降低过高的发展速度，优先恢复农业和保障基本生活。中央同时强调调查研究，领导干部随后到基层了解农村和工厂实际状况。

结果与历史联系全国建设由大跃进转入调整轨道，为逐步克服严重经济困难奠定政策基础。

3月6日经济建设

安徽试行责任田

地点 / 范围：安徽

安徽根据农村生产困难试行定产到田、责任到人的田间管理办法，部分农户和生产队积极响应。责任田在当年得到过一定支持，随后又被作为单干倾向批判，探索未能持续稳定推进。

结果与历史联系它反映基层寻求恢复生产的努力，也成为以后讨论农业经营责任制的历史经验。

3月15日—23日经济建设

农业六十条草案制定

地点 / 范围：广东广州

中央工作会议讨论农村人民公社工作条例，针对公社规模、管理权限、劳动和财务制度等作出调整。草案随后根据调查继续修改，试图用较明确的规则纠正公社化过程中的混乱。

结果与历史联系农村政策从急剧变动转向稳定经营和改善管理，为恢复农业创造条件。

3月23日党的建设

中央要求认真调查研究

地点 / 范围：全国

中央向各地发信，要求县以上党委领导干部学习调查研究方法，深入了解实际问题。有关调查工作的旧文被重新印发，中央和地方的调研结果开始进入农业、商业、工业和教育等政策修订。

结果与历史联系调查研究使政策调整获得基层材料，纠正只听口号和统计浮夸的工作方式。

4月9日经济建设

精简职工与调整劳动力

地点 / 范围：全国

中央转发调整农村劳动力和精简下放职工的报告，试图减少城镇口粮与工资支出压力，并向农业补充劳力。这一政策影响众多职工和家庭，既是经济调整措施，也改变城乡人口配置。

结果与历史联系压缩城市规模缓解当时供应紧张，但个体家庭需要承担迁移与就业变化的成本。

5月21日—6月12日经济建设

修订农村政策与取消公共食堂规定

地点 / 范围：北京

中央工作会议依据调查修订农业六十条，删去公共食堂和供给制等原有规定，同时讨论压缩城镇人口、下调钢产量及甄别受处分干部等工作。政策在生产、供应与组织处理上同步调整。

结果与历史联系农村家庭生活和集体生产的边界开始恢复，经济工作中的实事求是要求得到加强。

7月19日科技教育

科研十四条推动政策调整

地点 / 范围：全国

中央同意有关自然科学工作的政策意见，强调科研特点、知识分子使用及研究机构秩序。文件力求纠正此前简单化的政治干预，使科学工作更重视专业分工、研究规律与必要条件。

结果与历史联系科研政策调整为人才发挥作用和重点技术攻关创造了较有利环境。

9月15日—16日经济建设

高教与工业工作条例试行

地点 / 范围：全国

中央相继批准高教六十条和工业七十条等条例，要求高校恢复以教学为主，国营企业加强计划、责任制和管理秩序。这些措施把经济调整由总量压缩进一步落实到单位运行规则。

结果与历史联系教育质量、专业人才培养和企业管理的恢复，支撑此后国民经济逐步好转。

1928

农村根据地与红军力量汇合

井冈山会师、平江起义和赣东北等地斗争，使分散起义的力量逐步汇合、发展。六大在莫斯科召开，试图判断低潮中的革命任务；土地政策和工农武装割据的理论则在具体根据地实践中形成。

1月军事活动

弋横起义与赣东北斗争

地点 / 范围：江西弋阳、横峰

当地党组织领导农民武装起义，建立革命武装、开展土地斗争，并在敌军压力下逐步转向游击活动。方志敏等把群众组织与山区武装相结合，后来形成赣东北革命根据地。它是多个农村根据地分别成长的实例。

结果与历史联系赣东北逐步形成独立的农村革命根据地，扩展土地革命的地域布局。

1月起军事活动

湘南起义

地点 / 范围：湖南宜章、郴州、耒阳等

朱德、陈毅率南昌起义保留下来的部队进入湘南，同当地党组织和农民武装合作发动起义，扩大队伍。由于敌军进攻与环境变化，部队随后向井冈山地区转移。湘南斗争因而同南昌起义余部和井冈山会师形成连续关系。

结果与历史联系南昌起义余部与湘南农军结合，随后转移成为井冈山会师的重要力量。

4月下旬军事活动

井冈山会师

地点 / 范围：江西井冈山

朱德、陈毅率部及湘南农军与毛泽东领导的队伍会师，合编工农革命军第四军，后称红四军。朱德任军长，毛泽东任党代表和军委书记。会师增强根据地军事力量，也带来部队整合、组织制度和供给等新任务。

结果与历史联系多支革命部队合编为红四军，增强井冈山军事力量并提出新的整合任务。

5月20日—22日党的会议

湘赣边界第一次党代会

地点 / 范围：江西宁冈茅坪

湘赣边界党代表大会讨论根据地建设、土地革命和红军发展，产生边界特委。会议尝试把跨县游击活动组织成有党政军联系的区域性斗争。同月相关苏维埃政权逐步建立，为根据地的日常治理提供组织基础。

结果与历史联系跨县党组织与苏维埃政权逐步建立，使根据地治理更为稳定。

5月1日人物与社会

向警予在武汉被杀害

地点 / 范围：湖北武汉

大革命失败后，向警予留在武汉从事地下工作。1928年3月20日被捕后，她遭到审讯，仍未交出党组织秘密，5月1日被杀害。她此前在女工组织、妇女宣传和干部培养中的工作，与这一时期地下组织遭受的严重打击，共同构成理解其生平的背景。

结果与历史联系早期妇女运动失去了一位重要组织者；这一事件也反映国共合作破裂后，公开社会活动者转入地下工作的危险处境。

6月18日—7月11日党的会议

中共六大

地点 / 范围：莫斯科近郊

因国内环境险恶，中共六大在莫斯科举行。大会分析革命性质与形势，提出争取群众的工作要求，选举新的中央机构。会后向忠发任中央领导职务，周恩来承担重要中央工作。会议试图纠正低潮中急于组织全国暴动的倾向。

结果与历史联系提出争取群众的任务并选出新中央，试图纠正低潮中急于全国暴动的倾向。

7月22日军事活动

平江起义

地点 / 范围：湖南平江

原国民革命军部队在彭德怀、滕代远等领导下起义，建立红五军并组织当地政权。部分部队此后到井冈山会合，也有力量留在湘鄂赣边开展游击斗争。军队转变与地方农民组织的结合，为新根据地形成创造条件。

结果与历史联系建立红五军，部分赴井冈山会师，部分留湘鄂赣继续发展根据地。

10月5日思想文献

提出工农武装割据思想

地点 / 范围：湘赣边界

边界党的第二次代表大会通过毛泽东起草的决议，总结井冈山及其他地区红色政权的经验，解释农村革命力量为何能够存在和发展。相关论述把土地革命、武装斗争与根据地建设联系起来，尝试回答革命低潮中的道路问题。

结果与历史联系把土地革命、武装斗争和根据地建设联系起来，农村道路认识逐步系统化。

12月政策建设

井冈山《土地法》公布

地点 / 范围：湘赣边界

边界特委公布土地法，将土地分配问题纳入根据地政权的制度建设。早期规定仍有不完善之处，次年兴国土地法等又作调整。土地革命既是动员农民的重要手段，也涉及所有权、分配对象与生产秩序等复杂现实问题。

结果与历史联系土地分配成为根据地制度事务，其不完善规定推动次年进一步修正。

1931

苏区政权建设与民族危机

连续反“围剿”胜利扩大中央苏区，红四方面军和苏维埃临时中央政府相继建立。与此同时，九一八事变使民族危机急剧加深，党内教条主义与肃反扩大化造成严重损害。军事成长、治理尝试和内部教训并行存在。

1月7日党的会议

六届四中全会与领导变化

地点 / 范围：上海

在共产国际代表介入下，中共召开六届四中全会，王明等在中央的影响增强。其后以王明为代表的教条主义错误逐渐支配中央决策，既涉及革命形势判断，也影响组织和军事路线。不能因为纠正李立三冒险计划，就认定新的领导已避免类似错误。

结果与历史联系王明等在中央的影响加强，教条主义错误此后深入组织、政治和军事决策。

1月起历史教训

苏区肃反扩大化造成损失

地点 / 范围：中央苏区、鄂豫皖、湘鄂西等

各苏区在肃反工作中出现严重扩大化，许多干部、红军将士和群众被错误审查、拘捕乃至杀害。中央和地方不同机构均负有相应责任，地区过程也不完全相同。此类错误削弱革命力量，是土地革命时期必须正视的沉痛教训。

结果与历史联系许多干部、将士和群众遭冤错处理，削弱党和红军力量并留下沉重教训。

1月15日组织建设

苏区中央局成立

地点 / 范围：江西宁都小布

中共设立苏区中央局，以加强对中央根据地党政军工作的领导；周恩来未到职时先由项英代理书记。中央组织同根据地军事和政权建设的联系由此加强，但工作中也逐步受到中央错误路线影响，领导关系与军事分工不断变化。

结果与历史联系加强中央对苏区的直接领导，也使中央路线更直接影响根据地工作。

4月—5月军事活动

第二次反“围剿”胜利

地点 / 范围：江西东固、富田等

国民党军以较大兵力向中央苏区推进，红军先集中打击较弱一路，再连续机动作战，取得第二次反“围剿”胜利。胜利扩大根据地生存空间，并进一步积累集中优势兵力、在运动中歼敌的经验。

结果与历史联系巩固中央苏区，发展集中兵力、运动歼敌的军事经验。

7月—9月军事活动

第三次反“围剿”胜利

地点 / 范围：江西兴国及赣南地区

国民党军再次大举进攻中央苏区，红军通过长距离转移避开主力，寻找薄弱环节打击，最终击破进攻。连续反“围剿”的胜利巩固中央根据地，也使红军在兵力处于劣势时如何作战成为党内军事讨论的重要依据。

结果与历史联系中央苏区继续扩大，红军机动作战经验更加丰富，也成为后续军事争论的依据。

9月18日历史转折

九一八事变与东北抗日斗争

地点 / 范围：沈阳及中国东北

日本关东军发动事变并迅速侵占东北，东北民众和部分爱国官兵组织抵抗。中共开展抗日宣传、参与义勇军工作并逐步建立自身领导的抗日武装。民族危机由此显著加深，后来发展的东北游击战争成为长期抗战的重要组成。

结果与历史联系抗日抵抗和救亡动员在东北与全国发展，民族危机成为更突出的政治问题。

9月组织建设

临时中央在上海成立

地点 / 范围：上海、莫斯科

王明赴莫斯科参与共产国际工作后，上海成立由博古等负责的临时中央。该机构在严重的白色恐怖条件下活动，后来迁入中央苏区。领导机关的处境与其路线失误都应分别说明，不能以秘密工作的危险性免除决策责任。

结果与历史联系形成由博古等负责的临时中央，为1933年中央迁瑞金建立组织承接。

11月7日军事活动

红四方面军成立

地点 / 范围：湖北黄安七里坪

鄂豫皖根据地的红军部队合编为红四方面军，徐向前任总指挥，陈昌浩任政治委员。统一编组适应区域作战需要，部队随后进行多个战役并向川陕发展。其来源、指挥系统与中央苏区红一方面军应加以辨别。

结果与历史联系鄂豫皖主力实现统一编组，为后来川陕发展和长征提供重要力量。

11月7日—20日党的会议

中华苏维埃第一次全国代表大会

地点 / 范围：江西瑞金

大会通过宪法大纲、劳动法、土地法等文件，宣布成立中华苏维埃共和国临时中央政府，选举中央执行委员会，并建立相应军事领导机关。它是中共在局部地区探索政权建设的重要尝试，治理范围并不等于全国实际控制范围。

结果与历史联系建立较系统的苏维埃政权、法律和行政机构，是中共局部执政的重要尝试。

11月—12月思想文献

红色通讯与机关报建立

地点 / 范围：江西瑞金

红色中华通讯社于11月成立，临时中央政府机关报《红色中华》于12月创刊。通讯社和报刊承担发布政策、报道苏区建设、沟通各地消息的任务。红色中华通讯社到1937年改称新华社，机构名称的变化应按时间辨认。

结果与历史联系苏区政策与新闻拥有稳定传播机构，红色中华通讯社后来发展为新华社。

12月14日军事活动

宁都起义

地点 / 范围：江西宁都

国民党第二十六路军一部在赵博生、董振堂等率领下起义，随后改编为红五军团。地下党工作、士兵处境和政治军事形势共同影响这一转变。起义为红军补充人员和装备，也带来对原有军队进行政治、组织改造的任务。

结果与历史联系原国民党军转为红五军团，为红军增加有组织的人员装备和军事骨干。

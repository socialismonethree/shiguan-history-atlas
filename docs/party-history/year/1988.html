2月25日改革开放

部署城镇住房制度改革

地点 / 范围：全国城镇

国务院提出分期分批推行城镇住房制度改革。住房供给逐步从单位包办转向新的分配和管理方式；1998年停止实物分配是后来阶段，不能提前写入1988年。方案要求分期分批推行，显示住房改革需在收入、财政和住房供给条件中逐步实施，后来又发展到货币化分配安排。

结果与历史联系职工住房与单位福利关系逐渐改变，为九十年代住房制度改革奠定政策基础。

3月14日国防军事

南沙海域军事冲突

地点 / 范围：南沙群岛海域

中国海军在南沙海域进行军事行动，权威大事记称为南沙群岛自卫还击作战。条目记录事件发生与国防背景，具体海战过程、法律主张需结合专门史料阅读。

结果与历史联系海洋权益问题是这一时期国防外交工作的重要背景之一。

3月25日—4月13日改革开放

海南建省并设经济特区

地点 / 范围：北京、海南

七届全国人大一次会议决定设立海南省和海南经济特区，批准国务院机构改革方案，并完成国家机构换届。开放区域扩大与行政管理体制调整在同年展开。会议同时批准机构改革并推动部门职能、机构和编制的“三定”工作，把行政改革同扩大开放放在年度国家建设议程中。

结果与历史联系海南成为大范围经济特区，政府部门职责和组织配置也进一步明确。

6月1日党的建设

要求党和国家机关保持廉洁

地点 / 范围：全国

中共中央发出关于党和国家机关保持廉洁的通知。市场活动增加和行政管理调整带来新的权力利益关系，纪律要求需要针对经济转型中的具体问题作出回应。

7月1日国防军事

军队实行新的军衔制度

地点 / 范围：北京、全军

全国人大常委会通过军官军衔条例，为人民解放军实行新军衔制度提供法律依据。军衔设置与人员管理、部队正规化建设相联系。

结果与历史联系军衔属于军队组织管理制度，不应与职务和历史授衔混为一谈。

8月科技文化

火炬计划启动

地点 / 范围：全国

国务院批准实施火炬计划，推动高新技术产业发展。与侧重前沿研究的规划相比，它更关注技术成果产业化和企业发展，体现科技与经济结合的不同路径。火炬计划更着重技术成果商品化、产业化及高技术企业成长，与八六三计划的前沿研究布局相互配合，支持路径有所区别。

结果与历史联系高技术发展由科研规划进一步延伸到产业组织和企业经营环境。

9月5日、12日思想理论

科技生产力与区域“两个大局”

地点 / 范围：北京

邓小平强调科学技术在生产力中的地位，又提出沿海先发展、条件成熟后帮助内地发展的“两个大局”思路，把效率、区域差距与共同发展联系起来。

结果与历史联系改革战略同时处理技术进步和地区发展先后次序的问题。

9月26日—30日经济社会

十三届三中全会提出治理整顿

地点 / 范围：北京

全会提出治理经济环境、整顿经济秩序并全面深化改革。它反映改革推进中通货膨胀和经济运行压力增加，政策需要在继续改革与稳定经济之间作调整。全会把治理环境、整顿秩序与深化改革同时提出，说明中央认为稳定宏观运行是改革继续推进的现实条件，而非二者简单对立。

结果与历史联系改革进入调整阶段，稳定物价和经济秩序成为随后数年工作的重要重点。

10月16日科技文化

北京正负电子对撞机对撞成功

地点 / 范围：北京

中国第一座高能加速器实现正负电子对撞，为粒子物理实验提供重要装置。大型科研设施的建设既依靠自主研发，也包含科学合作与专业人才培养。

结果与历史联系基础研究能力是现代化的一部分，其成果不等同直接商业产出。

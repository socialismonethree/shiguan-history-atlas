3月9日—12日党的建设

十三届六中全会讨论党群联系

地点 / 范围：北京

全会通过加强党同人民群众联系的决定，要求改进工作方式。会议发生在政治风波和治理整顿背景下，党群关系与干部作风成为中央关注的重要问题。

结果与历史联系党的建设不能只读机构名单，也要看其与社会群众的关系。

3月20日—4月4日法治制度

香港基本法通过

地点 / 范围：北京

七届全国人大三次会议通过香港特别行政区基本法和设立香港特别行政区的有关决定，并选举江泽民为国家中央军委主席。香港过渡安排进一步获得法律形式。基本法围绕香港特别行政区制度作法律安排，与中英联合声明相衔接；国家中央军委主席职务也在本次人大会议完成交接。

结果与历史联系香港恢复主权后的制度框架法律化，国家军事领导机构完成相应更替。

4月12日改革开放

批准浦东开发开放方案

地点 / 范围：上海浦东

中央政治局原则通过浦东开发开放方案，上海浦东成为新的国家级开发开放区域。开放由沿海地区的先行探索，进一步进入大型城市功能和区域经济结构调整。浦东开发以综合城市区域为载体，超越早期小范围出口加工试验，将金融、贸易、产业和城市功能放在更广背景中推进。

结果与历史联系上海成为九十年代开放的重要枢纽，国家级新区这一形式也在以后逐渐扩展。

4月对外关系

首次参加联合国维和行动

地点 / 范围：联合国停战监督组织

中国向联合国停战监督组织派遣五名军事观察员，开始参加联合国维和行动。1992年成建制派出工程兵是后来一步，不应与本年的首次派遣混同。首批人员属于军事观察员，与后来成建制工程兵参加维和不同，体现中国参与联合国行动由小规模人员派遣逐步发展。

结果与历史联系中国军队的国际合作任务从观察员参与开始积累经验。

5月25日、7月7日党的建设

完善干部民主生活与交流制度

地点 / 范围：全国

中央先后制定党员领导干部民主生活会规定和干部交流制度决定，对党内生活与干部任职管理作出安排。制度建设试图把组织监督和人员流动纳入较固定的程序。

结果与历史联系党内管理逐步形成可持续的组织规则。

9月1日经济社会

沈大高速公路通车

地点 / 范围：辽宁沈阳至大连

中国大陆早期建设的沈大高速公路正式通车，加强沈阳与大连之间的运输联系。高速公路建设与区域产业、港口物流和城市往来相互促进。

结果与历史联系交通基础设施扩展，是观察经济空间变化的具体线索。

9月22日—10月7日科技文化

北京举办亚洲运动会

地点 / 范围：北京

第十一届亚洲运动会在北京举行，是中国首次承办综合性国际体育大赛。赛事组织、城市建设和对外交流共同构成其时代背景。

结果与历史联系大型国际赛事展示开放进程，也依赖城市公共设施和组织能力。

11月26日、12月19日改革开放

上海证券交易所成立并开业

地点 / 范围：上海

上海证券交易所于11月成立，12月正式开业，新中国大陆资本市场出现重要制度平台。企业融资、证券发行和市场监管由此进入新的探索阶段。证券交易由组织成立进一步进入正式经营，企业融资与居民投资出现新的制度渠道，同时对信息披露和市场监管提出要求。

结果与历史联系大陆证券市场形成重要平台，资本配置和企业改革开始出现新的连接方式。

长征转折、陕北落脚与抗日联合

遵义会议调整领导，中央红军通过灵活机动摆脱合围，最终抵达陕北；张国焘分裂带来严重危机，西北地方红军的贡献也至关重要。华北危机、一二·九运动与瓦窑堡会议推动抗日统一战线策略发展。

1月15日—17日党的会议

遵义会议

地点 / 范围：贵州遵义

中央政治局扩大会议集中讨论第五次反“围剿”和长征初期失利，调整中央领导与军事指挥。毛泽东进入政治局常委，张闻天随后代替博古负总责，新的军事决策分工逐步形成。不能把后续数周完成的调整全部写成会议当天决定。

结果与历史联系纠正关键军事和组织问题，新的中央领导与军事决策分工逐步形成。

1月下旬—5月上旬军事活动

四渡赤水与巧渡金沙江

地点 / 范围：川黔滇交界

中央红军随敌情不断改变行动方向，反复渡过赤水，随后南渡乌江、向云南机动并渡金沙江，摆脱多路敌军追堵。行动依靠侦察、快速转移和集中指挥，不是按预先固定路线执行的简单行军。

结果与历史联系通过连续机动摆脱重兵追堵，中央红军恢复战略主动并继续北上。

5月—7月军事活动

陕甘革命根据地连成一片

地点 / 范围：陕北、陕甘边

西北红军和游击队在刘志丹等领导下进行反“围剿”，使陕甘边与陕北根据地逐渐连接。当地多年斗争形成的政权、群众组织和部队，为后来各路红军长征到达提供生存基础。不能把西北根据地写成中央红军抵达后才建立。

结果与历史联系陕甘边与陕北力量连片，为各路红军长征提供可依托的根据地。

5月下旬—6月中旬军事活动

大渡河、夹金山与懋功会师

地点 / 范围：四川大渡河、泸定、懋功

中央红军越过凉山彝族地区，渡大渡河、夺泸定桥，再翻越夹金山，与红四方面军在懋功地区会合。山川、天气、补给和民族关系都是行军的真实条件。两支主力会合增强力量，但对发展方向的分歧随后转为严重危机。

结果与历史联系中央红军突破自然与军事险阻并同红四方面军会师，随后面对新的整合与路线分歧。

8月1日拟定统一战线

八一宣言倡导抗日救国

地点 / 范围：莫斯科、巴黎

中共驻共产国际代表团草拟抗日救国宣言，主张停止内战、组织国防政府和抗日联军。宣言后来在海外刊物公开发表，推动救亡舆论与合作主张传播。草拟日期、海外发表时间及国内实际收到时间，不应混为同一节点。

结果与历史联系停止内战、组织联合抗日的主张广泛传播，推动抗日统一战线发展。

9月—10月历史教训

张国焘反对北上并另立中央

地点 / 范围：川西北、甘南

一、四方面军会合后，张国焘拒绝中央北上方针，要求部队南下，并于10月另立“中央”。中共中央率部分主力继续北进，红四方面军南下作战遭严重损失。分裂破坏统一指挥，1936年另立机构才被取消。

结果与历史联系党和红军统一指挥遭破坏，红四方面军南下受重大损失，分裂延至翌年才被纠正。

9月中旬军事活动

红二十五军抵达陕甘

地点 / 范围：陕甘革命根据地

红二十五军结束长征到达陕甘地区，同当地红二十六、红二十七军会合，合编红十五军团。不同来源部队的结合，增强了西北根据地军事力量，也为随后中央红军抵达及新的战略部署提供有利条件。

结果与历史联系组成红十五军团，增强西北根据地兵力并为中央红军抵达提供条件。

10月19日军事活动

中央红军抵达吴起镇

地点 / 范围：陕西吴起

中央红军北上部队到达吴起镇，中央红军主力长征结束，随后恢复红一方面军番号。到达根据地不意味着战争压力消失，仍需面对追兵、整编与补给问题。其他主力红军尚在途中，全国性的长征会师将在1936年完成。

结果与历史联系中央红军主力长征结束，中共中央在西北建立新的战略立足点。

11月历史教训

纠正陕北错误肃反

地点 / 范围：陕北瓦窑堡等

中共中央进入陕北后，停止当地正在扩大的错误肃反，释放刘志丹等被错误拘押的干部，保护西北党组织和红军骨干。纠错对稳定新落脚区域和整合各路力量具有实际作用，也揭示“肃反”名义下的扩大化曾造成严重危险。

结果与历史联系释放被错误拘押的干部，保护西北组织和红军骨干，有利于各路力量团结。

直罗镇战役

地点 / 范围：陕西直罗镇

12月9日工农运动

一二·九运动

地点 / 范围：北平及全国各地

在日本加紧侵略华北的背景下，北平学生举行抗日救亡示威，反对分裂华北、要求停止内战。运动遭压制却迅速向全国扩展，推动更多青年走向救亡活动。中共地下组织参与领导，学生则是运动的直接主体。

结果与历史联系抗日救亡扩展为全国青年与社会运动，推动停止内战的公共要求。

地点 / 范围：陕北瓦窑堡

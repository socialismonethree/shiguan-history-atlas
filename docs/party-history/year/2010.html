1月1日改革开放

中国东盟自贸区全面启动

地点 / 范围：中国、东盟地区

中国与东盟自由贸易区全面启动，区域贸易合作进入新的实施阶段。关税和贸易安排的调整加强双方经贸联系，并与产业和运输网络发展相互作用。

结果与历史联系区域开放不仅改变贸易总额，也影响企业经营与分工结构。

3月14日法治制度

城乡按相同人口比例选举代表

地点 / 范围：北京、全国

全国人大修改选举法，实行城乡按相同人口比例选举人大代表。城乡代表名额分配制度的重要变化，通过具体选举程序落实。原来城乡代表名额比例存在差别，此次修改通过相同人口比例原则调整代表选举规则，制度变化将在具体换届选举中落实。

结果与历史联系城乡居民在人大代表名额分配上的差别进一步缩小。

4月30日—10月31日科技文化

上海世界博览会

地点 / 范围：上海

上海举办综合性世界博览会，各国围绕城市和发展主题参展。会展组织、城市基础设施、国际交流和公众参观共同构成这一大型活动。博览会以城市发展为主题，参与国家、企业和公众通过展览交流技术与生活经验，上海同时完善场馆周边和城市公共设施。

结果与历史联系大型国际交流扩展到城市与可持续发展主题，促进公众接触不同文化和技术实践。

6月19日、7月21日思想理论

加强党史工作部署

地点 / 范围：北京、全国

中央印发加强和改进党史工作的意见，随后召开全国党史工作会议，明确研究、资料整理和宣传等任务。官方党史研究的组织与制度安排进一步完善。文件明确党史研究、资料整理、宣传和机构领导等要求，强调提高党史工作水平，党史知识生产由此获得更集中的组织部署。

结果与历史联系为此后百年党史资料建设、研究和公共传播提供制度背景。

7月8日科技文化

中长期教育改革发展规划

地点 / 范围：全国

中央和国务院发布教育改革与发展规划纲要，安排二〇一〇至二〇二〇年的教育任务，涉及公平、质量和人才培养。纲要覆盖多个教育阶段，要求在普及基础上提高质量和公平，教育资源、教师与制度改革被放在十年周期内统筹安排。

结果与历史联系教育发展由规模扩张进一步转向质量和机会改善。

10月15日—18日经济社会

十七届五中全会谋划十二五

地点 / 范围：北京

全会通过第十二个五年规划建议，讨论转变经济发展方式和下一阶段建设任务。经济总量扩大后，结构与可持续性问题更加突出。建议围绕下一阶段经济社会发展设定目标，资源约束、产业结构和公共服务受到重视，与转变发展方式的要求相互衔接。

结果与历史联系十二五成为调整增长方式与加强社会建设的重要规划阶段。

12月21日经济社会

全国主体功能区规划发布

地点 / 范围：全国

国务院发布全国主体功能区规划，对不同地区国土空间开发提出分类安排。资源环境承载能力和区域功能定位被纳入国家层面的空间规划。规划对国土空间按主要功能分类，不同区域在生态保护、农业和城镇工业发展上承担不同任务，以避免开发强度超过资源环境条件。

结果与历史联系国家空间治理开始强调功能分区和差异化管理。

本年经济社会

成为世界第二大经济体

地点 / 范围：全国

按所据权威大事记，本年国内生产总值超过四十万亿元，中国成为世界第二大经济体。经济体量上升与人口规模、产业发展和国际联系密切相关。

结果与历史联系总量地位不等于人均发展水平或所有公共服务问题均已解决。

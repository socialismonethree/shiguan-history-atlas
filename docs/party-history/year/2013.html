2013

全面深化改革的制度部署

新一届国家机构产生，十八届三中全会提出全面深化改革总目标，政府与市场关系进一步调整。群众路线教育、行政审批改革、上海自贸试验区与“一带一路”倡议，形成国内治理和对外开放的多条新线索。

1月21日—22日党的建设

部署惩治腐败与权力监督

地点 / 范围：北京

十八届中央纪委二次全会召开，习近平提出同时查处高级干部违纪违法和群众身边的腐败问题，强调制度制约权力。此后反腐败工作与巡视、党内法规和监督机构建设相互配合，不能只理解为查办个别案件。

结果与历史联系反腐败在这一时期成为党的建设的持续重点，并影响干部管理与权力运行方式。

2月26日—28日法治制度

十八届二中全会讨论机构改革

地点 / 范围：北京

全会通过国务院机构改革和职能转变方案，随后提交全国人大审议。改革既调整部门设置，也强调政府职能转变，回应行政审批过多、部门职责交叉和经济社会治理需求变化等问题。

结果与历史联系机构改革从组织数量调整进一步指向政府与市场、社会之间的职能边界。

3月5日—17日法治制度

国家机构换届完成

地点 / 范围：北京

十二届全国人大一次会议选举习近平为国家主席、国家中央军委主席，张德江为全国人大常委会委员长，决定李克强任国务院总理，并批准机构改革方案。党的中央领导交接与国家机构换届在不同会议完成。

结果与历史联系形成新一届国家机构领导安排，为后续改革部署和政策实施提供组织基础。

3月22日—30日对外关系

阐述新型国际关系与对非政策

地点 / 范围：俄罗斯、坦桑尼亚等

习近平访问俄罗斯和非洲三国，并出席金砖国家领导人会晤。他在莫斯科讨论人类命运共同体和合作共赢，在坦桑尼亚说明对非政策理念。访问把大国关系、新兴经济体合作与发展中国家关系相联系。

结果与历史联系中国外交开始更加集中表达合作共赢和发展伙伴关系等政策理念。

4月24日改革开放

取消和下放行政审批

地点 / 范围：全国

国务院常务会议决定先行取消和下放七十一项行政审批事项，推动简政放权。改革从具体许可项目入手调整政府管理方式，此后又逐步与加强事中事后监管、优化服务相结合，形成“放管服”改革线索。

结果与历史联系企业和群众办事环境成为行政改革的重要检验领域，减少审批也要求改进监管。

5月9日党的建设

部署群众路线教育实践活动

地点 / 范围：全国

中央印发开展党的群众路线教育实践活动的意见，随后分两批实施，重点整治形式主义、官僚主义、享乐主义和奢靡之风。活动涉及领导机关、干部作风和群众反映突出问题，并延续至次年。

结果与历史联系作风整顿由中央八项规定继续扩展到党内教育、检查和具体问题整改。

5月17日—18日党的建设

中央巡视工作加强

地点 / 范围：北京、全国

中央召开巡视工作动员与培训会议，把巡视作为发现党组织和干部问题的重要制度手段。此后十八届中央分轮开展巡视，覆盖对象和工作程序不断扩展，并以相关条例进一步制度化。

结果与历史联系巡视由既有监督形式发展为这一时期党内监督与反腐败的重要渠道。

8月17日改革开放

批准上海自由贸易试验区

地点 / 范围：上海

国务院批准设立上海自由贸易试验区，为投资管理、贸易便利化和监管制度试验提供区域平台。九月发布的外资准入负面清单，把试验从优惠政策进一步转向管理规则创新。其后自贸试验区在更多省区市设立，上海先行试验成为全国制度探索的一个起点。

结果与历史联系自贸试验区为扩大开放与国内制度改革之间建立了新的试验接口。

9月7日、10月3日对外关系

提出“一带一路”倡议

地点 / 范围：哈萨克斯坦、印度尼西亚

习近平在哈萨克斯坦提出共同建设丝绸之路经济带，在印度尼西亚提出二十一世纪海上丝绸之路。倡议以历史交流意象连接现实经济合作，后来逐步扩展为政策沟通、基础设施和多领域合作安排。

结果与历史联系对外合作从双边项目进一步形成跨区域框架，实施方式和成果需按后续年份观察。

11月9日—12日改革开放

十八届三中全会

地点 / 范围：北京

全会通过全面深化改革决定，提出完善和发展中国特色社会主义制度、推进国家治理现代化的总目标，强调市场在资源配置中起决定性作用并更好发挥政府作用，部署经济、政治、文化、社会和生态等领域改革。

结果与历史联系改革由单个领域推进转向更综合的制度设计，政府与市场关系形成新的表述。

11月18日党的建设

党政机关节约反浪费条例出台

地点 / 范围：全国

中央和国务院发布党政机关厉行节约反对浪费条例，把经费、差旅、公务接待、车辆和办公用房等纳入规范。它将作风要求转化为可识别的管理制度，后续配套文件又细化不同活动的支出和组织规则。

结果与历史联系公务活动的经费与资源使用成为监督重点，作风整顿开始与日常财务制度衔接。

12月2日、14日科技文化

嫦娥三号实现月面软着陆

地点 / 范围：中国、月球

嫦娥三号于十二月二日发射，十四日在月球表面软着陆，推进月面就位与巡视探测。中国月球探测由绕月观测进入落月阶段，任务需要发射、深空测控、制导和探测设备等系统协作。

结果与历史联系为此后的月背着陆和采样返回积累经验，但各次任务成果应按实际年份分开。

12月21日经济社会

调整生育政策

地点 / 范围：全国

中央和国务院发布调整完善生育政策的意见，提出单独两孩政策。此前长期人口控制政策开始作新阶段调整，政策变化与人口年龄结构、家庭生育意愿和经济社会条件相联系，全面两孩则在后来实施。

结果与历史联系人口政策由控制数量逐步转向兼顾结构与长期均衡，影响家庭生活与公共服务需求。

1927

大革命失败与武装斗争转折

上海工人起义的成功很快遭遇四一二政变，武汉分共使合作全面破裂。中共在严重损失中召开八七会议，组织南昌、秋收、广州等起义，并探索井冈山农村根据地。城市暴动的失败和新的冒险错误也须一并理解。

1月—2月统一战线

汉口、九江英租界收回

地点 / 范围：武汉、九江

工人和市民的反帝行动与武汉政府的外交谈判相配合，英国先后同意交还汉口、九江租界。群众压力和外交交涉共同发挥作用，成为近代中国收回租界的重要事件。它发生在北伐推进、武汉政治力量上升的背景下。

结果与历史联系群众行动与谈判共同促成租界交还，增强反帝运动的社会信心。

3月思想文献

《湖南农民运动考察报告》发表

地点 / 范围：湖南、武汉

毛泽东实地考察湖南农村后，发表报告讨论农会活动及农民对乡村秩序的改变，回应对农民运动的指责。报告把农村社会关系和农民作用放在国民革命的中心位置，成为当时党内外土地与群众路线争论的重要文本。

结果与历史联系农村调查进入革命理论和政策争论，农民问题在党内议程中的地位上升。

3月21日—22日工农运动

上海工人第三次武装起义

地点 / 范围：上海

在前两次起义失败后，上海工人再次组织总罢工和武装行动，击败军阀守军，成立临时市政府。周恩来承担军事指挥，赵世炎等参加领导。城市工人一度控制上海主要城区，但武装力量与政治成果很快面临蒋介石方面的压迫。

结果与历史联系工人一度掌握上海主要城区并建立临时市政府，随后成果遭四一二政变破坏。

4月6日—28日人物事迹

李大钊被捕并遇害

地点 / 范围：北京

奉系军阀在北京逮捕李大钊等人，4月28日将其处死。李大钊长期推动马克思主义传播、创建北方党组织并开展统一战线工作，其遇害使北方革命力量遭到重大损失。此时南方国共关系也迅速恶化，革命面临多方面打击。

结果与历史联系北方党组织失去主要领导者，反帝反军阀工作遭受重大损失。

4月12日历史转折

四一二政变

地点 / 范围：上海及多省

蒋介石在上海发动清共政变，工人武装被解除，大批共产党员和群众遭逮捕、杀害。类似镇压随后在多省发生。国民革命阵营出现严重分裂，中共在城市、军队和群众组织中积累的力量受到沉重破坏。

结果与历史联系合作阵营分裂，大批党员和群众被捕杀，革命由高涨走向失败。

4月27日—5月9日党的会议

中共五大召开

地点 / 范围：武汉

五大在国共合作已发生严重危机时举行，讨论革命领导、土地等问题，产生中央委员会和中央监察委员会。大会未能及时解决挽救革命的迫切问题。根据大会要求，会后修改党章，并正式规定民主集中制的组织原则。

结果与历史联系成立中央监察委员会等机构，但未能解决当时挽救革命的迫切战略问题。

7月15日历史转折

武汉分共与大革命失败

地点 / 范围：武汉

汪精卫方面宣布分共并大规模逮捕、杀害共产党人和革命群众，第一次国共合作全面破裂。中共原先依托合作推进革命的条件被摧毁，需要重新确定军事、土地与组织路线。大革命的失败不是单一城市的孤立事件。

结果与历史联系第一次国共合作全面破裂，中共被迫重新选择组织、土地和军事道路。

8月1日军事活动

南昌起义

地点 / 范围：江西南昌

中共前敌委员会组织所掌握和影响的部队在南昌起义，占领城市后南下广东。起义军后来遭受严重挫折，部分力量继续斗争。它标志中共开始独立领导革命战争和创建人民军队，8月1日后来被确定为建军纪念日。

8月7日党的会议

八七会议

地点 / 范围：湖北汉口

中共中央紧急会议总结大革命失败，批评陈独秀领导时期的错误，确定土地革命和武装斗争方针，选出临时中央政治局。瞿秋白随后主持中央工作。毛泽东在会上强调军事问题，革命的工作方式由此发生重大转变。

9月9日军事活动

湘赣边界秋收起义

地点 / 范围：湖南、江西边界

毛泽东等组织工农革命军发动秋收起义，原定攻打长沙的行动受挫后，部队改变方向，向敌人控制较弱的农村山区转移。随后三湾改编与井冈山斗争逐步展开。秋收起义的意义包含失败后的路线调整，而不只是起义当天。

结果与历史联系进攻长沙受挫后转向农村，为井冈山根据地建设开辟实际出路。

9月29日组织建设

三湾改编

地点 / 范围：江西永新三湾

秋收起义余部到达三湾后进行改编，缩编部队，建立党的基层组织并调整军队内部关系。党支部建在连队，使党组织直接深入基层军事单位。它是在部队面临失利、减员和动摇的条件下，为重新凝聚队伍而采取的措施。

结果与历史联系党组织深入连队，加强部队凝聚和政治领导，为新型军队制度奠基。

10月军事活动

创建井冈山根据地

地点 / 范围：江西井冈山及湘赣边界

毛泽东率部进入井冈山地区，同当地武装和群众建立联系，逐步形成农村革命根据地。地形、群众基础、地方党组织与军事活动共同构成生存条件。根据地的建设此后还需经受经济困难、敌军进攻和党内路线争论。

10月—11月工农运动

海陆丰苏维埃政权建立

地点 / 范围：广东海丰、陆丰

当地党组织联合农民武装及南昌起义军余部再次发动起义，在海陆丰建立县苏维埃政府。农民组织与土地斗争转向政权建设，成为土地革命早期的地方实践。政权随后遭敌军反扑，发展过程有明显的起伏。

结果与历史联系把海陆丰农会和武装斗争推进到地方政权建设，但也面临敌军持续反扑。

11月军事活动

黄麻起义

地点 / 范围：湖北黄安、麻城

黄安、麻城地区党组织领导农民和地方武装起义，建立农民政府与工农革命军。县城后来失守，部分队伍转入山区坚持斗争。起义保存的力量逐渐成为鄂豫皖地区革命武装发展的来源之一。

结果与历史联系县城失守后部分力量转入游击，为后来鄂豫皖武装发展保存骨干。

11月9日—10日党的会议

临时政治局扩大会议的冒险方针

地点 / 范围：上海

中央临时政治局在革命低潮中召开扩大会议，提出在全国实行城市武装暴动的方针，过高估计当时的革命形势。实际执行造成组织和群众力量损失，后来停止执行。转向武装斗争并未自动避免对形势的误判。

结果与历史联系盲目估计革命形势导致新的损失，后来停止执行全国暴动计划。

12月11日军事活动

广州起义

地点 / 范围：广州

中共广东省委组织军队和工人武装起义，成立广州苏维埃政府。敌军迅速反扑，起义失败，张太雷等遇害，部分余部撤出继续斗争。这次行动同南昌、秋收起义一起，构成中共独立武装斗争早期探索的重要节点。

结果与历史联系起义失败并造成张太雷等重大牺牲，余部撤出后继续参与地方武装斗争。

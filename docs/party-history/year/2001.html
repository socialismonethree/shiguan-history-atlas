1月10日思想理论

提出依法治国与以德治国结合

地点 / 范围：北京

江泽民在全国宣传部长会议上强调依法治国与以德治国相结合。讲话把制度规范与社会道德建设放在国家治理的共同框架内讨论。

结果与历史联系法治与道德建设功能不同，二者联系不意味着可以相互替代。

2月19日科技文化

首届国家最高科学技术奖颁授

地点 / 范围：北京

国家科学技术奖励大会向吴文俊和袁隆平颁授二〇〇〇年度国家最高科学技术奖，分别体现数学研究与农业科技等领域的长期贡献。

结果与历史联系科研评价不能只看即时经济收益，不同学科贡献有不同体现方式。

5月24日—25日经济社会

部署新阶段农村扶贫

地点 / 范围：北京、全国农村

中央扶贫开发工作会议总结世纪末温饱目标，部署新阶段减贫，国务院随后印发二〇〇一至二〇一〇年农村扶贫纲要。脱贫工作转向新的对象与发展任务。新纲要设定二〇〇一至二〇一〇年的工作周期，使温饱改善后的扶贫进入新的政策阶段，重点区域与任务也随之调整。

结果与历史联系扶贫由解决最基本温饱进一步转向持续发展与公共服务改善。

6月15日对外关系

上海合作组织成立

地点 / 范围：上海

中国、俄罗斯及中亚四国元首签署成立宣言，建立上海合作组织。此前的元首会晤机制发展为常设合作组织，安全、经济与地区协作逐步展开。组织在此前中国、俄罗斯与中亚国家元首会晤机制上发展而来，成立宣言明确互信、平等协商和共同发展等合作原则。

结果与历史联系地区安全协作有了常设组织平台，经济和人文合作也逐渐拓展。

6月29日经济社会

青藏铁路开工

地点 / 范围：青海格尔木、西藏拉萨

青藏铁路开工典礼在两地同时举行，建设连接青藏高原的铁路。工程需应对高寒、冻土和生态条件，正式通车则发生在二〇〇六年。铁路建设不仅跨越高原自然条件，也需要沿线运输、补给和生态保护相配合，体现大型工程从开工到运营的长期过程。

结果与历史联系为青藏高原交通联系和后续地区发展创造新的基础条件。

7月1日思想理论

庆祝建党八十周年

地点 / 范围：北京

建党八十周年大会举行，江泽民讲话总结党的历史经验并阐述“三个代表”重要思想。讲话成为理解此后十六大相关理论安排的重要文献。讲话在总结历史之外阐明党的建设与变化中的社会条件相适应的问题，成为后来党章修改和理论概括的重要依据之一。

结果与历史联系三个代表重要思想得到更系统阐述，推动新阶段党的建设讨论。

十五届六中全会讨论作风建设

地点 / 范围：北京

全会通过加强和改进党的作风建设的决定，提出一组坚持与反对的要求。党风建设关注干部行为与群众关系，回应执政和市场环境变化产生的问题。

11月10日、12月11日改革开放

中国加入世界贸易组织

地点 / 范围：卡塔尔多哈、中国

世贸组织部长级会议通过中国加入决定，十二月十一日中国正式成为成员。加入不仅扩大贸易机会，也意味着按承诺调整相关制度和开放安排。中国须履行市场准入、贸易规则等承诺，国内有关法律和管理制度相应调整，企业也面对更直接的国际竞争与合作。

结果与历史联系对外开放进入规则约束更强的新阶段，深刻影响产业、就业和国际经贸联系。

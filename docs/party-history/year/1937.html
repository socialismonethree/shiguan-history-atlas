全民族抗战与敌后根据地展开

卢沟桥事变使抗日战争全面爆发，第二次国共合作形成，红军和南方游击队分别改编为八路军、新四军。中共通过洛川会议确立全面抗战路线，在配合正面作战的同时向敌后展开，建立根据地与新型地方政权。

1月13日组织建设

中央机关迁驻延安

地点 / 范围：陕北延安

西安事变后中共中央机关迁到延安，城市及周边逐步形成中央政治、军事、干部教育和文化活动中心。延安的地位并非只来自地理位置，还依赖根据地政权、群众生产和对外交通联络等条件，随后经历战争封锁和物资困难。

结果与历史联系延安逐步形成中共中央的政治、军事、干部教育和文化工作中心。

5月党的会议

苏区与白区代表会议

地点 / 范围：延安

中共先后召开苏区和白区代表会议，讨论抗日新形势下的任务，总结根据地与地下工作的不同经验。统一战线、组织建设和群众工作成为共同议题。不同地区的环境差异，需要不同的策略，不能把一种工作方式机械套用全国。

结果与历史联系根据地与地下工作的经验得到总结，为全面抗战新任务调整组织策略。

7月7日—8日历史转折

卢沟桥事变与中共抗战通电

地点 / 范围：北平卢沟桥、延安

日军在卢沟桥挑起进攻，中国驻军抵抗。中共中央次日发表通电，呼吁全国抗战。事变引发战争全面扩大，国共谈判与地方救亡动员随之加速。1931年以来局部抵抗的历史没有因此被抹去，1937年的特点在于全民族全面抗战展开。

结果与历史联系局部抗战扩大为全国全面战争，救亡动员和国共谈判迅速推进。

7月—8月思想文献

《实践论》《矛盾论》形成

地点 / 范围：延安

毛泽东为哲学讲授整理有关认识与矛盾问题的论述，后来以《实践论》《矛盾论》收入文集。文章针对脱离实际的思想方法，讨论认识同实践、普遍性同特殊性的关系。作品的形成、后续修订与出版不能一概视为同一时间。

结果与历史联系认识论、辩证法同革命经验结合，形成后来具有深远影响的哲学文本。

8月22日—25日党的会议

洛川会议确定全面抗战路线

地点 / 范围：陕西洛川

中央政治局扩大会议讨论抗战方针，通过抗日救国十大纲领，主张发动群众、开展敌后游击战争并保持共产党独立作用。会议同时调整军事领导机构。其全面抗战主张不限于军队作战，也涉及政治、经济和社会动员。

结果与历史联系全面抗战路线与敌后战略得到确定，政治和社会动员纳入抗战安排。

8月25日军事活动

红军改编为八路军

地点 / 范围：陕北、山西抗日前线

中共中央军委宣布红军改编为国民革命军第八路军，设三个师，朱德任总指挥、彭德怀任副总指挥。部队随后东渡黄河赴华北抗战。名义上进入全国抗战军事序列，但党在部队中的领导与政治工作继续保持。

结果与历史联系红军进入全国抗战军事序列，保持党的领导并转赴华北前线。

9月22日—23日统一战线

第二次国共合作正式形成

地点 / 范围：南京、全国各地

国民党中央通讯社公布中共合作宣言，蒋介石次日发表实际上承认中共合法地位的谈话。双方长期谈判因全面战争而取得结果，抗日民族统一战线正式形成。合作是在存在政治分歧的条件下进行，并不意味着内外政策完全一致。

结果与历史联系共产党合法地位获实际承认，抗日民族统一战线正式形成。

9月25日军事活动

平型关战斗

地点 / 范围：山西灵丘平型关

八路军一一五师主力利用山地设伏，打击日军运输和后续部队，取得重要胜利。它配合华北正面防御作战，增强社会抗战信心。应把战斗置于整体平型关作战与全国抗战中，不能误写成单独消灭整个日军师团。

结果与历史联系打击日军并振奋抗战信心，为八路军开展华北作战扩大社会影响。

9月政策建设

陕甘宁边区政府改制

地点 / 范围：陕甘宁边区

原有苏维埃政府机构按统一战线新形势改称陕甘宁边区政府，随后调整行政与参政制度。改制旨在适应共同抗日，边区仍承担中共中央所在地与战略后方的功能。名称和政策改变同此前的土地、政权历史具有延续关系。

结果与历史联系根据地政府形式适应合作抗战，陕甘宁成为中央所在地与战略后方。

10月—11月军事活动

配合忻口作战与敌后袭击

地点 / 范围：山西雁门关、阳明堡等

八路军在雁门关、阳明堡等地袭击日军运输和机场，配合国民党军的忻口防御作战。战术袭击与主战场防御相互联系，显示敌后行动在破坏补给、牵制兵力上的作用。相关行动不能同正面会战割裂理解。

结果与历史联系袭击日军交通和机场，有力配合忻口等正面防御作战。

11月起军事活动

华北敌后根据地展开

地点 / 范围：晋察冀、晋西北、晋冀豫、山东等

八路军在各地党组织配合下向敌后分散展开，组织群众、发展游击力量并建立抗日根据地。不同地区有山地和平原等差异，政权与军队建设逐步适应当地条件。由此形成长期敌后抗战的区域性基础。

结果与历史联系多个敌后根据地建立，军事、地方组织和群众动员形成长期抗战基础。

12月25日军事活动

新四军军部成立

地点 / 范围：武汉，后迁南昌

南方多地红军游击队按合作协议改编为新四军，军部在武汉成立，叶挺任军长、项英任副军长，次年向华中敌后展开。其基础来自1934年后坚持南方游击战争的力量，琼崖游击队等并未纳入这次改编。

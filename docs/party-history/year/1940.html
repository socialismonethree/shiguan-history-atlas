1月思想文献

《新民主主义论》发表

地点 / 范围：延安

毛泽东系统讨论中国革命的社会性质、阶段任务以及政治、经济、文化安排，提出新民主主义理论。文章回应半殖民地半封建社会如何走向新的国家与社会制度的问题，也为此后关于联合政府和建国纲领的讨论提供理论基础。

结果与历史联系为中国革命阶段和未来国家制度提出系统构想，成为后续建国纲领的重要理论基础。

3月政策建设

抗日根据地政权的“三三制”原则

地点 / 范围：各抗日根据地

中共提出抗日民主政权人员组成的“三三制”原则，由共产党员、非党左派进步分子和中间派各占一定比例。其目的在保持党的领导的同时扩大抗日联合。具体执行受地方情况影响，比例原则不应被当作所有机构始终整齐不变。

结果与历史联系政权参与面扩大，党同非党进步人士、中间力量形成较制度化合作。

3月思想文献

提出统一战线策略原则

地点 / 范围：延安

中共中央总结抗战以来的合作与摩擦，强调发展进步力量、争取中间力量、孤立顽固力量，并要求斗争有理、有利、有节。策略针对不同社会政治力量区别对待，不是把所有非党力量都归为敌人，也不是对进攻无条件退让。

结果与历史联系统一战线中的联合与斗争得到策略区分，影响国统区、根据地与军事工作。

4月—7月政策建设

民族工作纲领讨论

地点 / 范围：延安、西北地区

中央西北工作委员会先后拟定回回民族和蒙古民族问题的工作提纲，经中央批准后用于指导抗战民族工作。文件讨论民族平等、团结抗日和具体地方政策，说明抗战动员必须面对不同民族的实际处境和历史关系。

结果与历史联系民族平等与联合抗日的具体政策获得指导文件，拓展不同民族的参与基础。

6月1日统一战线

陈嘉庚访问延安

地点 / 范围：延安

南洋华侨回国慰劳视察团到延安，陈嘉庚会见毛泽东等，考察边区和抗战情况。华侨通过募捐、物资、人员与舆论支持祖国抗战。访问既是社会人士了解不同抗战力量的过程，也是中共同海外爱国网络建立联系的机会。

结果与历史联系中共同海外华侨网络直接交流，增强侨界对敌后抗战的了解与支持。

8月20日—1941年1月下旬军事活动

百团大战

地点 / 范围：华北正太铁路等区域

八路军总部组织多支部队进攻日伪交通线、据点和封锁设施，随后进行反击报复“扫荡”等作战。行动规模大、持续时间长，打击敌方交通体系并振奋抗战信心，同时也伴随损失和其后军事压力的加重，应按阶段理解。

结果与历史联系打击日伪交通与据点，振奋抗战信心，也引发持续反“扫荡”和军事压力。

9月18日组织建设

加强敌后城市工作

地点 / 范围：重庆、延安及沦陷城市

中央书记处通知加强敌后大城市工作，设立相关工作协调机构，由周恩来负总责。军事力量主要在乡村活动，不等于城市工人、文化、情报和社会联络工作消失。公开职业和秘密组织相结合，是沦陷区工作的重要条件。

结果与历史联系城市地下组织、情报与社会联络受到重视，与农村根据地工作形成互补。

11月17日军事活动

华中八路军新四军总指挥部成立

地点 / 范围：江苏海安

华中地区建立新四军、八路军联合总指挥机构，协调两军在当地的行动，刘少奇承担政治领导，陈毅在叶挺到任前代理指挥。此前不同来源部队向华中发展，统一协调成为建立和巩固抗日根据地的实际需要。

结果与历史联系加强华中八路军和新四军的行动协调，为敌后区域整合提供指挥框架。

1月27日外交

中法建立外交关系

地点 / 范围：北京、巴黎

中国与法国宣布建立外交关系，法国成为第一个与新中国正式建立外交关系的西方大国。建交突破当时西方阵营对华关系的既有格局，也为中国同更多国家发展关系提供新的条件。

结果与历史联系中法建交扩大新中国外交空间，体现不同制度国家之间建立正式关系的可能。

2月5日经济建设

工业学大庆运动展开

地点 / 范围：全国

中央转发石油工业部关于大庆会战的报告，推动各地学习大庆的生产组织和作风。大庆建设中，地质、钻井和运输等系统协作，王进喜等工人的劳动实践成为全国工业宣传的重要内容。

结果与历史联系大庆既是能源基地，也成为企业组织与劳动模范教育的重要示范。

2月10日经济建设

农业学大寨运动展开

地点 / 范围：山西昔阳及全国

报刊集中介绍大寨大队整治土地、发展生产的经验，农业学大寨运动随后扩展。学习活动带动一些地方兴修农田水利，但后来又与政治化评比和不顾地方条件的模式推广相结合。

结果与历史联系农业典型有动员作用，但把单一模式强加各地会忽视自然条件和农民实际需要。

5月15日—6月17日经济建设

中央讨论三线建设

地点 / 范围：北京及中西部地区

中央工作会议讨论在内地布局工业和国防生产，考虑外部战争风险，提出把部分重点工业项目和交通设施放到较安全的中西部地区。1965年起，三线建设进入较大规模实施阶段。

结果与历史联系这一战略促进内地工业和基础设施发展，也带来选址偏远、成本和后续调整等长期问题。

10月16日科技教育

第一颗原子弹试验成功

地点 / 范围：新疆罗布泊

中国首颗原子弹爆炸试验成功，核武器研制实现关键突破。核物理理论、装置设计、材料、试验与保障队伍长期协作完成任务，中国政府同时宣布在任何时候和情况下不首先使用核武器。

结果与历史联系核试验增强国家战略威慑和安全能力，也标志中国在尖端科技方面取得重大突破。

12月20日—翌年1月5日法治制度

四届全国政协一次会议

地点 / 范围：北京

全国政协举行新一届会议，选举周恩来为主席，并继续推举毛泽东为名誉主席。政协作为统一战线组织，吸纳各民主党派、团体与不同界别人士，参与国家政治生活和协商工作。

结果与历史联系会议显示人民政协制度在国家建设阶段的持续运行，与全国人大职能相互区别。

12月21日—翌年1月4日经济建设

四个现代化目标系统提出

地点 / 范围：北京

三届全国人大一次会议上，周恩来的政府工作报告提出实现农业、工业、国防和科学技术现代化的目标。会议选举刘少奇继续任国家主席、朱德任全国人大常委会委员长，决定周恩来任国务院总理。

结果与历史联系四个现代化成为此后国家建设的长期目标，1975年和1978年又被重新强调。

城市经济改革与沿海开放扩展

对外开放从特区扩展到十四个沿海港口城市，十二届三中全会把城市经济体制改革推向前台。乡镇企业发展、中英香港问题联合声明与民族区域自治法，构成这一年的其他重要节点。

1月22日—2月17日改革开放

邓小平考察经济特区

地点 / 范围：深圳、珠海、厦门、上海

邓小平考察三个经济特区和上海，肯定试办特区与开放决策。高层考察既总结局部探索的成效，也为继续扩大开放提供政治支持，随后沿海开放城市政策出台。高层对特区试验的肯定有助于稳定开放预期，同年中央决定开放沿海港口城市，使特区经验与更广地域政策衔接。

结果与历史联系对外开放从少数试验点逐步扩展为沿海城市群的政策布局。

3月1日改革开放

社队企业改称乡镇企业

地点 / 范围：全国农村

中央转发有关报告，同意将社队企业改称乡镇企业并提出发展政策。名称变化对应农村工业和经营主体的发展，农民就业与地方经济开始出现农业之外的增长渠道。中央提出配套发展政策，乡镇企业逐渐成为吸纳农村劳动力、增加地方收入的重要经营形式，改变只把农村看作农业生产空间的认识。

结果与历史联系农村经济结构与就业渠道拓展，推动城乡之间的产业和人口联系。

4月8日科技文化

东方红二号通信卫星发射成功

地点 / 范围：中国

中国成功发射试验通信卫星东方红二号，推进卫星通信技术应用。空间技术逐步与广播、通信等需求连接，体现航天能力从试验向更广泛应用发展的过程。

结果与历史联系通信基础设施的进步，是现代化建设与信息交流扩大的物质条件。

5月4日改革开放

开放十四个沿海港口城市

地点 / 范围：天津、上海等十四城

中央批准进一步开放十四个沿海港口城市，并提出逐步兴办经济技术开发区。开放布局由少数经济特区向较长的海岸线延伸，地方开始承担吸收外资和发展外向型经济的新任务。新开放城市包括天津、上海、大连、青岛、宁波、广州等，兼具港口和产业基础，开发区则用于集中探索投资和经营条件。

结果与历史联系沿海开放形成更长的产业与港口联系带，为后续区域开放奠定基础。

5月31日法治制度

民族区域自治法通过

地点 / 范围：北京

六届全国人大二次会议通过民族区域自治法，以法律形式规定民族自治地方的有关制度。制度法律化与国家治理体系恢复建设相联系，后来修法应按其实际时间另作说明。

结果与历史联系从政策到法律的制度化，是民族工作的重要一环。

10月20日改革开放

十二届三中全会推进城市改革

地点 / 范围：北京

全会通过经济体制改革决定，把城市改革作为重点，提出公有制基础上的有计划商品经济。企业管理、价格和国家调控等问题由局部试验转向更系统的制度讨论。决定说明改革以增强企业活力为中心环节，企业经营、国家管理和商品交换之间的关系因此需要整体调整。

结果与历史联系城市经济改革由单项放权走向较系统的制度设计，成为八十年代中期改革重点。

12月3日党的建设

禁止党政机关和干部经商办企业

地点 / 范围：全国

中央针对机关和干部直接经商办企业的问题作出禁止性决定。经济活动扩展后，公权力与经营利益的边界成为新的治理难题，党风廉政建设需要回应改革中的新现象。

结果与历史联系防止权力与经营利益混同，是改革时期纪律建设的具体课题。

12月19日对外关系

中英香港问题联合声明签署

地点 / 范围：北京

中英两国政府签署关于香港问题的联合声明，明确中国于1997年7月1日恢复对香港行使主权。谈判形成的安排为后续基本法制定和政权交接提供框架。联合声明经过前期多轮谈判形成，中国同时说明恢复主权后实施的基本政策，后续香港基本法把相关安排进一步法律化。

结果与历史联系香港过渡有了明确时间和政策框架，主权交接准备由此持续推进。

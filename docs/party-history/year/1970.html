1月31日—2月5日历史曲折

一打三反运动展开

地点 / 范围：全国

中央先后部署打击所谓反革命活动及反贪污、反投机倒把、反铺张浪费等工作。运动中许多一般问题被上升为政治案件，缺乏正常证据和程序保障，再次造成大量冤假错案。

结果与历史联系政治运动式治理继续侵害群众与干部权利，加深对正常社会秩序的破坏。

3月27日历史曲折

清查五一六严重扩大化

地点 / 范围：全国

中央发出清查所谓五一六集团的通知，原本针对个别组织的问题被扩大为全国性清查。派性力量利用政治指控打击不同意见者，大量干部与群众遭受审查和迫害，许多案件后来被否定。

结果与历史联系清查进一步把社会分歧政治化，造成广泛人身伤害和组织内耗。

4月24日科技教育

东方红一号发射成功

地点 / 范围：中国酒泉卫星发射中心

中国第一颗人造地球卫星进入预定轨道，运载火箭、卫星系统和测控协作取得成功。任务建立在此前国防科技和工业能力积累上，使中国具备独立发射卫星的能力。

结果与历史联系这一成果拓展航天技术基础，为通信、遥感和后来的空间工程培养队伍与经验。

6月27日科技教育

高校试招工农兵学员

地点 / 范围：北京及全国高校

中央批准北京大学、清华大学招生试点报告，高等学校开始恢复招生，但采用群众推荐、领导批准和学校复审等办法，取消文化考试，教学又受到政治运动强烈干预。

结果与历史联系招生部分恢复并未消除文革对教育的破坏，人才选拔和教学质量问题持续存在。

8月23日—9月6日历史曲折

九届二中全会与庐山争论

地点 / 范围：江西庐山

九届二中全会围绕国家主席设置、个人崇拜和领导权等问题发生尖锐斗争。毛泽东批评陈伯达，林彪集团同毛泽东之间矛盾进一步公开化，但会议并未从根本上纠正文革路线。

结果与历史联系中央领导层内部斗争加剧，为1971年林彪事件埋下直接政治背景。

8月25日—10月5日经济建设

北方农业会议重申部分农村政策

地点 / 范围：北京及北方地区

国务院讨论农业生产，在继续宣传政治运动的同时，重新强调农业六十条等部分经营政策，要求恢复生产秩序、改善管理。相关措施针对文革初期对农村生产与分配造成的混乱。

结果与历史联系恢复合理生产安排有助于农业回升，表明经济运行需要稳定规则而非不断斗争。

12月18日外交

毛泽东向斯诺谈中美接触

地点 / 范围：北京

毛泽东会见美国记者斯诺，表示可以同尼克松谈话。双方尚无正式外交关系，公开传递接触意愿有助于试探对方态度，为随后体育交往、秘密会谈和总统访问创造条件。

12月25日经济建设

葛洲坝工程获准兴建

地点 / 范围：湖北宜昌

中央批准建设长江葛洲坝水利枢纽，工程涉及发电、航运和河道控制等目标。大型水电建设需要进行长期设计论证与施工，后来不断修订方案，直到1988年全部建成。

结果与历史联系葛洲坝积累大型水电工程技术和组织经验，并为区域能源与航运提供支撑。

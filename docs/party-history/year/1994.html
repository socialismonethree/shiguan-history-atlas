1月11日改革开放

深化外贸体制改革

地点 / 范围：全国

国务院部署进一步深化外贸体制改革，调整经营机制和政策安排，推动外贸活动与国际经济惯例衔接。对外贸易管理逐步从行政包办转向更强调经营责任和竞争。政策要求放开经营、平等竞争和自负盈亏，同时保留统一政策与管理规范，使外贸企业在更明确责任下参与国际市场。

结果与历史联系外贸经营机制更加接近市场经济和国际交易规则，企业自主经营空间扩大。

2月28日—3月3日经济社会

部署八七扶贫攻坚

地点 / 范围：北京、贫困地区

全国扶贫开发工作会议部署八七扶贫攻坚计划，目标是在世纪末前七年内基本解决约八千万贫困人口温饱问题。扶贫工作形成明确期限与对象范围。计划以当时国家贫困标准为依据，把有限时间、重点地区与对象结合，扶贫开发因此形成集中攻坚的工作方式和资源安排。

结果与历史联系农村减贫进入目标更明确的政策阶段，为后来十年扶贫纲要积累经验。

3月19日统一战线

政协主要职能进一步明确

地点 / 范围：北京

全国政协八届二次会议修改政协章程，把政治协商、民主监督和参政议政并列为主要职能。政协工作在制度文本中获得更清晰的功能说明。

结果与历史联系三项职能各有含义，不能与国家行政决策职权混同。

3月22日法治制度

预算法通过

地点 / 范围：北京

八届全国人大二次会议通过预算法，为预算编制、审查和执行提供法律依据。财政制度调整与预算法律建设相配合，公共收支管理逐步制度化。在分税制开始实施的背景下，预算法律制度进一步明确公共收支的组织和监督，使财政关系调整有相应程序规范。

结果与历史联系财政改革不仅改变收入分配，也促进预算管理法治化。

3月25日经济社会

提出可持续发展战略

地点 / 范围：全国

国务院常务会议通过中国二十一世纪议程，确定实施可持续发展战略。人口、资源、环境与发展之间的关系进入综合政策框架。议程把人口和资源条件纳入发展安排，强调发展不能脱离环境承载能力，为后来绿色和生态政策提供较早的战略背景。

结果与历史联系可持续发展逐渐进入国家规划、产业和资源环境治理。

7月5日法治制度

劳动法通过

地点 / 范围：北京

全国人大常委会通过劳动法，对劳动关系和劳动者权益提供基本法律规范。企业改革与就业方式变化，需要通过法律明确劳动合同、工作条件和社会保障等问题。法律适应劳动用工方式变化，对劳动关系与权益作基础规范，为后来劳动合同、就业促进和社会保险等专门制度发展奠基。

结果与历史联系劳动者基本权益和企业用工责任有了更加完整的基本法律框架。

7月20日—23日经济社会

第三次西藏工作座谈会

地点 / 范围：北京

中央召开第三次西藏工作座谈会，部署中央与全国各地支持西藏建设。地区发展通过中央决策、地方对口支持等形式协调推进。

结果与历史联系区域政策要结合基础条件差异和具体援助机制观察。

9月25日—28日党的建设

十四届四中全会讨论党的建设

地点 / 范围：北京

全会通过加强党的建设若干重大问题的决定，提出推进党的建设新的伟大工程。市场经济发展带来的组织、干部和纪律问题成为党内制度建设的背景。决定把思想政治建设、组织建设与干部队伍等联系起来，试图回应改革开放和市场经济条件下执政党面临的新问题。

结果与历史联系党的建设被作为长期工程部署，与经济社会转型同步推进。

农村发展与冒险方针的冲突

红军集中为军团和方面军，根据地相互连接，中央苏区取得反“围剿”胜利。与此同时，李立三等推动进攻中心城市的计划造成损失。调查研究、左翼文化运动和党内纠错共同构成这一年的多重面貌。

1月5日思想文献

《星星之火，可以燎原》

地点 / 范围：闽西

毛泽东在给林彪的信中讨论农村红军和根据地发展的前景，回应对革命形势的悲观判断。文章强调在农村艰苦积累力量，并把地方红色政权同全国革命变化联系起来。其标题为后来编选时采用，阅读时应关注原信的现实问题。

结果与历史联系回应党内悲观判断，把农村根据地积累同全国革命前景联系起来。

3月思想文献

左翼作家联盟成立

地点 / 范围：上海

在中共推动下，左翼作家联盟于上海成立，鲁迅等参与活动，随后更多左翼文化团体形成。文学、戏剧、电影与社会科学传播进入新的组织阶段，同时遭受国民党当局的文化压制。政治斗争因而具有文化生产和大众传播的一面。

结果与历史联系左翼文化团体扩大，文学、戏剧和电影等成为政治与社会动员的重要领域。

4月—6月军事活动

鄂豫皖根据地逐渐统一

地点 / 范围：鄂豫皖边区

鄂东、豫东南、皖西的革命力量加强联合，建立边区党组织并整编红军，随后形成区域苏维埃政权。此前分散的起义和游击队，逐渐成为跨省边界的军事、政治网络。整合过程也受到交通、地形与地方社会条件影响。

结果与历史联系鄂东、豫东南、皖西力量逐步联合，跨省根据地和统一军事组织成长。

5月思想文献

寻乌调查与反对本本主义

地点 / 范围：江西寻乌

毛泽东在寻乌调查城乡商业、土地和阶级关系，并撰写《调查工作》，后以《反对本本主义》为题发表。其论述反对脱离实际照搬条文，强调了解中国具体情况。调查并非只服务于写作，也直接关系土地与经济政策的制定。

结果与历史联系实地调查为土地经济政策提供依据，推动反对脱离实际的思想方法。

6月11日历史教训

李立三冒险方针形成

地点 / 范围：上海

中央政治局通过关于革命高潮的决议，过高估计全国形势，继而部署全国暴动和集中红军进攻中心城市。实际行动使革命力量受到损失。农村根据地已发展的事实，并不能证明短期内夺取全国中心城市的条件已经具备。

结果与历史联系全国暴动和进攻中心城市的计划造成损失，暴露对革命形势的严重误判。

6月—7月军事活动

红军军团相继组成

地点 / 范围：江西、福建、湖北等

红一、红三军团于6月组成，红二军团于7月组成。各地部队由军、师等单位向军团集中，适应更大范围的作战需要。不同军团有各自的起义来源和根据地，后来的番号沿革还经历多次变化，不能把同名部队视为始终不变。

结果与历史联系红军向军团集中，适应更大范围作战，并推动政治和后勤工作整合。

8月23日军事活动

红一方面军成立

地点 / 范围：湖南浏阳

红一、红三军团会合后组成红一方面军，朱德任总司令，毛泽东任总前委书记兼总政治委员。部队集中提升了在中央根据地周边进行运动战的能力，也使指挥、政治工作与后勤供给需要更明确的分工与协调。

结果与历史联系中央苏区的主要作战力量形成，为随后反“围剿”建立军事组织基础。

9月24日—28日党的会议

六届三中全会停止冒险行动

地点 / 范围：上海

中共中央全会批评李立三等对形势的错误估计，停止组织全国总暴动和集中红军进攻中心城市的计划。此前部分纠正已开始，会议使调整更为明确。但对错误的根源、对农村道路的认识仍存在分歧，党内路线斗争没有随即结束。

结果与历史联系停止李立三等的冒险行动，中央开始调整军事和群众工作方针。

12月—1931年1月军事活动

中央苏区第一次反“围剿”

地点 / 范围：江西龙冈、东韶等

国民党军向中央苏区进攻，红一方面军采取诱敌深入和集中兵力打击的办法，在龙冈、东韶等地作战，取得第一次反“围剿”胜利。根据地军民的支援使红军得以发挥熟悉地形和机动作战的优势，巩固了中央苏区的生存空间。

结果与历史联系保存并巩固中央苏区，积累以机动与群众支援克服敌方优势的作战经验。

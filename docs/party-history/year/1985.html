1月1日改革开放

改革农产品统购派购制度

地点 / 范围：全国农村

中共中央、国务院推出活跃农村经济的政策，决定从当年起改革农产品统购派购，实行合同定购与市场收购。农村改革由生产责任制进一步触及流通和购销关系。购销改革与家庭承包经营相接，试图使农户生产决策更多与需求、价格和交易联系起来，而不只服从原有统购任务。

结果与历史联系农业改革从生产组织延伸至流通领域，农村市场联系进一步扩大。

1月21日科技文化

确立教师节

地点 / 范围：北京

全国人大常委会决定将9月10日设为教师节。国家通过纪念制度突出教师和教育的重要地位，与当时推进教育体制改革、重视人才培养的政策环境相呼应。

结果与历史联系教育工作者的社会地位也是现代化人才政策的组成部分。

2月18日改革开放

开辟沿海经济开放区

地点 / 范围：长三角、珠三角、闽南三角地区

中央决定在长江三角洲、珠江三角洲和闽南三角地区开辟沿海经济开放区。开放由点状城市进一步扩展为区域性布局，使产业、城镇和对外贸易联系更加紧密。三个区域都已有一定城市和工农业基础，中央以区域范围推进开放，使原先开放城市与周边生产网络相互衔接。

结果与历史联系开放开始呈现从点到面的扩展，区域产业分工和外贸联系增强。

2月20日科技文化

南极长城站建成

地点 / 范围：南极乔治王岛

中国第一个南极考察站长城站建成，为持续开展极地观测与科学考察提供基地。考察站建设需要运输、通信、补给和多学科科研合作，不能仅看作一座建筑落成。

结果与历史联系中国科学研究活动的空间范围进一步拓展。

3月13日科技文化

科技体制改革决定出台

地点 / 范围：全国

中共中央部署科学技术体制改革，强调科技工作与经济建设的联系。改革试图改进科研管理和成果应用机制，使技术发展不只停留在科研机构内部。文件以科研同经济发展结合为方向，回应科研成果与生产应用之间的分隔，技术市场和科研组织运行也成为改革议题。

结果与历史联系科研体制调整与企业技术进步联系起来，促进知识成果向实际生产转化。

5月23日—6月6日国防军事

宣布裁军一百万

地点 / 范围：北京

中央军委扩大会议重新判断国际形势与战争风险，邓小平宣布军队减少员额一百万。军队建设指导思想随之调整，把组织结构和现代化建设放在新的战略环境下安排。会议对国际局势的判断变化，使军队建设不再主要围绕大规模战争随时爆发安排，组织精简与质量建设由此相互配合。

结果与历史联系军队转向更加重视质量和现代化，国家建设与国防资源配置随之调整。

5月27日科技文化

教育体制改革部署

地点 / 范围：全国

中共中央发布教育体制改革决定，提出分步骤推行九年义务教育，发展职业教育，并调整高校招生与毕业分配等制度。教育领域改革开始更系统地回应经济和人才需求。决定还要求扩大学校办学自主权、发展职业教育，并改变高等学校招生计划与毕业分配中不适应新形势的安排。

结果与历史联系教育管理与培养结构发生调整，为经济和社会转型准备人才条件。

全国代表会议与领导机构调整

地点 / 范围：北京

党的全国代表会议调整中央委员会等机构成员，随后十二届五中全会继续调整中央政治局和书记处成员。这些安排推进中央领导机构新老交替。

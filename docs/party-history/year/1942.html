整风、文艺与根据地生存

1月1日国际联系

《联合国家宣言》签署

地点 / 范围：华盛顿、中国各战场

中国、美国、英国、苏联等26国签署共同反对轴心国的宣言，国际反法西斯联合进一步制度化。中国抗战成为这一全球战争的重要组成。中共据此继续推动团结抗日与国际联络，中国战场的民族解放斗争与世界反法西斯战争更加紧密相连。

结果与历史联系国际合作格局扩大，为中国抗战争取国际支持创造条件。

1月28日、2月4日政策建设

明确抗战土地政策

地点 / 范围：各抗日根据地

中共中央发布土地政策决定及执行指示，要求减租减息，改善农民生活，同时在减租后交租交息、保障地主相应权益。政策体现抗战统一战线条件下的调整，与土地革命时期没收分配土地的办法不同。

结果与历史联系兼顾动员农民与联合抗日力量，成为根据地社会政策的重要基础。

2月1日、8日思想文献

延安整风全面展开

地点 / 范围：延安及各党组织

毛泽东先后讲授整顿作风和反对党八股，集中批评主观主义、宗派主义和空洞文风，整风随后在全党展开。学习文件、研究历史和检查工作成为主要方式。运动促进思想统一，也在后来审干中出现需要纠正的扩大化问题。

结果与历史联系加强理论、组织与工作作风建设，为七大前形成共同认识提供基础。

5月思想文献

延安文艺座谈会

地点 / 范围：延安杨家岭

中共中央召集文艺工作者讨论文艺与革命工作的关系，毛泽东讲话提出面向工农兵、深入群众生活等要求。会议影响此后文学、戏剧、音乐和美术创作的方向，也改变知识分子同根据地社会的互动方式。

结果与历史联系推动文艺与群众生活、战时动员更紧密结合，对后来文艺政策影响深远。

5月—6月军事活动

冀中反“扫荡”

地点 / 范围：河北冀中平原

日伪军对冀中进行大规模进攻和封锁，制造屠杀并破坏村庄、生产和交通。军民通过分散转移、游击作战、地道和地下组织坚持，付出重大牺牲。平原根据地受到严重压缩，恢复组织与民众生活成为随后的长期任务。

结果与历史联系说明敌后战争最困难时期的社会代价，不只记录作战次数和战果。

5月13日军事活动

陕甘宁晋绥联防军成立

地点 / 范围：陕甘宁、晋绥地区

中共中央军委建立联防军司令部，协调陕甘宁与晋绥地区的防务，贺龙任司令员，徐向前任副司令员兼参谋长。跨区域协调需要处理河防、交通、后勤和不同部队配合，服务于保卫中央所在地与坚持敌后抗战。

结果与历史联系增强两区军事联动，在根据地受到封锁进攻时巩固战略后方。

8月国际联系

日本人反战团体联合

地点 / 范围：延安及华北根据地

在华日本反战人员举行代表会议，将有关组织整合为华北联合机构，反对日本侵略战争并开展对日军宣传。反战工作常与战俘教育、翻译和政治联络结合。日本军国主义同反对侵略的日本人，应在历史叙述中明确区分。

结果与历史联系形成对敌政治工作的一部分，也体现跨国反战合作。

9月1日组织建设

统一根据地党政军领导

地点 / 范围：延安及各抗日根据地

中央政治局决定统一抗日根据地领导、调整各组织关系，规定党委在区域党政军民工作中的领导地位，并要求防止包办政府和群众组织事务。政策回应军事、行政与社会组织间协调不畅的问题，其执行也需处理集中与具体分工。

结果与历史联系加强根据地统筹能力，形成后来地方党政军关系的重要制度经验。

12月政策建设

提出发展经济、保障供给

地点 / 范围：延安

毛泽东在边区干部会议的经济财政报告中，把发展生产作为保障军政供给的基础，批评只从财政征收上寻找出路。生产、财政和民众负担被放在一起考虑，军队机关自给与帮助群众生产由此成为克服困难的重要办法。

结果与历史联系推动大生产与财政政策结合，减少单纯向民众增加征收的压力。

1月8日—10日党的建设

十届二中全会调整领导机构

地点 / 范围：北京

中央全会讨论四届全国人大筹备工作，选举邓小平为中共中央副主席和政治局常委。此前他已被任命为军委副主席兼总参谋长，党政军岗位的恢复使其能参与更广泛的整顿工作。

结果与历史联系领导分工变化为1975年集中推动正常工作恢复提供组织条件。

1月13日—17日法治制度

四届全国人大一次会议

地点 / 范围：北京

会议选举朱德为全国人大常委会委员长，任命周恩来为国务院总理、邓小平等为副总理，政府工作报告重申四个现代化目标。同时，1975年宪法仍带有文革错误影响，国家制度尚未恢复正常。

结果与历史联系会议延续国家机关形式并明确建设目标，但不能把它理解为文革错误已经纠正。

2月起经济建设

邓小平推动全面整顿

地点 / 范围：全国

邓小平主持国务院日常工作，随后又主持中央日常工作，把恢复秩序、加强纪律和搞好生产相联系。整顿从铁路等关键部门展开，逐步涉及工业、军队、科研教育和地方领导班子。

结果与历史联系整顿改善部分经济指标和管理状况，为后来拨乱反正积累政策与干部实践经验。

2月25日—3月8日经济建设

铁路运输整顿

地点 / 范围：全国铁路系统

中央召集有关负责人研究铁路运输，针对派性、纪律松弛和调度不畅提出整顿措施。铁路是煤炭、钢铁、粮食等运输的关键，恢复运输秩序使企业停产和物资积压等问题得到缓解。

结果与历史联系以铁路为突破口带动经济运行好转，显示全国生产体系需要统一管理和正常责任制。

3月17日法治制度

全部在押战犯获特赦

地点 / 范围：全国

全国人大常委会根据建议决定特赦释放全部在押战争罪犯并给予公民权，最高人民法院执行。自1959年以来的分批特赦由此完成，一些人员随后参与社会和统一战线活动。

结果与历史联系特赦体现对原对立人员的政策转化，为扩大团结和推动统一事业创造条件。

4月4日历史曲折

张志新被杀害

地点 / 范围：辽宁

辽宁省委宣传部干部张志新因反对文革错误和揭露林彪、江青等问题，被长期关押并被杀害。她坚持对党和国家重大问题表达意见，却失去法律与组织保护，1979年才获平反。

结果与历史联系这一冤案成为文革践踏言论、人格和生命权利的典型，警示必须坚持法治与制度保障。

6月24日—7月15日军事国防

军委扩大会议整顿军队

地点 / 范围：北京

中央军委讨论压缩定额、调整编制与整顿作风，要求减少肿、散、骄、奢、惰等问题，恢复训练和正常管理。会议针对文革和林彪影响造成的损害，提出恢复军队建设秩序的具体任务。

结果与历史联系军队整顿为减少派性和提高建设质量作准备，但随后同其他整顿一样受到政治干扰。

9月26日科技教育

科学院汇报推动科研整顿

地点 / 范围：北京

邓小平听取有关科学院工作的汇报，肯定科技队伍总体情况，强调科学技术对生产发展的作用，支持改善研究条件、引进先进技术和开展理论研究。有关提纲试图恢复专业工作应有地位。

结果与历史联系科研整顿为1977年后的科学教育恢复提供重要政策思路和组织经验。

11月起历史曲折

批邓反击右倾翻案风

地点 / 范围：全国

对文化大革命不满和要求纠正错误，被毛泽东错误地视为翻案。整顿遭批判，邓小平被迫停止主持工作，江青等利用运动攻击正常建设和干部政策，已经取得的恢复成果受到冲击。

结果与历史联系纠正文革错误的尝试再遭中断，加深社会对结束混乱、恢复正常秩序的期待。

11月26日科技教育

返回式卫星发射并回收

地点 / 范围：中国有关发射与回收地区

中国发射返回式遥感卫星，按预定方案运行后成功回到地面，掌握卫星回收技术。发射、轨道控制、姿态稳定与返回着陆相互衔接，构成比一般卫星入轨更复杂的工程系统。

结果与历史联系返回技术拓展遥感和空间试验能力，中国航天进入新的技术阶段。

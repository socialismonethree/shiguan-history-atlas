1946

从政治协商走向全面内战

年初停战与政协会议一度提供和平建国机会，军队整编谈判却难以落实。6月全面内战爆发，中共组织战略防御，同时推进土地政策转变；苏中作战、国统区抗议运动和国际宣传共同影响战争初期局势。

1月5日—10日统一战线

停战协定与停战令

地点 / 范围：重庆、各军事地区

国共代表在美国调处下达成停止军事冲突协定，双方于10日下达停战令，并建立军事调处安排。协议给和平解决争端带来希望，但东北等地仍不断发生冲突。文字上的停战与实际军事态势之间，始终存在明显落差。

结果与历史联系为政协会议创造谈判环境，也暴露和平安排执行中的脆弱性。

1月10日—31日统一战线

政治协商会议

地点 / 范围：重庆

国民党、共产党、民盟、青年党和无党派代表召开政协会议，就政府组织、国民大会、宪法草案、军事问题与和平建国纲领达成协议。不同政治力量尝试以协商安排战后国家制度，但协议后来未能得到有效落实。

结果与历史联系展示战后和平民主建国的制度探索，是全年由谈判走向内战的重要起点。

2月统一战线

军队整编谈判

地点 / 范围：重庆

国共在调处机制下讨论军队整编和统编，试图把军事力量问题纳入和平建国安排。协议涉及部队数量、编制与指挥，直接触及双方政治安全。由于互信不足和战场竞争持续，军事协商未能阻止后来全面战争爆发。

结果与历史联系军队问题是和平谈判的核心障碍之一，不能只看一般性和平宣言。

4月8日人物事迹

四八空难

地点 / 范围：山西兴县黑茶山

王若飞、秦邦宪、叶挺、邓发等由重庆返回延安途中，所乘飞机在黑茶山失事，机上人员遇难。事故使中共失去多位负责谈判、组织和军事工作的干部。叶挺刚结束长期囚禁不久，其经历又同皖南事变和战后谈判相连。

结果与历史联系对党的人才和政治工作造成损失，也成为战后人物史的重要交汇点。

5月4日政策建设

五四土地指示

地点 / 范围：延安、各解放区

中共中央发布土地问题指示，支持把抗战时期减租减息逐步转向实现耕者有其田。各解放区据此开展土地改革，农民生产和政治地位发生变化。政策转变回应战后农村要求，也为战争动员提供更广泛的群众基础。

结果与历史联系标志土地政策由抗战联合条件下的调整走向更深层的土地制度改变。

6月26日历史转折

全面内战爆发

地点 / 范围：中原解放区及全国多地

国民党军大举进攻中原解放区，停战和政协安排遭破坏，全面内战爆发。中原部队随后突围，其他解放区进入抵御进攻的战争阶段。战后关于和平、民主与统一的协商道路在军事冲突扩大中严重受挫。

结果与历史联系中国政治重心由协商再次转向全国性战争，军事与社会动员全面升级。

7月20日军事活动

中央部署自卫战争

地点 / 范围：延安、各解放区

中共中央发出以自卫战争粉碎进攻的指示，分析敌我力量并部署军事与群众工作。此时解放军在兵力装备上总体较弱，需要通过运动作战、集中兵力与地方支援改变局势。土地改革、生产和军队组织成为战争能力的共同条件。

结果与历史联系为解放战争初期的战略防御和各战区行动确定基本方向。

7月—8月军事活动

苏中战役

地点 / 范围：江苏苏中

华中部队在苏中以灵活机动作战连续打击国民党军，取得重要胜利。部队利用内线交通与群众支援，在多次局部作战中集中兵力。战役为解放战争初期在兵力劣势下进行运动战积累经验，不宜只概括为一次单独战斗。

结果与历史联系增强华东地区防御和指挥经验，影响后来战役组织的发展。

8月6日思想文献

毛泽东同斯特朗谈话

地点 / 范围：延安

毛泽东接受美国记者采访，讨论国内战争、美国政策与人民力量，提出关于反动派的著名比喻。谈话发生在全面内战初起、力量对比悬殊之时，既有对国际局势的判断，也服务于增强党内和军民对长期斗争的信心。

结果与历史联系成为理解解放战争初期政治动员和战略判断的重要文本。

12月30日起工农运动

抗议美军暴行运动

地点 / 范围：北平及全国多城

北平学生为抗议驻华美军强暴中国女学生而举行游行，各地随后响应，诉求同反对内战、争取民族尊严和民主权利相联系。中共地下组织参与动员，学生是主要行动者。运动扩展显示国统区社会不满日益加深。

结果与历史联系为1947年更大规模的爱国民主运动提供组织和舆论基础。

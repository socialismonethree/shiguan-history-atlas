# 党史人物生平纪年：资料与维护

本栏目以可核实的人物年谱书目为线索，依据公开年表、文献及研究资料撰写纪事选编。原中央文献研究室和后来的中共中央党史和文献研究院的机构与书目应按具体版本分别标明。书目介绍不等于已查阅或逐条核对年谱全文；本栏目不是原著全文，也不能证明穷尽全部人物或活动。

## 来源与事实

各数据文件记录资料名称、机构、URL和每条具体定位。已公开书目可从各人物资料页查看。记录来源之间的日期差异，不推定未经证实的月日；涉及严重历史曲折时标注背景和可查来源。`source/access-check.json`记录本次网络访问检查结果：无法通过检查的来源暂不提供跳转，但保留名称和定位；网络状态可能随时间变化，维护时应重新核验，并优先寻找内容确实对应的可访问替代。不要把仅能证明书籍存在的目录当作具体事件证据。

## 维护流程

- 修改 `source/{zhu,zhou,deng,liu,chen,ren,xi}.json` 的人物、年度与来源；扩充人物时在 `tools/sync-leader-chronologies.mjs` 的人物清单和书目链接中登记。
- 核验新增来源，更新 `source/access-check.json`；不要关闭证书验证或为了替换而引用不支持该条的资料。
- 从仓库根目录执行 `node tools/sync-leader-chronologies.mjs`，再执行 `node tools/check-leader-chronologies.mjs`。它会检查年度连续、出处ID、本地链接、党史关联及相邻年份导航。
- 如果修改党史首页或毛泽东页的入口模板，还须执行对应的同步与检查脚本，并一起提交生成页面。

# 毛泽东生平纪年：资料与维护

本栏目按1893—1976年设置84个独立页面，以可核查的公开年表、年谱选载、文献和研究文章编写简明纪事，并提供具体出处与定位。中央文献研究室编《毛泽东年谱》及中共中央党史和文献研究院编2023年修订本为书目与编年参考；书目介绍不等于已经逐条查阅全书。此处是目前收集的纪事选编，并不宣称覆盖完整年谱。

现有391条个人纪事覆盖68个有确年记录的年份；16个年份没有已整理、能够确切归年的个人纪事，保留待补提示。1902—1909年的私塾教育为有出处的跨年背景，不推断各年具体校次。原党史中的关联条目单独呈现，不计入个人纪事。对于记载冲突、重大曲折及不确定的日期，应保留说明和对应证据。

## 维护

- `source/early.json`、`source/middle.json`、`source/late.json`：分期资料、年度概览、个人纪事与来源。
- `node tools/sync-mao-chronology.mjs`：从仓库根目录运行，生成逐年HTML、检索数据、参考资料页及清单。
- `node tools/check-mao-chronology.mjs`：检查年度覆盖、内部链接、来源和关键日期。
- 补充内容时保留来源名称、可访问链接和具体定位；仅能确定年份的记载不推定月日。核查年谱正文或其他可靠文献后再增加条目，并说明版本差异。

# 中共党史逐年知识库（0.10.0）

范围1921—2021，101个年度均生成独立静态页面 `year/<年份>.html`，可直接访问和分享。入口是 `index.html`；`people.html`提供人物介绍及相关史事，`references.html`登记依据。独立正红色视觉，不修改夏至清各朝代配色，不使用AI生成的历史场景或虚构史料。

## 内容维护

`source/catalog.json`维护批次与基本来源；`early.json`、`middle.json`、`late.json`按时期保存原创事实稿及人物介绍；`social-history-supplement.json`补充群众运动和基层人物线索，`people-supplement.json`补充人物档案。清单中的`supplements`用于向已有年份增补事件，不覆盖年度原稿。运行 `node tools/sync-party-history.mjs` 生成101年度HTML、总览、人物/文献页面、搜索索引及清单；再运行 `node tools/check-party-history.mjs`。每项事件有稳定ID、所属年、日期精度、名称、地点/范围（可缺省）、经过、结果与历史联系、具名人物、门类及来源定位。来源保留作者、刊载平台、网址、核对日与资料年代说明。

人物档案应依据独立人物专页，生卒年不从事件起讫推断；本库的相关人物不自动等于中共党员。没有足够独立生平证据的人物只列事件关联。人物事迹以1921—2021为叙述范围，后续生卒资料若收录须单独核实。

不为凑齐每年条数捏造事实，不批量复制原文或机械换词改写整篇。主要事实用原创结构表达；文献、会议名称和基本事实保留原名。原著全文及图片不随站发布。重要历史曲折与纠正过程一并收录，历史性质和评价需注明具体文献与编写年代，不以现有叙述倒推当事人的全部认识。

## 资料范围

主要参照中央党史和文献研究院、原中央党史研究室大事记；机构沿革与署名分开标注。2021百年大事记仅到6月，7—12月须依据后续大事记、公报及具体报道补齐。逐年覆盖不等于穷尽当年所有史实，后续可以在稳定ID下持续核订和扩充。

## 交互与可用性

总览按年代定位、年份直达，输入词可查全年全文索引；年度页面有主题与文字筛选、相关人物弹窗、来源折叠、相邻年跳转、固定锚点、分享和打印。页面正文在HTML中，JavaScript未载入仍可读正文并跳转；全文搜索需要索引，载入失败会明确回退为目录检索。新板块不设测验、复习或进度要求。

所有静态文件随GitHub Pages公开部署，运行不依赖登录、后端数据库、外部字体或接口。外站资料链接仍受各站自身可达性限制。网站不是上述编研机构的官方网站，也不能将有来源定位说成经过官方审定。

少数已核实别名在清单`personAliases`中登记，并说明依据；只做有证据的同一人物合并，不按姓名相似度自动归并。

# 两次世界大战逐月叙事

独立公开入口，位于通史侧栏和战役长卷导航。两卷共145个月度节点：一战56、二战89。主战期1914-07至1918-11、1939-09至1945-09共126个月连续无缺，其他月份为前史与余波选编。未把稀疏选编伪称为逐日全史。国家视角为基于事实的编辑解读，不是虚构个人自述。

## 数据与扩充

- `source/ww1.json`、`ww2.json`：稳定ID、年月、标题、战场标签、相关国家、人物、正文段落、同期视角及来源定位。增补同月史事时优先扩充该月正文；仍按战争进程讲故事，不用机械要素栏。
- `source/countries.json`：13个国家或帝国的分卷处境，俄国与苏联分别处理，不把现代国家边界直接用于旧帝国。
- `source/people.json`：31位主要人物简要展签，其他人物只建立事件索引，不冒称完整生平。人物行动与各月事实关联。
- `source/sources.json`：42项资料记录，含博物馆编年、档案、官方外交文件和研究著作；部分为同一资源不同用途的入口。来源存在视角、简化或错误，不照搬其所有日期与人数。

修改后运行 `node tools/build-world-wars.mjs`，校验主战期月份无缺、来源引用、视角与段落完整性，并生成 `war-data.js` 和 `manifest.json`。再运行 `node tools/check-world-wars.mjs`。页面使用 `#ww1/1916-07`、`#ww2/1942-11`，第三段可带国家ID。每月均可直接分享；国家追踪、主题与全文筛选在浏览器内运行，无账号要求。关联既有战役时沿用其稳定ID。

## 内容边界与核查

本站正文为原创事实叙述与解释，不转载资料全文，不虚构对白、现场细节或心理独白。年份月份依公历，俄国革命旧历名称、德军投降时区、日本宣布与签字分开说明。持续进程不是每月重新发生的事件。战役起讫、人数、核武器决策和统帅评价等问题保留口径与研究差异，不写未核实的精确数字。

目录与年度时间线用于跨月定位；详细事件还需结合对应主题资料和原始文献。部分军史网站访问受限，本版未声称读完美国陆军完整编年史；未将无法读取的目录作为逐条核验完成的证明。国家处境与因果连接属于编辑归纳，须与所据事实区别。后续加深时优先补足每月多战场进展、具体事件档案定位、普通人证言及其他参战国；新增事实须核对来源，不用没有事实内容的模板填月份。
